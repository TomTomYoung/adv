# 登場人物一覧

更新: 2026-09-13。q001〜q010 の登場人物は安定した ID で定義し、会話場面に AIPaint 製の画像を表示する。同じリネを別人として増やさず、関所番と水門番は分ける。名無しの役割に本名を捏造せず、集団は集団実体として記載する。

外見・服装・小道具は今回の美術設定であり、元のシナリオから確定した外見ではない。NPC は戦闘隊員へ自動加入しない。
