# 探索による到達とシナリオの常体化

確認日: 2026-09-25。作品版1.21.0の探索移動・常体化と適用範囲を記載します。現在はセル進入・施設到着で自動続行し、共通メッセージ内で選択します。

## 適用方針と範囲

イベントの成立に転移そのものが必要な場合を除き、行き先を選んだだけで探索隊を現場へ移しません。選択は出発準備を確定し、プレイヤーが通常の移動・階段・町の施設間移動を使って到達した後に場面を開始します。コードの制御フローである `jump` と、鏡などの設定上の転移、明示された帰還手段は物理移動の省略と区別して保持します。

今回の物理接続はq001・q002・q003・q004です。q005〜q200はイベント配置の索引があるだけで、全ての物語内移動を探索化したわけではありません。全200件に適用したのは地の文・概要・システム側のシナリオ文章の常体化です。人物の台詞を一律に常体へ変える処理ではありません。

## q001 帰らない灯番

正本は [story-q001.mjs](../../authoring/story-q001.mjs)。8場面、物語状態revision 4、救助後の2結末です。入口→巡灯路→老人の支道→帰路の消灯地点→入口→灯番詰所という5移動を、出発と到着へ分けました。場面開始時の `map.teleport`、選択時の座標移動、詰所への `town.return` を除去しました。

老人に肩を貸すと老人は同行状態になり、帰路の地点に着くまで消灯場面は始まりません。新人による救助は元の物語通りですが、探索隊を転送しません。救助後もまず入口まで歩き、通常の出口から町へ戻り、組合の下にある詰所へ移動して初めて帰還報告が成立します。

消灯から救助までの二場面は、その場面の中断選択だけを出しません。通常のセーブと同じ命令位置からの復元は可能です。その他の場面は中断できます。火の設定を会話再開のたびに再実行せず、各場面の初回に限ります。到着していない場面のスクリプトを起動しても、火や壁灯を先に変えません。

老人の油の保存、老人を先に帰さないこと、新人の恐怖と救助行動を別状態にすること、巡灯路修繕と付き添いの二結末は維持しました。携行火を補給しながら寄り道する探索と、特定地点で発生する脚本上の消灯は別の処理です。火・水位などの長期バランス調整は別途必要です。

## q003 晴天の増水警鐘

正本は [stories-v11-1.mjs](../../authoring/stories-v11-1.mjs)、現地配置は [q003.events.json](../../config/quests/q003.events.json)。9場面、物語状態revision 2、3結末です。鐘室、通行人のいる通路、上層の待避場、宿屋裏の汚水槽を実在する場所へ結び、9移動を定義しました。

最初の選択では避難完了になりません。通路へ歩き、通行人を連れて入口から町へ戻り、待避場に着いて初めて避難完了となります。探索隊だけが鐘室へ戻り、通行人は待避場に残ります。

宿屋裏の記録と原因は汚水槽への到着後に判明します。人手の警報へ切り替える経路では、鐘室へ戻って鐘とソラを迎え、鐘を持ち、待避場に着いてから設置します。遠隔地にある鐘をその場で受け取ったり、移動選択一つで往復を終えたりしません。放水の合意は宿屋で、試験は鐘室へ戻ってから成立します。

新しい場所は `hikarigaeri_lamplighter_post`、`hikarigaeri_waterwatch`、`hikarigaeri_tavern_cistern`。q003実装時点では町は計10か所でした。新規3か所の背景には既存画像を再利用し、今回画像は生成・差し替えしていません。独自背景の制作は未実施です。

## q004 二枚目の通行証

地下関所の外、詰所の受付、留置室前、地上の通行資格審査所に分けました。戸口のセルで入室を選択し、記録照会・帰還・申告・審査官同行・姉妹の帰路を9つの実移動として扱います。罰金は受付、強行救出の戦闘は留置室前で確定します。[個別経路](Q004_WORLD_ROUTE.md)。

## 共通処理

[world-story-kit.mjs](../../authoring/world-story-kit.mjs) は出発効果、同行者、到着効果を分ける原稿側の共通部品です。Coreへ固有クエストIDを追加しません。`state.journey` を保存し、到着前に受付地点へ戻って再度話しかけても場面を巻き戻しません。実際の目的地に到着すると自動確定します。町では施設ID、ダンジョンでは足元の実座標を検査し、正面からの調査を到着扱いにしません。

宿・医学校のサービス、店の購入は対応する現在地にいる場合だけ許可します。遠隔の操作要求は位置や資金を変えずに失敗し、施設へ自動移動しません。通常の迷宮一覧は出発先を持つ町ロケーションから選び、受注中クエストの入口ボタンは町のどの施設からでも使えます。ViewのボタンとCoreの判定を揃え、q001の入口を地域番号から地下水道と誤認しないよう実定義を参照します。隊編成・職業など、現在地を変えない既存の町内APIを全て施設限定にしたわけではありません。

## 地の文の常体化

[narration.mjs](../../authoring/narration.mjs) と [build-narration.mjs](../../tools/build-narration.mjs) で配布文章を生成時に整えます。表示時の置換ではありません。全200クエストと共通シナリオを対象とし、地の文・概要・結末・説明の文章フィールドだけを処理します。「」・『』内の台詞、話者付きsayの台詞、命令名・ID・数値・報酬・条件式は変更しません。

原稿に敬体が残っていても最終配布データとカタログは常体になります。新しい原稿では初めから自然な常体で書く方針です。「残します／記録します」「当たります／足ります」「覚ましました／目を覚ました」などを区別する回帰試験と、二度適用しても変わらない検査を追加しました。一般の日本語全てを正しく活用できる形態素解析器ではないため、新規の未知の言い回しは生成差分を人が点検してください。人物の固有の口調は保存します。

## 保存・生成・検証

現行作品版は1.21.0です。異なる内容版の保存は移行せず、読込失敗時に新規開始します。同版の移動途中、会話、同行者、荷物、環境を保存・復元します。

```sh
npm run build:scenarios
node tools/validate.mjs
node tools/check-static.mjs
node --test --test-concurrency=2 tests/*.test.mjs
npm run check:docs
```

[探索・文体回帰試験](../../tests/exploration-policy.test.mjs)を実行します。全体の最終結果と再生成一致は [PROGRESS.md](../development/PROGRESS.md) に記録します。旧データの構造指紋は `tests/fixtures/pre-1.11-structure.json` に保持し、q001・q003以外の文章外の構造、命令・条件・数値が変わっていないことを検査します。過去の原文fixtureは上書きしません。

実ブラウザでのクリック、背景と人物の重なり、スマートフォン幅、音声の確認は今回実施していません。自動試験の到達成功を実画面の確認や全編の文芸品質保証とは扱いません。
