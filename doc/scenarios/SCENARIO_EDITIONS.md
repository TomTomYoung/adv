# シナリオの版切替

更新日: 2026-10-26。作品内容版1.34.0のまま、シナリオの初版と第2版を選べるようにしました。本文の版と、セーブ形式・共通システムの内容版・配信更新IDを分けて管理します。

## 遊ぶ版と記録

「記録」のシナリオ版で、最新版を自動選択、初版、第2版を選べます。新しく始める人の初期設定は最新版で、現在の最新版は第2版です。現在プレイしている版も画面に表示します。

初版から第2版へ切り替えると、第2版の続きがあればその記録を再開し、まだ遊んでいなければ第2版を最初から始めます。初版へ戻すと、初版で中断したところから再開します。隊・所持品・金・依頼・戦闘・会話・報酬を含む進行全体を版ごとに保存するので、異なる本文へ途中の会話位置だけを持ち込みません。

自動保存と手動3枠は版ごとに独立します。保存ファイルにも具体的な版を記録し、読み込みではその版のデータを先に読みます。ファイルへ「latest」は保存しません。将来最新版が増えても、保存時の版の続きを再開します。

以前のセーブは版の項目を持たないため、初版として読み込みます。従来の自動保存があれば初回起動でその進行を再開し、新版への強制移行はしません。旧自動保存と旧3枠の原文は変更・削除せず、初版の記録として引き継ぎます。

「最初から」は選んだ設定の版を対象にし、確認画面で対象を示します。最新を選んでいれば現在の最新版です。版切替はその版の続きを再開する操作で、最初からやり直す操作とは分けます。

## 第2版の改稿範囲

第2版で改稿したのはq001「帰らない灯番」です。[第2版の原稿とレビュー](editions/e2/QUEST_Q001.md)で本文、条件による返答、結末と検査範囲を確認できます。礼拝堂q031〜040・q131〜140と沈没城q061〜070・q161〜170、観測所q081〜090・q181〜190、書庫q041〜050・q141〜150、機関廟q071〜080・q171〜180は旧本文・選択・結末を保って、実移動・同行・保持者を改訂しました。残る109件は初版の定義を継承します。加えて、新作の[仲間連作80件・162結末](editions/e2/COMPANION_QUESTS.md)を第2版だけへ実装しました。加えて[国境宿場の新作10件](editions/e2/ODDLAND_FIRST_TEN.md)を実装し、第2版は合計300件です。既存210件すべてをv1.2bで再制作した版ではありません。

q001は入口で新人へ伝えたことを保存し、救助と帰還後の会話へ反映します。油瓶、支える手、帰還帳を手掛かりにし、作者向けの説明を人物の台詞へ流し込みません。二つの結末は巡灯路の引継ぎと帰還者への付き添いに対応し、いずれも到着・救助・報告を満たした後で選びます。

物理的な到着、老人の同行、帰路の消灯戦闘、新人の救援、徒歩での帰還、報酬の一回性と後続依頼の解放を保持します。初版由来の消灯イベントには携行松明の燃料を固定値に変更する演出が残ります。再補給で救援イベントを飛ばせるようには戻さず、消灯の見える状態を本文へ描き、自然な燃料切れが全経路で再現されるとは説明しません。この固定演出と通常の燃料消費の統合は、後続のMechanism見直し項目です。

## 定義と生成

一覧は [data/scenario-editions.json](../../data/scenario-editions.json) で、`latest`、各版の表示名、差替える依頼のパスを宣言します。初版の正本は従来の `data/quests/` と各authoring原稿です。第2版は初版を基に、明示した依頼だけを同じIDで置き換えます。q001を別の報酬付き依頼として追加しません。`additions` は新しい依頼・施設・人物・物語地域をまとめた追加定義で、既存IDとの衝突を拒否します。新規IDは表示順の末尾へ追加します。

q001第2版の原稿は [authoring/editions/e2/story-q001.mjs](../../authoring/editions/e2/story-q001.mjs)、配布先は [data/scenario-editions/e2/q001.json](../../data/scenario-editions/e2/q001.json) です。`npm run build:editions` は専用生成器で第2版、文書の集計、配信指紋を更新します。`npm run check:editions` が原稿と生成結果の一致を検査します。既存の `build:catalog` にも第2版の生成を組み込んでいます。

`loadContent(read, {edition})` は差替え後のクエストとスクリプトを組み立て、その後にマップ上の固有イベントを投影し、内容を検証します。編集・既存試験・初版カタログの互換性のため、低レベルAPIの省略値は `e1` です。実ゲームのApplicationは必ず対象版を指定し、新規開始時の最新版を解決します。

初版カタログの本文は初版のまま保持します。第2版の本文は専用ページへ分け、配布内容の指紋には両版を含めます。新しい版を増やす際は一覧・原稿・配布先のほか、`src/core/scenario-editions.js` の対応版集合、保存・切替試験、専用文書を更新します。

第2版で初版を継承している依頼も、公開後には第2版の保存内で進行中になり得ます。q002以降を第2版へ追加改稿するときは、既存のVM位置・物語状態・報酬の移行、または進行中依頼の旧定義維持を先に設計します。本文差替えだけで公開して既存進行を初期化しません。PR #135の礼拝堂前半導入時の保存改訂だけが、ユーザー指示による一回限りの例外です。以後の改訂2の進行を再び初期化する許可として扱いません。

## 保存の実装境界

具体的な版はセーブ外側と `state.scenarioEdition` に同じ値を記録します。両方とも欠落した旧保存だけを初版と判断し、片方だけある保存、不一致、未知の版は拒否します。版を照合した後で既存の内容版移行と状態検証を行います。

ブラウザの保存キーは `lantern-archive:v1:scenario:saves` です。形式1のレジストリに選択方針、最後に遊んだ版、版別のauto・slot1・slot2・slot3をまとめ、1回のストレージ書き込みで切替を確定します。元の版の保存、移動先の読み込み・検証、保存領域への書き込みが成功してから、表示中のエンジンを交換します。

不正な保存や未対応版のimport、差替えJSONの読込失敗、保存容量不足で、表示中の進行や既存の保存原文を初期状態へ上書きしません。起動時の破損記録も原文を保持し、「保護中の記録を書き出す」で読み込めなかった原文をそのままファイルへ取り出せます。回復画面用の仮の新規状態を元の記録として書き出しません。実際の確認結果と未確認事項は[検証履歴](../development/PROGRESS.md)へ記録します。

## 第2版の地理差分と越境保存

第2版の `geography` は [geography.json](../../data/scenario-editions/e2/geography.json) を指します。[生成器](../../tools/build-oddland-geography.mjs)が新規マップ・施設・道標スクリプトと、地下水道・荷揚げ場の差替えを作ります。差替えは対象IDと基点のSHA-256を照合し、古い指紋・既存追加ID・重複対象があれば、適用前に全体を拒否します。地理を適用した後に依頼物体を投影・検証します。初版の基底JSONは変更しません。

2026-10-26のユーザー指示により、今回だけ旧e2との保存互換を切る。保存改訂番号 `scenarioRevision: 2` を外側とstateに保存し、番号なしの旧e2は自動移行せず明示的に拒否する。旧原文と手動枠は保持し、書出しできる。新規開始を明示した時だけ新しい自動保存を作る。初版の内容・保存互換は維持する。今回以後の改訂2の進行は次工程でも保持する。 新しい読込では地理改訂前のVMや帰路を移し替えません。過去4段階の定義は移設前監査のテストfixtureとしてだけ再構成します。

改訂2でも訪問拠点・登録・帰還先・拠点別油保管を検証します。番号の欠落・片側のみ・不一致・未対応番号は拒否し、読み込み前のエンジンを変更しません。作品内容版は1.34.0を維持します。[現在の越境・巡礼路](../world/ODDLAND_ACCESS_IMPLEMENTATION.md)。

## 礼拝堂後半・沈没城・観測所・書庫20件の保存継続

保存改訂2を維持する。更新前に受注済み・完了済みのq131〜150・q041〜050・q061〜070・q161〜170・q081〜090・q181〜190は、旧定義で保存全体を検証した後に `flags.legacyStoryRoutes` を付与し、旧イベントID・命令列・報酬を保持する。未受注分は変更せず、新たな受注時に `flags.currentStoryRoutes` を記録する。新経路の物語を持つ保存を旧経路と誤認したり、不正な混在を補修して読み込んだりしない。読込失敗時は現進行を変更しない。旧経路を新しい現場へ強制変換しないため、読書中・選択待ち・戦闘中の命令位置も維持できる。[後半10件](editions/e2/CHAPEL_SECOND_TEN.md)。
