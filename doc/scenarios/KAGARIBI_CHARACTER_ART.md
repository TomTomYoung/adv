# 篝火q201・q202の人物画

2026-10-27。PR #148統合後のmaster `5b080ed553b8e37519f47429b9a28f38efa2ed6c` を基点に、既存の人物4人へ専用の透過画像を追加した。

- q201：油蔵の記帳係ナヴィア `q201_clerk`、油の運搬人エン `q201_porter`。
- q202：別班の見習い灯番トマ `q202_trainee`、合図の教習係セナ `q202_trainer`。

各1024×1536の腰までの彩色人物画。既存の人物画と構図・質感を揃え、1人1画像を肖像と会話用立ち絵で共用する。画像登録は131→135、音声30は維持。未制作の定義済みNPCは42→38（篝火16＋国境22）となる。初版・第2版で同じ4人の画像を使う。

## 人物と状態

氏名、役割、目的、過去、所在、知識、物品の保持者は原稿を維持する。外見・服装・見た目の年代は今回の美術設定であり、原文から確定した情報ではない。q202のトマはq001の新人や探索隊員トマと別人。セナも別依頼の同名人物と統合しない。

ナヴィアは無地の勤務帳を持ち、エンは指の布を示す。エンの覚え書きやトマの訓練札は、受渡し後に絵だけが持ち続けることを避けるため人物画へ固定しない。署名、書類の文面、合図の具体的な試験結果、費用は本文と既存状態で示す。

q201は記帳台のナヴィアと休憩ベンチのエンを場面ごとに切り替える。q202は出発時のトマだけ、交差路へ同行・到着後のトマとセナの2人という既存castを使う。立ち絵の接続は同行・入隊・到着の新しい判定を作らない。

## 原本と再生成

[生成・変換記録](../../assets/source/characters/kagaribi-2026-10-27.json)に英語プロンプト、日本語訳、PNG原本、配布WebP、寸法、透明度、SHA-256を保存した。標準の画像生成機能で制作し、生成されたアルファを保持する。同寸法の可逆WebPは復号RGBAがPNGと完全一致する。

人物参照の正本は[原稿側の割当](../../authoring/kagaribi-character-art.mjs)。[篝火原稿の人物生成](../../authoring/kagaribi-kit.mjs)と旧原稿ビルドでもこの割当を使う。素材参照だけの更新には `npm run build:character-art` を使う。このコマンドは本文や旧版スクリプトを再生成せず、人物・素材登録と生成資料・配信指紋を更新する。

画面下端へ合わせる既存の人物表示を利用し、人物位置・倍率・本文領域のCSSは変更しない。残る16人は引き続き名前だけで表示し、別人の画像を補わない。
