# 灯帰りの迷宮 現行仕様

更新日: 2026-09-16。作品版1.10.0の町ロケーション・q002の実移動・q001・火・水没・装備個体を含む実装を対象とします。反映状態は[CURRENT_STATUS.md](CURRENT_STATUS.md)を参照してください。

## 実行と構成

HTTPで配信する静的ブラウザRPGADVです。ゲーム実行時に外部CDN・APIキー・サーバー側処理は不要です。開発・検証のNode.js要件は22以上。`npm run serve` はPythonのHTTPサーバーを使います。

作品固有データは `data/game.json` のmanifestからJSONとして読み込みます。任意JavaScriptをJSON内で評価しません。シナリオはJSON DSL、ダンジョンはJSON定義と登録された共通部品で構成します。YAML入力や設定フォームは現在ありません。

## 世界と探索

町は篝火の迷宮の入口を拠点に生まれた灯帰り、酒場は帰り火亭です。10地域の分類に13ダンジョン・26マップがあります。地域1には地下水道と篝火の迷宮、地域10には深淵・谷・移動集落が含まれます。町からダンジョンIDを選んで入場します。旧来の地域指定も使用できます。町は篝火広場を根とする7ロケーションを選択肢で移動します。店・宿・組合・医学校・標本室・審査所の背景と人物を表示し、q002は地下水道との往復・標本照会・審査を実際の現在地へ接続します。[ワールド接続仕様](WORLD_LOCATIONS.md)を参照してください。

1セルずつ前後移動し、左右操作は向きを変えます。調べる対象は足元と正面です。正面の閉じた扉は足元の再利用可能な階段より優先します。地図の踏査、扉・宝箱等の状態、会話継続を保存します。

篝火、周期水位・水門、腐食・破壊壁、植物の成長、鏡ワープ、技能貸出、市場取引、空気残量、動力配分、手動／ランダム地形変化、セルの流れへの逆行による衰弱、境界内の術制限を実装しています。操作・持続期間・座標は[ダンジョン一覧](DUNGEON_CATALOG.md)から各仕様を参照してください。

通常の灯油と、篝火の迷宮の携帯松明は別の管理です。環境による移動可否、遭遇率、敵の強さ、能力、技能の使用可否を、表示と実行で同じ計画器へ問い合わせます。

## 依頼と現地調査

200クエスト・629結末。受注状態は available／active／completed で、内部の場面進行とは分離します。受注時に戦績の基準点を保存します。結末の条件を実行時にも検査し、報酬を一回だけ付与します。

q001〜q010は人物・物品の所在、保持者、同席、介助、合意、情報取得、資材、到着を検査する `adv-story-state/1`。q011〜q020はカタログ反映後の `.catalog1.*`。q021〜q200は個別の `.flow.*` 等の場面を使います。q001は火と恐怖を軸にした改訂2で、救助後の二結末です。

クエスト固有イベントは同じクエストJSONの events と scripts に集約し、物体は読込時にマップへ投影します。出現条件 visibleWhen と操作条件 condition を別に記述できます。[QUEST_EVENTS.md](QUEST_EVENTS.md)を参照してください。

13件の現地調査もクエスト内イベントとして実際の固有状態を読み、確認できた観察を `flags.dungeonNotes` に保存します。依頼一覧と手帳で再読できます。再調査は現在の環境を判定し直します。住民の救出や署名の成立など、既存の別の物語上の事実は個別に確認します。

## 隊と職業

仲間候補10人から1〜5人を編成します。初期隊はアダ・ニオ・セラ・イルの4人です。NPC36定義は物語の登場人物であり、探索隊員へ自動加入しません。

隊のLv・EXPは共有します。30職を町の待機中に無料で変更できます。職業は技能、装備の種類、成長履歴、特性へ作用します。転職は回復を行わず、不適合装備を袋へ戻せない場合は成立しません。副職や職業技能の恒久的な持越しはありません。

通常の職業技能に加え、書庫で借りた技能、境界による制限、腐食した装備、深淵の衰弱などをコアで合成します。詳細は[JOB_SYSTEM.md](JOB_SYSTEM.md)へ記載します。

## 戦闘・戦績・資源

ターン制のコマンド戦闘です。技能と対象の選択時に、習得、出撃、生存、MP・HP・材料、装備、環境の制限を検査します。バフの更新・かばう・敵AI・逃走・全滅を処理し、戦闘結果に応じたスクリプトを再開します。

戦闘数、勝利、逃走、敗北、撃退、敵別討伐、遭遇別勝利を自動記録します。逃走前に倒した個体の討伐は取り消しません。`record_count` の `sinceQuest` で受注後の差分を読みます。旧版に記録のない過去の戦績は推測しません。

初期所持金は120G、傷薬5、解毒薬3、野営糧食3、松明3、縄3です。道具は44定義、通常の袋上限は各99。町で購入・休息・編成・転職を行い、帰還印と全滅にはそれぞれ定義された費用がかかります。

## 保存と表示

セーブ本体は形式1、作品内容版1.10.0、物語・ダンジョン状態の形式は各1です。旧内容版は移行しません。自動保存・スロット・ファイルで解析または検証に失敗した場合、Applicationが新しいゲームへ切り替えて自動保存します。同版の正常な会話・戦闘・所在・装備個体・火・水位はそのまま再開します。

BGM・SE・表示効果はゲーム進行から分離します。瞬間演出は保存せず、持続レイヤーのみ保存します。壁面・装置・人物の画像はViewModelから表示します。現在の件数は[DATA_SNAPSHOT.json](DATA_SNAPSHOT.json)、表示APIは[VIEW_CONTRACT.md](VIEW_CONTRACT.md)、確認済み範囲は[PROGRESS.md](PROGRESS.md)を参照してください。

## 水没と装備個体

2D地下水道はフロア全体の水没度0〜10、3Dは水平連結区域への水没操作です。下向きに通水穴がある区域では、下部へ再帰的に操作します。表示は1〜3が足元、4〜6が腰、7〜10が完全水没。6以上は潜水の備えが必要で、10では備えがない隊が溺れます。濡れによる雷・氷の弱点と自傷、炎・水の威力、速さ・腕力、敵の出現へ接続します。

廃坑の塩は装備個体へ累積し、水没区画への進入または退出時に落ちます。ソルトイーターは塩の多い個体を永久に消失させます。[水道・廃坑](WATERWAYS_SALT_MINE.md)と[立体地形](VOXEL_TERRAIN_AND_WATER.md)を参照してください。
