# オッドランド越境基盤の実装

実装日: 2026-10-26（日本時間）。PR #131の設計先端 `8bd05218f1bb37614a8763d0e65481a0cbcb3648` が基点。作品内容版1.34.0、第2版だけへ追加する。[設計](ODDLAND_ACCESS_DESIGN.md)の第1段階を対象とし、本書の290件・受付0件は基盤導入時の記録。続く[第一群10件](../scenarios/editions/e2/ODDLAND_FIRST_TEN.md)で現在は300件・現地受付10件となった。移設・サロメ街道は後続工程。

## 歩いて越境する

| 接続 | 灯帰り側の端 | オッドランド側の端 |
| --- | --- | --- |
| 地下水道の地上階段 | 灯帰り広場 | `region_1_f1 (1,1)` |
| 関所の登録口 | `region_1_landing (15,3)` | `e2_trade_corridor (1,1)` |
| 交易回廊から退避所 | `e2_trade_corridor (9,3)` | `e2_trade_refuge (1,1)` |
| 退避所から出入窓口 | `e2_trade_refuge (9,3)` | `e2_border_customs (1,1)` |
| 宿場の石段 | `e2_border_customs (9,3)` | オッドランド・国境宿場 |

全接続を往復できる。マップの指定セルで「任意調べる」から接続を選び、実行する。国境宿場からは施設画面の石段を選ぶ。登録は無料で、q004の受注・姉妹の証・結末を条件にしない。既存の関所戸口 `(13,3)`、姉妹イベント `(13,5)`、室内と審査所を保持する。

追加3マップは地下水道の同じ探索番号を保持する小さな2D通路。途中で油・HP・MP・探索番号を初期化しない。通路は固定照明と安全セルを持ち、携行灯が尽きても帰路を歩ける。足踏み以外の通常移動とマップ通過は既存の歩数・燃料処理を使う。宿場へ実到着して初めて訪問済みにする。短縮便や町間の瞬間移動は追加していない。

## 国境宿場と帰還

宿場の根は `oddland_border`。旅籠で宿泊・既存隊員の編成、施療所で無料の応急手当、補給店で既存商品の購入と携行油の無料補充、スキル屋で従来条件による教習を利用できる。無料給油はHP・MPを回復しない。設備修理前の油管理も維持する。

帰還先は実際に町から出発した時点で記録する。灯帰りから出た遠征は灯帰り、宿場から出た遠征は宿場へ、通常帰還・帰還印・全滅救助のすべてで戻る。宿場へ初到着したり宿を開いたりするだけでは帰還先を変更しない。地下水道の既存地上出口は実際に灯帰りへ出る出口として処理し、帰還印の帰還先とは区別する。

依頼受付・迷宮出発・中継出発は拠点をCoreでも検証する。既存290件と既存迷宮は今回すべて灯帰りの所属を維持するため、外国から直接受注・出発できない。手帳の進行記録は残す。基盤導入時の宿場の共同依頼所は0件。第一群追加後は宿場所属の10件を表示する。保管油・瓶は拠点別とし、外国の店で灯帰りの在庫を取り出せない。隊員・金・携行品は同じ隊の状態を使用する。
