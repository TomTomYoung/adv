# 町・地区・シーンの切替候補

照合日: 2026-10-27。作品版1.34.0、PR #143統合後の現行第2版を対象とする。[不足素材台帳](ASSET_BACKLOG.md)から、場所の分け方を先に決める項目を抜き出した提案。今回変更したのは文書で、町の追加・親の変更・場面切替は未実装。

## 切替の判断基準

- **独立拠点**：国・訪問・受注・帰還・救助・補給をその場所で管理する町。`worldTravel.settlements` と町のroot、往復経路を揃える必要がある。
- **町の地区・施設**：同じ町の帰還・受付圏のまま、広場から家・工房・窓口へ移る。既存locationがあれば背景・入口の整理を先に行う。
- **現地の個別シーン**：実際の足元へ到着してから、会話・作業・内部の状態に合う描画へ切り替える。背景変更だけで人物・物品・隊を移動させない。
- **探索マップ**：道順、危険、燃料、水深、渡し、救助経路や複数の訪問先が遊びになる場所。屋外であることを理由にすべて町画面へ置換しない。

現在は151ロケーション、86マップ、6独立拠点。locationが存在することと、独立した町として登録されていることは別である。

## すでに独立している6拠点

- 灯帰り：root `hikarigaeri_square`。
- 国境宿場：`oddland` / root `oddland_border`。
- 石橋の交易市：`oddland_market`。
- 巡礼台地：`oddland_plateau`。
- 旧王領の村：`oddland_village`。
- サロメ：`salome` / root `e2_academy`。

これらの独立化は完了済み。灯帰り以外の5拠点は到着背景が共通広場で、まず背景と出入口表示を分ける。旧王領の村の港やサロメの生活市を別の都市として再作成する必要はない。

## 独立した町・生活拠点にする候補

### 優先度1：行政都市

現行は `e2_admin`「行政都市・水門警備隊庁舎」が `e2_road` 配下の一施設で、独立settlementではない。作者設定の都市と庁舎を同じ一画面で扱っている。

町の到着口・街区と庁舎内を分ける候補。既存 `e2_admin` は庁舎の安定IDとして残し、都市の根を別途設計する。行政都市への往復、初訪問、受注、帰還先、必要なサービスを先に定義する。現在の個人依頼の受注や施設内保存だけで新都市への訪問を一律付与しない。

### 優先度1：地下街

現行は `hikarigaeri_waterwatch` → `e2_underground` → 荷揚げ場 `e2_docks`・赤壺市場 `e2_market`・排水回廊 `e2_culvert`。専用の生活圏と勢力を持つが、現在の帰還・受付は灯帰り圏。

まず辻・荷揚げ・市場・外縁回廊を別背景にする。その後、地下街で受注・救助・補給を完結させる設計なら独立settlementへ昇格する候補。地上との徒歩経路と往復条件を保ち、ニオの勢力支援を新しい街経済や勢力AIの実装済み扱いにしない。

### 優先度2：開拓地

現行は `e2_settlement`「仮設集会所」と `e2_levee`「旧堤の作業道」が停留所配下にある。集会所を村全体の代わりに使っている。

開拓地の到着口／共同広場と集会所の室内を分ける候補。旧堤、墓地への小道、石切場の救助口は現場の地区として扱う。補給・救助・帰還の独立運用を採用する段階で町のrootを追加し、被災者の集落を行政都市やサロメと混同させない。

### 当面は小拠点・地区のまま扱うもの

- 街道の共同施療院 `e2_chapel`：施療、礼拝、裏の林 `e2_grove` をシーンとして分ける。町一式を増やす前に街道の休息拠点として整理する。
- 薬草探索路 `e2_herbs`／`e2_garden`：休息所と花畑の現場。探索を拡張するなら経路と到達条件を設計し、今の一対のlocationを新都市には数えない。
- 観測所関連の村 `e2_observatory_village` と補給村 `e2_observatory_supply`：現行は依頼用探索マップ。常設の宿・補給・地域受付を持たせると決まった場合に小拠点化を検討する。現段階では町の追加を確定しない。

## サロメで町を増やさず地区を分ける候補

[六地区の設計](SALOME_DESIGN.md)を既存IDへ整理する。第二の「学術都市」を作らない。

- 学門前・下宿街：`e2_academy`、下宿・共同依頼所・生活市を入口としてまとめる。
- 灰時計の書庫周辺：`e2_archive`／`e2_stacks`、契約・写本・保管の部屋を一地区として案内する。個人連作の踏査回廊と迷宮 `region_5` は別の現行IDであり、見た目だけで同一地点へ統合しない。
- 機関坂・遺物管理区：`e2_workshop`／`e2_relic`／`e2_storage`、義肢・刺繍の作業台、部品庫をまとめ、書庫と違う外観・室内へ切り替える。
- 外縁：水路、生活道、墓地道、谷道へ出る案内を明確にする。個人宅や祠を学門前の施設一覧だけで平面的に並べる状態は、地理を確認したうえで整理する候補。
- 聖堂学舎、魔術院の独立した地区一式はまだ設計段階。既存の施療所や試験槽があるだけで六地区完成とは数えない。地域新作の採用範囲と同時に作る。

地区の親を変える場合も、現在の `worldPlaces`、旅程、施設内保存を先に調べる。背景だけの変更から始めれば、地区再編と保存移行を分離して確認できる。

## 優先して個別シーンへ切り替える現場

### 優先度1：屋外から住居・作業室へ

- q179の三家：現在は `e2_salome_outskirts` の (3,7)、(9,7)、(13,7) が各家の訪問先。同じ道路の絵で話すため、各戸口または室内のシーンへ切り替える候補。三家の意思・訪問順・墓標の保持者は別状態のまま保つ。共通家屋絵に戸口差分を付けてよい。
- q071の作業員室：`region_8_f1` (5,11)。門番の巡回経路と、本人に帰還を求める室内を見分けるシーンへ。迷宮内の室内locationを使う場合は、その足元から入退室し、町の無料回復や編成を自動開放しない。
- q171〜173の家・店・工房：`machine_home`、`machine_shoes`、`machine_lui`、`machine_mother`、`machine_tera` はすでに別location。新規の場所を重ねず、戸口・靴店・刺繍工房・住居の背景へ差し替える。
- q188の妻・弟との個別面談：`observatory_room` と `observatory_backroom` は別locationとして実装済み。部屋・出演人物を切り替え、全員が同席しているような共通絵を避ける。別居先 `observatory_lodging` も区別する。

- q171の足音：`e2_salome_outskirts` の境界・規則の確認・試験・輪。現場の区別を背景や印で見せる。歩行や場面切替だけで試行回数を進めない。
- q178の夜と翌朝：`machine_family`／`machine_morning` はすでに別location。宿の家族室と扉の先を状態差分で描き分ける。通過後に物語の夜へ戻れない制約を保ち、一般の世界時計を新設した扱いにはしない。
- q177の鏡、q180の怪談：鏡の像・日時と現実の店、語りの内容と現在地を演出上区別する。映像や語りの切替で、実際の遠方へ移動・到着したと判定しない。
- q135の沈んだ宿：`e2_sunken_inn` の潜水口と水底の食堂。水際・水中の場面を区別するが、潜水・水深・帰路を通常の宿泊施設へ置き換えない。
- q137の燃え残る図書館、q139の救助坑道、q140の整備別棟：読書机、負傷者・排水・送気、事故現場のシーンへ。各マップ・座標はすでに分離されているため、最初の改善はartと局所背景の割当。

### 優先度2：湖岸・前線・収容地

- `e2_royal_lakeshore` と `e2_royal_island`：渡し場、舟への乗降、島の野営を分ける。現在の渡し舟の往復を会話だけで省略しない。

- 前線・砲台・橋・砦・守った村・補給村：探索マップは残し、交渉席・指揮所・倉庫・退避先で局所シーンへ切り替える。
- `e2_observatory_rescue`：救助標、水路、救出待機を区別する。通常の町や宿として扱わない。

## 実装するときの順序と受入れ

1. 既存6拠点の背景と屋外描画を分ける。現行ID、経路、受注、帰還を変更しない範囲を先に完成させる。
2. すでにlocationがある住居・店・部屋の背景とcastを接続する。
3. 三家・作業員室など、足元のイベントから局所シーンや迷宮内室内へ切り替える試作を作る。
4. 行政都市・地下街・開拓地の独立拠点化、サロメ地区の親子再編を、保存移行を伴う別工程として実装する。

各変更で出発・到着・退出・帰路、会話と旅程の途中保存、旧受注・旧探索の帰還先を確認する。人物の同席、品物の保持者、費用・報酬、燃料・遠征番号を見た目の切替で更新しない。Scene／Classicの1440px・390pxで現在地名、背景、人物、本文と選択肢を確認する。

このリストは提案の採否を含む設計台帳。旧100件の地域配分採否、新作30件、三地域100件計画の件数を変更するものではない。侵攻・大水門開放・最終盤の人物交代は対象外。
