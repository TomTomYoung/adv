# 不足素材と表示接続の台帳

照合日: 2026-10-27。作品版1.34.0、PR #143統合後のmaster `f7dfc22fb09d42860d3c8ba697bf629b3e614eb2` を基準とする。対象は初版と第2版の現行実装。制作・採用の優先順位を示す文書で、画像・音源・新しい町はまだ追加していない。[町・シーンの切替候補](SCENE_SWITCH_PLAN.md)と併用する。

## 照合結果

- [素材登録](../../data/assets.json)は画像126、音声30（探索・戦闘BGM各1、SE28）。登録先156ファイルはすべてGitツリーに存在し、この一覧内の欠落は0。画像の見た目・音質や全画面での表示を今回新たに確認した結果ではない。
- 第2版のロケーションは151。初版15＋仲間連作20＋オッドランド地理66＋国境新作7＋サロメ地理43。町、施設、迷宮内の室内を含む数で、151都市ではない。
- 151ロケーションは8種類の背景を共用する。広場31、店9、組合82、酒場13、医学校6、標本室5、保険審査所2、関所3。共用自体は不具合ではないが、庭・墓地・住居・工房などの用途の違いが絵に表れていない。
- 初版56マップ・13迷宮・210依頼、第2版86マップ・20迷宮定義・300依頼。第2版の追加30マップはすべて `background: corridor`。実際の探索描画は迷宮の壁・床・装置アトラスも使うため、背景IDだけの変更では完成しない。
- 第2版の人物定義86のうち、肖像・立ち絵とも未設定のNPCは42人（篝火20＋国境宿場22）。既存36NPCには肖像と立ち絵の登録があり、仲間連作8人には既存の仲間肖像がある。
- 現場接続した旧100依頼の `story.scenes` 753場面はすべて `cast: []`。人物の `entities.character` も未接続。本文や所在の定義はあるが、人物画を制作するだけでは表示されない。
- 仲間80依頼の場面castは同行する仲間だけ。現地の相手は本文・作者側のagentsに存在するが、独立した人物表示へは未接続。80件をそのまま80人の新規制作数とは数えない。

「不足」は、専用絵の未制作、既存絵の仮用、人物や場面への未接続、将来案を分ける。原稿や旧PNGの存在を、配布用に登録・表示できる素材の完成とは扱わない。

## 最優先：地域と屋外を見分ける素材

### 町の到着背景5系統

次の5拠点はすでに別の町として移動・帰還を実装済み。新しい町IDではなく、到着時にその町と分かる背景を制作・割り当てる。

- 国境宿場 `oddland_border`：出入窓口からの石段、荷車、宿と掲示板。[第一群の詳細台帳](ODDLAND_ASSETS.md)。
- 石橋の交易市 `oddland_market`：橋と交易の両岸、荷揚げと店の並び。サロメ側の生活市と区別する。
- 巡礼台地 `oddland_plateau`：台地、礼拝堂への階段、巡礼宿と組合。
- 旧王領の村 `oddland_village`：村の広場、港への道、沈没城・観測所への出入口の案内。
- サロメ・学門前 `e2_academy`：高台、三学の建物、坂道、下宿街と書庫への分岐。

灯帰りの `location_square` は既存の基準背景として利用する。5枚は到着背景の最小案で、各施設の差分や昼夜差分を含む確定総数ではない。

### 街道・外縁の探索描画

- オッドランド街道3区画：`e2_market_road`、`e2_pilgrim_road`、`e2_village_road`。道、橋・坂、草地や外壁、行先の違いが必要。
- 高台街道2区画：`e2_highland_lower`、`e2_highland_upper`。坂下と学門坂、町の近づく見通しが必要。
- サロメ水路：`e2_salome_canal`。岸・水面・橋と静養の場所を区別する。
- サロメ生活道：`e2_salome_outskirts`。戸口、井戸、道祖神、境界、足音を試す道を区別する。
- サロメ墓地道：`e2_salome_cemetery`。墓地、葬列の道、墓標の育つ庭を区別する。
- サロメ谷道：`e2_salome_valley`。獣の棲処、進行路、警告を届ける先を区別する。

`salome_road.art` は書庫 `region_5.art` と同一。`oddland_roads` を含むオッドランド追加6迷宮のartは礼拝堂 `region_4.art` と同一。屋外用の壁・床・境界・装置の描画セットを用意し、必要なら描画テーマを分ける。現在の通行セル・照明・帰路を絵に合わせて変更する工程ではない。

- 魔物・戦闘・エフェクト：現行登録ファイルの欠落はない。新しい地域素材監査を理由に既存魔物を一括再制作しない。4迷宮の深層24種・残る8主などは[未実装の戦闘設計](../battle/FOUR_DUNGEON_COMBAT_DESIGN.md)と同時に別便で確定する。

## 制作順と完了条件

1. 5拠点の到着背景、屋外街道・サロメ外縁の描画を優先し、場所の誤認を減らす。
2. 42NPCと旧100件の出演接続を、実際に通す依頼の単位で進める。
3. 住居・書庫・工房・湖岸・収容地を用途別の共通背景＋差分で揃える。
4. 状態差分・小物・環境音を追加する。未実装地区、追加職・仲間、最終盤の絵は別計画にする。

少色のドット絵を基本とし、同じ地域で視点・解像感・パレットを揃える。立ち絵は透過と足元基準、背景は本文・選択肢・人物を重ねる余白を確保する。画面内の固有名・条件・費用はUIの文字で扱う。

完成は「制作済み」だけでなく、出典記録、配布ファイル、assets登録、location／art／castへの接続、Scene／Classicの広幅・狭幅での表示確認までを含む。現在の保存改訂2、地理版2、初版の素材参照を維持する。
