# 屋外探索の描画

2026-10-27。PR #145統合後のmaster `309bf31e0f1b2a8631841cb7c6a7f80ab4caf493` を基点とする。第2版の街道とサロメ外縁、計9区画へ屋外描画を接続した。

## 対象と見分け方

- `e2_market_road`：石畳、低い石の欄干、石橋と水辺の遠景。
- `e2_pilgrim_road`：灰色の石道と石積み、巡礼台地の礼拝堂。
- `e2_village_road`：土道、生け垣、海の入り江。
- `e2_highland_lower`：土道、段丘の石積み、草地と丘。
- `e2_highland_upper`：明るい敷石、低い石壁、塔と学術施設の屋根。
- `e2_salome_canal`：岸の石畳、低い護岸、水面。
- `e2_salome_outskirts`：土道、木の柵、家並み。
- `e2_salome_cemetery`：石道、墓標と植栽、糸杉。
- `e2_salome_valley`：土と岩の道、岩壁、谷の樹木。

低い境界の上に空と遠景を描く。空は方位に追従し、路面と境界は現在の座標・レイ交差位置から描画する。水路の水面は護岸の外の水平面で、壁へ水模様を貼らない。地上の目印は装飾であり、新しい通過口や操作対象ではない。操作できる場所は既存のマーカー・地図・選択肢で示す。

## 実装と維持するもの

[原稿側の割当](../../authoring/editions/e2/outdoor-appearance.mjs)が地理生成時に `map.outdoor` を付ける。[許可するテーマ](../../src/core/outdoor-appearance.js)と[描画](../../src/view/outdoor.js)を分け、未知のテーマは内容検証で拒否する。今回の絵はCanvasのコードによる少色の図形・模様で、生成画像や新規画像ファイルの追加ではない。画像131・音声30の登録数は変わらない。

対象区画では継承した礼拝堂・書庫の壁、床、汎用装置画を探索画面へ出さない。明示されたセル画像、特殊床、水深、扉、エッジは既存処理を優先する。地形・通行・遮蔽・照明の判定、費用、イベント座標、帰路、初版の描画は保持する。低い境界の外側は従来どおり通行できない。

`background: corridor` と迷宮artの元定義は互換・既存参照用に保持するが、この9区画の通常探索では屋外テーマが優先される。保存改訂2・地理版2・作品版1.34.0は維持し、描画テーマを保存状態へ書き込まない。

## 検証と後続

[比較試験](../../tests/outdoor-appearance.test.mjs)は9区画の新旧投影、全セルの通行可否、遮蔽レイ、照明、保存読込と移動後の状態一致を確認する。[ソフトウェアCanvas確認](../../tools/render-outdoor-check.mjs)は実際の投影と描画を画像化する。[ブラウザー確認](../../tools/browser-outdoor-smoke.mjs)は9区画×Scene／Classic×1440／390pxの36条件で、空、向きによる描画変化、保存再開、横はみ出し、Sceneの1画面内表示を確認する。ブラウザー用の各地点は描画fixtureで、実歩行は既存の地域別検査を併用する。実施結果は[検証履歴](../development/PROGRESS.md)に記録する。

今回で完了するのは9区画の描画分離。個別の戸口・井戸・道祖神・葬列・獣の棲処、作業中や修復前後の差分は未制作。追加30マップのうち残る21区画の仮用、NPCと出演、施設背景は[不足素材台帳](ASSET_BACKLOG.md)に残す。町・地区・局所シーンの再編は今回行わない。
