# 進捗と検証

更新日: 2026-09-09。

## 完了

遊べる静的ブラウザRPGADVへ置き換えました。100件・300結末、10地域20階層、探索、隊、戦闘、町の各施設、複数保存、独立ビュー、編集プレビュー、実素材を実装しています。

JSON駆動の実行系は39命令、構造化条件・計算式、保存可能な継続スタックを持ちます。実行時検証器とエディター向けJSON Schemaを用意しました。

AIPaintのPaintCoreで6画像、AIMusicのMusicCore/renderPCMで2曲を実際に生成しました。実行素材、編集用原稿・命令列、固定したエンジンソースと再生成コードを保存しています。

## 実行済みの確認

最終検証は16テストすべて合格（失敗・skipなし）。100件×3経路と通常条件の100件通し検査を含みます。

Node.js 24環境で確認しました。コードの対応下限とCI指定はNode.js 22です。

- 100件のID・本文・300結末、419スクリプト、20マップの参照と幾何学的到達性。
- 全100件×3結末へ、実マップの移動・調査・選択・戦闘を通して到達。分岐網の検査では高レベルのfixtureを使い、戦闘バランスと切り分けています。
- 別の通し検査では、初期4人・初期能力・初期資金から、獲得報酬のみで補給・宿泊し、100件全ての事情を踏まえた結末を完了。デバッグ回復は使用していません。
- 本文・選択・戦闘中の保存と復元。同一乱数状態から同じ戦闘結果へ進むこと。
- 逃走では未完了、敗北では町へ救助、再挑戦可能、報酬・宝箱の重複取得防止。
- 壁で歩数を消費しないこと、鍵と施錠扉、階段移動、道具、毒、装備の在庫、無料施療所、5人目の加入。
- 不正保存・別作品・バージョン違い・不正HP・所持数・スクリプト位置の拒否。
- 危険な状態パス・未知命令・参照切れの拒否。分岐ローカル変数とreturnの継続。
- JavaScript構文、静的ファイルとモジュールの参照、ビューからコアへの依存禁止、PNG/OGGファイルの形式。

検証コマンドはルートREADMEにあります。GitHub Actionsへ同じ検査を登録しています。リモートCIの結果は実際の実行結果を参照してください。

## 残る制限

実ブラウザでのクリック操作、画面の視覚確認、モバイル実機、音声の試聴・アンロックは未検証です。自動検査は表示の美しさや物語の面白さを保証しません。100件を人が通して遊ぶプレイテストは未実施です。

エディター用JSON Schemaは生成済みです。依存なしの実行時検証器とテストをCIの判定に使います。外部のJSON Schema実装による適合検査はこの環境では未実行です。

旧設計の全命令を実装したわけではありません。YAML読込、時間帯システム、NPC自律移動、状態異常の任意フック、サブルーチン戻り値、jump/wait、演出タイムライン、ゲームパッド、ランダムマップ生成UIは未実装です。既存のJSON_SCRIPT_SPECは将来の設計原本として残しています。

地域ごとに地形と依頼は異なりますが、基本的な調査方式は痕跡・証言・決着の共通構成です。魔物画像は5種を地域間で再利用し、音楽は探索・戦闘の2曲です。追加の美術・音楽や戦闘演出は今後拡張できます。
