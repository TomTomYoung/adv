# 斥候：探索技能

実装日: 2026-10-13。内容版1.25.0。斥候の7技能と盗賊の罠解除を実装し、現行カタログへ反映した。

[職業システム](JOB_SYSTEM.md) ／ [技能レベル](SKILL_LEVELS.md) ／ [状態異常・戦闘時状態](STATUS_EFFECTS.md) ／ [トラップ](../dungeons/TRAPS_AND_HAZARDS.md)

## 基本方針

斥候は、未探索域・罠・敵との接触順を事前に操作する探索職とする。新しい技能はダンジョンフィールドで使用し、戦闘中や町では使用しない。

「技能を習得しているか」と「その技能の技能Lv」は別に扱う。職業・人物Lv等によって技能そのものを習得し、習得後は SKILL_LEVELS.md の規則で技能Lv1〜3程度へ成長できる。

## 罠解除

斥候と盗賊が使用可能。

通常の床トラップは、罠の隣接セルに立って罠設置セルを向いている状態で解除できる。まだ発動していない罠設置セル上にいる場合も解除できる。

罠設置セルの壁面に罠が取り付けられている場合も対象にできる。壁面罠は罠が属するセルと面の向きを持ち、技能使用者がその面を正しく対象にしていることを検査する。

解除成功後は、その配置の進入イベントを無効化する。既存の発生回数とは別に「解除済み」を保存し、保存再開・区画移動で復活させない。再装填・修理を明示した罠だけが再び有効になる。

技能Lvによっては、解除した罠をアイテムとして回収できる。どの罠種をどのアイテムへ変換するか、回収確率、所持上限、回収不能な大型罠・魔法罠の扱いは罠定義側へ持たせる。

既に発動処理が始まった罠を後から無効化して被害を取り消すことはできない。

## 罠発見

斥候がダンジョンフィールドで使用する。使用者を中心とする N×N の範囲から罠を探索し、発見した罠をマップへ表示する。Nは技能Lvや個別技能定義から決める。

発見は解除ではない。発見済み情報を保存し、再入場後も既知の罠として地図へ表示する。壁面罠は設置セルだけでなく設置面も記録し、解除時の向き判定へ利用する。

技能Lvが上がると探索範囲、発見対象の種類、隠蔽度への対応などを強化できる。具体値は実装時にデータで指定する。

## 奇襲

斥候がダンジョンフィールドで使用する。次に開始する戦闘へ味方側の先制を予約する。先制回数は技能Lvまたは技能定義で決める。

予約は次の戦闘開始時に消費する。敵側にも先制候補がある場合は、戦闘開始時にどちらが先制を取るかを一度だけ解決し、味方と敵が同時に先制状態にはならない。

## 索敵

斥候がダンジョンフィールドで使用する。現在フロアの通常遭遇候補から敵を選び、通常の戦闘開始処理で戦闘する。固定イベント戦闘・クエスト専用戦闘を勝手に引き寄せない。

## 哨戒

斥候がダンジョンフィールドで使用する。一定期間、敵側から先制を受けない状態をパーティーへ付与する。哨戒は味方へ先制を与える技能ではない。

## 迷彩

斥候がダンジョンフィールドで使用する。一定期間、通常の戦闘発生確率を下げる。固定戦闘、クエスト戦闘、セル進入イベントによる戦闘は一律に消さない。

遭遇率補正は既存のパーティー遭遇率、火の効果、安全地帯等と同じ最終遭遇計算へ接続する。

## 偵察

斥候がダンジョンフィールドで使用する。使用者は一時的にパーティーから離脱して偵察状態になり、その間は通常の出撃メンバーとして戦闘・他技能・サービス利用に参加しない。

偵察結果として、現在フロアの未探索部分をいくらか開示し、罠を発見する。技能Lvが高い場合は、一部の発見罠を解除して戻ることもできる。

偵察は一時離脱状態を保存して帰還時に復帰させる。保存再開、全滅、帰還、偵察中の強制イベント、使用者以外が戦闘へ入った場合の扱いを実装時に明示し、人物消失を起こさない。

## 実装上の共通状態

罠発見は発生回数とは別に発見済みを保存する。罠解除も発生回数とは別に解除済みを保存し、解除済みなら occurrence 抽選より前に候補から除外する。

奇襲は次回戦闘へ渡す味方先制予約を保存する。哨戒・迷彩は探索中の期限付きパーティー効果として保存する。偵察は一時離脱者、開始地点、開始時刻／歩数、帰還条件、結果を保存する。

これらを一般の flags へ散在させず、探索技能用の構造化状態として検証・保存する。

## 現行の数値と境界

技能：罠解除 / 人物の習得Lv：1（斥候・盗賊） / 技能Lv1 → 2 → 3：難度1 → 2・部品回収可 → 3

技能：罠発見 / 人物の習得Lv：1 / 技能Lv1 → 2 → 3：3×3・隠蔽1 → 5×5・隠蔽2 → 7×7・隠蔽3

技能：奇襲 / 人物の習得Lv：5 / 技能Lv1 → 2 → 3：先制1・40歩 → 2・60歩 → 3・80歩

技能：索敵 / 人物の習得Lv：1 / 技能Lv1 → 2 → 3：MP2 → 1 → 0

技能：哨戒 / 人物の習得Lv：1 / 技能Lv1 → 2 → 3：30歩 → 50歩 → 80歩

技能：迷彩 / 人物の習得Lv：5 / 技能Lv1 → 2 → 3：30歩・0.6倍 → 50歩・0.4倍 → 80歩・0.2倍

技能：偵察 / 人物の習得Lv：10 / 技能Lv1 → 2 → 3：半径4・8セル・6歩 → 半径6・16セル・5歩 → 半径8・24セル・4歩・解除2件

7技能のLv2は使用5回または訓練1回、Lv3は人物Lv10以上かつ使用15回または訓練2回。範囲・費用・条件の正本は [config/jobs.json](../../config/jobs.json)。旧来の毒の刃、足払い、測量、登攀誘導、職業特性を保持する。足払いは技能Lv2でMP2、Lv3で50%のスタンを追加する。

罠は `cellEvents[ID].trap` に `kind`・`hidden`・`difficulty`・任意の `recovery` を持つ。`recovery` は item/count/minLevel/chance。針は硬い茨、矢は機関部品を技能Lv2から50%で1個回収する。回収定義のない罠は回収しない。袋が満杯でも解除は成立し、回収しないことをログへ表示する。回収の再試行はできない。

壁罠はセル配置の `eventFaces[イベントID]` でnorth/east/south/westを指定し、所有セル上でその面を向いて解除する。床罠は正面の隣接セル（閉じた共有壁を越えない）、または発動回数0の現在セルから扱う。隠蔽0は直接対象にでき、隠された罠は発見してから解除する。複数対象がある場合は人物の技能一覧から対象名を選ぶ。進入処理の実行中には技能を使えない。通常の再入場で解除済みは復活せず、manual指定の `cell.event.reset` だけが再装填する。

`scouting` に traps/effects/recon を任意保存する。発見した罠は地図へ、壁罠はマスの端へ表示し、解除済みは薄い印で残す。期限は成功歩でのみ消費し、旋回・メニュー・戦闘・保存では減らさない。帰町で期限効果を消す。迷彩は歩行時の通常抽選だけへ掛け、索敵・イベント戦闘には掛けない。

偵察の結果候補は出発時に同フロアの通行可能な接続域から決め、保存する。帰還時に地図と罠情報へ反映し、上位Lvで予定した罠を解除する。結果としての部品回収は行わない。元の隊列位置を保存し、復帰枠を確保する。最後の生存者は離脱できず、同時偵察は1人まで。残る隊員の通常戦闘中は離脱を保ち、偵察者は戦闘・経験値・技能使用へ参加しない。

別マップへの移動、帰町、室内施設への入室、全滅救助、外部スクリプトによるイベント開始では、結果を破棄して即時合流する。通常の味方へのアイテム使用は中断しない。強制イベントが人物を加除するときも、先に復帰させる。同フロア内の転送は継続する。どの経路も人物を待機者へ置き去りにしない。

処理は [scouting.js](../../src/core/scouting.js)、回帰検証は [scouting.test.mjs](../../tests/scouting.test.mjs)。標準パッケージへメタデータを追加したが、罠を全マップへ新たに一括配置してはいない。
