# 状態異常一覧

更新日: 2026-10-13。作品版1.25.0。通常状態異常14件＋戦闘限定状態2件。

状態異常Lvは全種類でLv1〜Lv3固定、Lv3が上限です。Lv未指定はLv1。毒系・帰らぬ呪い・濡れ・衰弱、およびまひ・くらやみ・各封印・こんらんのLv1数値は2026-10-13時点の暫定基準値です。戦闘限定の防御とスタンもこのカタログに含めます。
