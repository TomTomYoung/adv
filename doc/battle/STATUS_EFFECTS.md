# 状態異常の共通仕様

2026-10-12。作品版1.25.0。トラップ、戦闘技能、通常スクリプト、水濡れ、回復・解除から使う共通仕様。

[トラップ](../dungeons/TRAPS_AND_HAZARDS.md) ／ [セル](../dungeons/CELL_LAYERS.md) ／ [職業・技能](JOB_SYSTEM.md)

## 現行の定義

ID：poison / 名称・分類：毒・身体異常 / 効果：成功歩ごとHP−1、戦闘ターン終了時HP−3 / 標準の持続：解除まで

ID：hollow_curse / 名称・分類：帰らぬ呪い・魔術系 / 効果：成功歩ごとHP−2、戦闘ターン終了時HP−4 / 標準の持続：解除まで

ID：wet / 名称・分類：濡れ・身体状態 / 効果：雷・氷の被害1.5倍。味方が雷・氷術を使うと最大HPの10%を失う / 標準の持続：乾燥・解除まで

ID：weakened / 名称・分類：衰弱・パラメータ異常 / 効果：力と防御が75% / 標準の持続：12歩または3ターン

ID：enfeebled / 名称・分類：重度衰弱・パラメータ異常 / 効果：力・防御・速さが50% / 標準の持続：20歩または5ターン

ID：arcane_malaise / 名称・分類：魔力障害・魔術系 / 効果：知力が50% / 標準の持続：12歩または3ターン

パラメータ倍率は装備・職業・環境効果の後、一時戦闘バフの前に適用し、小数を切り捨て、対象能力の下限を1にする。HP・MP上限の変更には使わない。弱い異常と強い異常は別IDで、併発した場合はそれぞれの倍率が掛かる。

分類の名称自体に隠れた追加効果はない。針・矢は衰弱、ガスは重度衰弱、異常型魔法陣は魔力障害を既定値とするが、配置側で変更できる。

## 付与、重複、持続

`applyStatus()` を戦闘技能・`status.apply`・トラップ・水濡れで共有する。死亡中の対象、指定状態への免疫、環境による停止中の状態には付与しない。技能の成功率抽選は従来どおり技能側で行う。トラップの発生抽選とは別である。

状態IDは `actor.statuses` の配列に一度だけ保持する。再付与による同一IDの二重掛けはない。期限付き状態への再付与は、指定された各時計の残りと新しい持続の長い方を採用する。期限なしの状態を短い期限へ変えない。期限なしで再付与すると期限を外す。

`statusDurations[id]` に残り `steps`／`turns` を保存する。状態定義の `duration` が標準値で、`status.apply` やトラップの状態指定に `duration` を置くと上書きできる。両方を持つ場合は先に0になった時計で解除する。

成功歩では既存の歩行ダメージ後に歩数期限を減らし、その後に進入トラップを処理する。その場で付与された異常の期限を同じ歩で減らさない。旋回、衝突、会話、転送、保存再開では歩数を減らさない。戦闘では敵味方のターン処理と継続ダメージを終えた時に、生存者のターン期限を減らす。環境で停止されている異常は期限も停止する。

## 解除と戦闘内外

1. `status.remove`、解毒など特定状態を対象にしたcleanseは該当IDと期限を消す。全解除は双方を消す。
1. 休息、施療、救助時の回復、レベルアップ時の全快は従来の状態解除と合わせて期限も消す。
1. 水のない場所で味方が炎術を使う乾燥と探索乾燥技能は、濡れを解除する。水中では再び濡れる。
1. 戦闘終了だけでは味方の状態を消さない。町や他区画へ移っても保持する。戦闘の敵の状態はその敵個体だけに属する。
1. 歩行による毒・呪いの継続ダメージではHPを1残す。戦闘の継続ダメージとトラップの直接ダメージでは戦闘不能になり得る。
1. 戦闘バフ `battle.buffs`、地形によるベクトル呪いの蓄積、迷宮の帰還封印は別の状態。共通の状態異常IDへ二重登録しない。

保存では既存のID配列に加えて任意の期限辞書を検証する。未知ID、重複ID、付与されていないIDの期限、0以下・範囲外の期限を拒否する。同じ内容版の従来の無期限状態には期限を後付けしない。

## 正本

追加状態の編集元は [config/dungeon-content.json](../../config/dungeon-content.json)、配布は [data/statuses.json](../../data/statuses.json)。毒の基礎定義は既存のコンテンツ生成原稿を引き続き使う。共通処理は [status-effects.js](../../src/core/status-effects.js)、戦闘は [battle.js](../../src/core/battle.js)、歩行は [engine.js](../../src/core/engine.js)。
