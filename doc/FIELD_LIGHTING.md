# セルごとの明るさとミニマップ

確認日2026-09-18、作品版1.14.0。歩行中の地形とミニマップを、同じセル照度0〜8で描画する。[実装イベント一覧](scenarios/EVENT_CATALOG.md)と[q001](scenarios/QUEST_Q001.md)を参照。

## 計算

光源とセル中心の直線距離を `d = hypot(x - source.x, y - source.y)`、照射半径を `r` とする。`d > r` なら0、範囲内なら `max(1, round(8 - 7 * d / r))`。半径0の場合は光源セルだけ8。光源中心8、外周1、範囲外0となる疑似円を作る。複数光源が重なるセルは最大値を採用する。

壁・閉じた物体扉・閉じたボクセル境界面で光を遮る。最初に当たる壁セルの表面は照らすが、その奥へは通さない。斜めの閉じた角からも漏れない。扉や地形の変更、光源の移動・点灯・消灯・燃料切れの後は現在の地形から再計算する。

## 光源

1. 携帯松明：火網の点灯状態・燃料・所持を確認し、プレイヤーの現在セルを中心に半径4で照らす。
2. 火網の固定火台：同じマップ・高さにある点灯中の火台。半径はfixturesのradius。
3. 配置物の壁灯：表示されており、現在状態がfire.litStatesに含まれる物体。半径はfire.radius。q001の油切れ・消灯済み壁灯は光源にならない。
4. 通常ダンジョンの灯油灯：火網のないマップではlightが正なら現在セルを中心に半径4。残量は点灯の有無を決め、半径内の分布は距離で決める。

照度は現在のマップ・高さの平面内で計算する。階段先や別の高さへの光の伝播は扱わない。光の見た目と、くらがり除けの有効範囲は別の計算である。通常の火で明るくなっても、くらがり除けの効果がない火では襲撃を防げない。

## 表示

`ViewModel.dungeon.lighting` はmax、current、levels、sourcesを持つ。`cells[y][x].illumination` は同じセル値。画面側で燃料やクエストIDから明暗を再判定しない。

歩行画面では壁面・床面をそれぞれのセル値で暗くし、現在セルの照度によって黒い画面レイヤーの不透明度を `0.65 * (1 - current / 8)` にする。8なら重ねず、0なら0.65。操作ボタンや会話、ミニマップはこの暗幕の外に置く。演出オフでも照明は維持する。

ミニマップの踏査済みセルは、照度0でも元の地形色の55%を残す。光が強いほど明るく暖色になり、セルの説明にも「明るさ N/8」を表示する。現在地の矢印は常に読める。未踏査セルは照明情報を表示せず、光源によって未発見の地形が漏れない。
