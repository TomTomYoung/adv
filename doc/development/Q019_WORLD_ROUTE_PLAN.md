# q019 底なしの計量器の現場接続前監査

第2版で現場の移動に未接続の82件の先頭。原稿は `authoring/catalog-q011-q020.mjs`、配布原本は `data/quests/q019.json`（Git blob `e011a8293529550cbec9fa4d9fff9e37b491b74d`）。同じ荷の朝と夕の荷札に異なる重量が載っている。ルチは秤を疑う。坑主は軽い時の重量だけを給金に使っており、坑夫たちは販売と同じ基準で支払うよう求めている。

## 原本の5経路

`replace` は原因を調べず秤を交換する。時間を置くと同じ袋の重さが新品の秤でも変わる。ルチが再調査を求め、contractで89G・54EXP。

`average` は調査の前に今後の朝夕二回計量を約束する。`dry → average` は水分による重さの変化を確認してから同じ契約を選ぶ。`dry → books → limit` は当時の記録に照らして不足額まで算定し、その表を残す。三つとも過去の返金は行わず、今後の賃金と販売を朝夕の平均でそろえる。compromiseで44G・57EXP。結末が同じでも、何を調べ、何が記録に残ったかが異なる。

`dry → books → settle` は基準石と密封した対照袋を量った後、別に取り分けた開放試料を乾燥させ、同じ試料を重量が一定になるまで繰り返し量る。保存試料、時刻、乾燥室と保管庫の記録を当時の賃金契約・台帳に照合する。確認できた期間の不足を算定し、一部が坑夫へ渡るのを見届ける。今後の賃金と販売には共通の乾燥重量単価を採用する。informedで69G・76EXP。残額と資料のない期間は未精算。

## 次に実装する区間

旧受注の現場は廃坑地下2層 (15,5)、調査点は (5,3)・(14,1)。新規受注では計量室で基準石と封を保った対照袋を扱い、別の試料だけを乾燥皿へ移す。乾燥室と湿った保管庫の位置、保存試料と朝夕の記録の保管者を実地図で確定する。重量が一定になった時点、当時の契約と台帳を照合した時点、確認可能な不足額を算定した時点、実際に一部を支払った時点を分ける。隊の所持金と坑夫への支払いを別々に扱い、返金と将来の契約を二重に実行できないことを保存・再開で検証する。
