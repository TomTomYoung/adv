# q027 花粉の身代金の接続前監査

[配布原本](../../data/quests/q027.json)のGit blobは `792e6694ba25446b64bfa2eaa213f89b4597d4c5` です。地下庭園2階の旧決着点は (15,5)、調査点は (1,8) と (3,13) です。門番花は香袋の香りに反応して閉じ、無臭の銀器を近づけても反応しません。

原本は4場面・8経路・3結末です。銀器を先に試す4経路、香袋から試す3経路、根を断つ1経路があります。香袋を横道に置いて荷車を通し、香袋も回収して届ける結末は81G・84EXPです。香料を残して運賃を計算し直す結末は52G・63EXPです。銀器だけを試して香料を残す、香りへの反応を確かめてその場に残す、横道に置いた後で回収を断るという違いがあります。根を断つと101G・61EXPで、次の季節に下草が失われます。

3編成・Lv3・現場開始・seed 1907で原本24試遊、保存再読込180回、基本編成で異なる28状態を確認しました。旧flow.visitの8経路と旧decision・reviewの各3結末も計14回完走し、保存再読込98回、守護兵戦2回でした。旧informedには手掛かり二つが要ります。旧契約の戦闘はcontractのみにあります。

次は荷車、銀器、香袋の所在を分け、花が閉じる前後、横道へ向いた時点、荷車の通過、回収・放棄の選択、届けた荷に応じた運賃を現場に接続します。観察した順序と実際に得た証拠を保存し、途中で帰還・全滅した場合も荷を二重に運ばないことを確認します。
