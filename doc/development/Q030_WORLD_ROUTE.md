# q030 根の向こうの朝

薬師のハナはq022「緑の眠り」と同じ人物です。地下庭園2階の薬草棚 (12,9) で住民と相談し、古い明かり取り (10,9)、反射鏡の置き場 (9,11)、地上の施療院裏の林へ移動します。地下にある鏡や梁の作業には、その場にいる一行だけが登場します。[現行原稿](../../authoring/editions/e2/story-q030.mjs)・[初版の原本](../../data/quests/q030.json)

天井を補強してから移転を保留すると、薬草棚で判断し直せます。楔と梁は残り、次に穴へ行くと固定を確認できます。鏡を運んでいる間は光は支柱に当たり続けます。穴へ固定すると光が移り、根が光を追って穴を抜けたところで81G・84EXPです。

避難では、住民とハナが地上まで同行します。苗床を引き受けた場合は一行が箱を運び、地上の林で苗を下ろして52G・63EXPです。人を先に逃がした場合は人数を確認して81G・63EXPとなり、苗床は地下に残ります。どちらの道でも避難先に着くまで庭は根に覆われません。化身戦は逃走不可です。敗北後は薬草棚で採光や避難に切り替えられます。勝利後はハナの空き瓶が残り、切り株から最後の薬を採って101G・61EXPです。

[専用68試験](../../tests/q030-world-route.test.mjs)で6旅程すべての帰還・全滅、移転保留5回、鏡・箱を運ぶ途中の救助、旧版の進行中の化身戦と報酬を検査します。[通常試遊](../../tools/measure-root-morning.mjs)では、保留0～2回を含む42経路を3編成・Lv3/4・受付／現場開始で試し、504回すべてクリアしました。歩数は0～190歩で、敗北・救助は0件でした。[画面検査](../../.github/workflows/q030-world-route.yml)は112種類のセーブをScene・Classicの幅390・1440で開きます。
