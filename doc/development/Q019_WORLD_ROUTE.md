# 第2版 q019 底なしの計量器

塩哭きの廃坑地下2層に計量室 (15,5)、乾燥室 (15,3)、湿った保管庫 (13,5)、記録室 (14,1)、給金窓口 (13,3) を配置した。28場面・32行動・16旅程。ルチは試料を扱う隊に同行し、坑主と坑夫たちは給金窓口にいる。旧受注の原本、地下の調査点、進行中の選択を保持する。

基準石を載せ直し、封を保った対照袋を朝の値と照合する。別に取り分けた開放試料は同じ乾燥皿を使い、同じ秤で六十目、乾燥後に五十目、再乾燥後に五十目を読む。その皿を夕方まで湿った庫に置き、五十五目に増えたことを確かめる。ルチが皿を運ぶ途中と各室の棚に置いた時点を区別する。新品へ交換する経路では、同じ荷印の袋を朝から保管・出庫まで追い、新しい秤でも値が変わった結果をルチが再調査票に記す。

過去の精算では、保存試料、乾燥票、出庫時刻、当時の契約、給金台帳がそろう一荷を特定する。朝の乾燥十斤と夕方に売った十二斤は同じ一荷。契約は売り札一斤五Gで六十G、実際の給金は五十G。不足十Gの算定、支払帳への記載、坑主から坑夫への六Gの引渡しを別の行動にした。未精算は四G。返金の原資は坑主が持ち、隊の財布は使わない。今後の単価は双方が乾燥一斤六Gに合意してから計量室へ掲示する。これらの数値は、既存原稿の一部返金を試遊で追えるようにした作中の一例である。

朝夕の平均を選ぶ三経路では、未調査、水分を確認済み、過去の不足額を算定済みという違いを保存する。各経路の原本の確定事項・結末報酬と、旧受注の本文・選択・完了後の保存を照合した。[原本と旧受注](Q019_WORLD_ROUTE_PLAN.md)。

専用88試験が成功。3編成・Lv1と2・受付と現場開始の60試遊が完走し、移動は4～127歩、通常戦闘0～4回、敗北・救助0。画面検証は32の途中状態、16旅程の救援後、27場面の救援後、旧受注3状態を対象とする。[試遊画面](https://tomtomyoung.github.io/adv/quest-party-playtest.html?edition=e2&quest=q019&party=balanced&level=2&start=site&outcome=informed&seed=1907)。
