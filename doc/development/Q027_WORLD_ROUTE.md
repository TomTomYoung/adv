# q027 花粉の身代金

地下庭園2階の門前の荷置き場 (15,5)、門番花の敷居 (15,6)、横道の石棚 (15,9)、門外の荷受け場 (13,7) を歩きます。原本8経路・3結末を20場面・26行動・12旅程に接続しました。採集人のノムはq024と同じ人物です。ノムと商人は荷車に付き添い、試験や香袋の回収に出た一行の場面には登場しません。[現行原稿](../../authoring/editions/e2/story-q027.mjs)・[配布原本](../../data/quests/q027.json)

荷を分けて試すと、銀器で動かなかったこと、香袋で閉じたこと、引くと開いたことがそれぞれ観察時に記録されます。銀器だけを試して香袋を預ける場合と、香りへの反応まで見て預ける場合は、同じ棚に袋があっても得た証拠が異なります。香袋を横道の石棚に置くと花が横を向き、袋をそこで回収するまで香りが残ります。

荷車と二人を敷居まで運び、後輪まで門外に着いた時に通過を記録します。香袋を回収し、銀器とともに荷受け場に渡し、匂いを荷札に記すと81G・84EXPです。香袋を荷置き場に預けた場合も、通過後に横道からの回収を断った場合も、銀器の運賃で精算して52G・63EXPです。根を断つ経路は開通を知らせて101G・61EXPです。荷は荷車に残り、花粉を失う下草への影響は翌季に出ます。

[専用42試験](../../tests/q027-world-route.test.mjs)では、12旅程それぞれの帰還・全滅、現場での救助、袋・銀器・荷車と二人の所在、旧受注の命令と報酬を確認します。[通常96試遊](../../tools/measure-pollen-ransom.mjs)は3編成・Lv3/4・受付／現場開始で1～118歩、敗北・救助は0件でした。[Chromium検査](../../.github/workflows/q027-world-route.yml)では81種類の保存をScene・Classic、幅1440・390で開き、本文・出演者・選択肢を照合します。
