# q030 根の向こうの朝の接続前監査

[配布原本](../../data/quests/q030.json)のGit blobは `2376d0e7f0ecad59868e42ddc4f628abdcba64f2` です。薬師のハナの依頼です。地下庭園2階の旧決着点は (12,9)、調査点は (5,4) と (7,9) です。1階 (1,3) のダンジョン操作もこの原本にあり、引き続き使います。根は日光に向かって伸びます。進路には庭を支える古い天井があります。

原本は3場面・4結末です。天井を補強し、鏡で光を導いて根の向きを変えると81G・84EXPです。避難では薬草の苗床も地上へ運ぶ場合は52G・63EXP、住民だけを急いで逃がす場合は81G・63EXPです。根の化身を倒して成長を止めると101G・61EXPです。移転を保留して開始場面に戻り、採光・移転・戦闘を選び直す経路もあります。

保留から戻る回数を0～2回に区切った42経路を3編成・Lv3・現場開始・seed 1907で試遊しました。原本126試遊・保存再読込2,041回、基本編成で異なる224状態、戦闘21回です。旧flow.visitの42経路と旧decision・reviewの各3結末は計48試遊・保存再読込724回、戦闘11回でした。旧decision・reviewのinformedには手掛かり二つと戦闘勝利が必要です。根の化身の戦闘はboss_3で、逃走操作は拒否されます。

追加試遊では、補強から移転を保留し、再び移転を選んだ時点で全滅させました。町で保存して現場に戻ると移転の選択から再開し、住民だけを先に逃がす結末へ進めました。化身戦で全滅した場合は開始場面から再開し、補強・採光の結末に切り替えられました。

次は、補強済みの穴、鏡の所在と光の向き、住民と苗床の移送先を別々に保存します。保留を繰り返しても補強や避難を二重に計上せず、住民だけを逃がした場合に苗床が地下へ残ること、化身を倒す前後で採薬の結果が早まらないことを確認します。
