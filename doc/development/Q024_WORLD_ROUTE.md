# q024 食べられる地図

地下庭園1階の荷置き場 (15,5) と三つの分岐 (17,5)、(10,11)、(5,8) を歩いて往復します。各分岐は三方向に歩ける既存の床です。ノムは荷置き場に残り、初めての採集人は調査に同行します。[原稿](../../authoring/editions/e2/story-q024.mjs)・[配布原本](../../data/quests/q024.json)

荷置き場で虫を草に移してから薬で葉を固めると、先へ歩かずに今朝の地図を返せます。報酬は101G・61EXPです。

生きた葉を借りると、一地点目は低い側、二地点目は高い側の線が残ります。新しい分岐に着いたこと、来た道を道標に写したこと、そこで虫の食跡を観察したことを別々に保存します。三地点目で花粉との関係を確かめると、葉に凡例を書けます。一行は通った分岐を逆順に戻り、ノムに葉を返します。ノムが古い写しに日付を記すと81G・84EXPです。

三地点のどこから引き返しても52G・63EXPです。帰路図には荷置き場から最初の分岐までの道と、そこから確認できた0・1・2区間だけが残ります。同行者が荷置き場へ戻った後に帰路図を渡し、生きた葉はノムへ返します。

[専用28試験](../../tests/q024-world-route.test.mjs)では6旅程それぞれの途中帰還と全滅、観察・道標・引渡しの前後の保存再読込、凡例の早期作成の拒否、旧受注の途中からの再開を確認します。原本の5経路・3結末を16場面・21行動で扱います。[通常試遊](../../tools/measure-edible-map.mjs)は3編成・Lv3/4・受付／現場の全60件を0～88歩で完走しました。敗北・救助は0件です。[Chromium検査](../../.github/workflows/q024-world-route.yml)は50種類の保存をScene・Classicの幅1440・390で開きます。本文、人物、選択肢、スマートフォン幅で選択肢を全文読めることを検査します。
