# q023 母樹の指輪の現場接続前監査

[配布原本](../../data/quests/q023.json)の Git blob は `db74be2efebaaec6ff96d541621af216420d9143` です。旅人アセが取り戻したい母の指輪は、地下庭園の根の成長を測る標識です。広がった根が天井の支柱を押しており、母の目盛と今回の実測を比べて崩落の危険に気づきます。

## 原本の分岐

すぐに根を切る `cut` では指輪はアセに戻り、通路の膨らみを知らせる最後の印は失われます。原本のこの経路に戦闘はありません。報酬は101G・61EXPです。

複製を渡す結末は52G・63EXPで、到達経路が三つあります。最初から写しを作る `replica`、太さと目盛を写した後にアセへ知らせる `measure → leave`、住民への警報と測定記録の伝達を済ませてから本物を残す `measure → notice → keep` です。どの経路でも本物は根に残ります。誰が警告を受け取ったかは経路で異なります。

`measure → notice → remove` では、避難案内が出て測定値が保管された後、根を傷めず本物の指輪を外します。指輪と記録はアセに届き、庭園に測定標が残ります。報酬は81G・84EXPです。告知を済ませただけで住民全員の避難完了とはしません。

## 基準試遊と既存の地図

原本3場面の5経路を基本・継戦・探索の3編成、Lv3、現場開始、seed 1907で15回完走しました。開始時・操作後に90回、保存の妥当性と再読込直後の再保存一致を確認しました。基本編成では重複を除いて16状態です。旧 `flow.visit` の5経路、旧 `decision`・`review` の各3結末も計11回完走し、68回の保存再読込を確認しました。旧contractには各1戦があり、旧informedには二つの手掛かりが必要です。

地下庭園1階の旧決着点は (13,7)、旧調査点は (5,3)・(13,2) です。既存の床を四方向にたどると、決着点から各調査点まで26歩・35歩、出口 (1,1) までは22歩です。3地点にはそれぞれ旧q023のイベントがあり、既存イベントと新規イベントの表示は受注時の経路に合わせて切り替えます。

## 次の実装

指輪の原物・写し・根の目盛・測定記録の持ち主を分けます。実地測定、住民への警報、避難案内の掲出、代わりの測定標を残す作業、指輪の取り外しとアセへの返却を別々に保存します。根を切る経路では失われた印が復帰しないこと、複製の3経路では既に伝えた警告と記録が帰還・全滅後も保たれることが検証対象です。
