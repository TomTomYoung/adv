# q052 幽霊の競り札の接続前監査

競売人のウメの依頼です。誰も座っていない席で、売主の最低額を下回る時だけ先代の自動札が上がります。[配布原本](../../data/quests/q052.json)のGit blobは `3f5b2eb784ee922f18da9859476fa2889170a97a` です。眠れる地下市場1階の決着点は (11,9)、旧調査点は (7,1) と (14,1) です。

原本の9経路を3編成・Lv6・現場開始・seed 1907で試し、27試遊・99回の保存再読込を完了しました。倉庫開放は137G・82EXP、自動札を止めて最低額を掲示する決着は117G・108EXP、予算上限を掲示して札を使う決着は76G・81EXPです。原本の9経路では戦闘はありません。別の品での観察は一度だけ可能です。観察直後に全滅し、町で保存して現場へ戻ると、再観察を使い終えた入札場面から再開し、上限試験を経て自動札を停止できました。

旧decision・reviewからの6試遊では、16回の保存再読込と4回の戦闘を確認しました。旧informedは手掛かり二つ・縄1本・戦闘を要し、旧contractも戦闘を経ます。次は現在の札の稼働状態、出品者の最低額、買い支え予算の上限、掲示と倉庫開放を個別に保存します。二度目の出品の観察後に救助されても再観察が増えず、札を止める前に倉庫や掲示の状態が変わらないことを照合します。
