# q026 実らない約束

地下庭園2階の果樹の列 (17,3)、買主の畑 (15,3)、隣の果樹 (13,3)、苗床 (17,5) を歩きます。レイ、買主、隣の木の持ち主はそれぞれの木に留まります。原本の5経路・4結末を19場面・23行動・7旅程に接続しました。[現行原稿](../../authoring/editions/e2/story-q026.mjs)・[配布原本](../../data/quests/q026.json)

台木を薪にしてレイに渡すと101G・61EXPです。隣の木から穂を分けてもらい、レイの台木に接ぐと52G・63EXPです。最初から隣の持ち主を訪ねた場合と、買主から条件を聞いて断った場合を保存で区別します。どちらも元の穂は買主が持ち続けます。

元の穂は苗を育てる約束をしてから買主に返してもらえます。約束を交わした時点、受け取った時点、運び終えた時点、台木に接いだ時点を別々に保存します。接ぎ口の確認と苗の世話をレイが引き受ける結末は81G・63EXPです。一行が引き受けた場合は苗床に種をまき、翌季まで手入れを続け、苗床で苗を、台木で新芽を確認すると81G・84EXPです。苗は受け渡しの日まで苗床に残り、果物の収穫はさらに先です。

[現行経路の試験](../../tests/q026-world-route.test.mjs)と[旧受注の試験](../../tests/q026-legacy-route.test.mjs)は計31件です。全旅程の帰還・全滅後の再開、現場での救助、穂と約束の所在、旧命令列の手掛かりと縄の消費時点、報酬の一回性を照合します。[通常試遊](../../tools/measure-orchard-promise.mjs)は3編成・Lv3/4・受付／現場開始の60件を0～76歩で完走し、敗北・救助は0件でした。現場開始の薪の経路はその場で完結します。[Chromium検査](../../.github/workflows/q026-world-route.yml)は51種類の保存をScene・Classicの幅1440・390で開き、本文、人物、選択肢を照合します。
