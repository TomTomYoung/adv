# q023 母樹の指輪

地下庭園1階の母樹 (13,7)、アセの休み場 (13,2)、住民の通路口 (5,3) を接続しました。原本の5経路を17場面・21行動・7旅程に分けています。アセと通路当番は各自の持ち場に留まります。[物語原稿](../../authoring/editions/e2/story-q023.mjs)・[配布原本](../../data/quests/q023.json)

根を切ると、母が刻んだ比較の目盛を失います。輪を拾い、休み場でアセへ渡すと101G・61EXPです。測ってから住民に知らせる経路では、当番への警告、通路台帳への転記、避難案内の掲出を別々に保存します。元の高さに杭を据えてから、根を傷めず指輪を外します。休み場で指輪と手帳を渡すと81G・84EXPです。通路の台帳と新しい杭は現地に残ります。

複製を渡す3経路の報酬は52G・63EXPです。すぐに写しを作ると、誰にも実測値を伝えていません。根を測ってアセにだけ知らせる経路では、住民はまだ警告を受けていません。案内を出してから写しを選ぶと、住民の台帳に実測値が残ります。いずれも本物が根元にあり、アセが受け取るのは写しです。

[専用試験](../../tests/q023-world-route.test.mjs)では全7旅程の途中帰還・全滅後の再開、現場作業後の所在・所持、旧受注の各途中保存、旧 decision・review の手掛かりと戦闘条件、報酬の一回性を検査します。[通常試遊](../../tools/measure-mother-ring.mjs)は3編成・Lv3/4・受付/現場からの全60件を35～129歩で完走し、敗北・救助は0件でした。[Chromium検査](../../.github/workflows/q023-world-route.yml)では47種類の保存をScene・Classicと幅1440・390で開き、本文、選択肢、出演者を照合します。
