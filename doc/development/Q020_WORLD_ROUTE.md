# 第2版 q020「坑道の王冠」現場接続と検証

2026-11-19。原本は [q020.json](../../data/quests/q020.json)、接続前監査は [Q020_WORLD_ROUTE_PLAN.md](Q020_WORLD_ROUTE_PLAN.md)。実装正本は [story-q020.mjs](../../authoring/editions/e2/story-q020.mjs)、配布版は [e2/q020.json](../../data/scenario-editions/e2/q020.json)。初版の原本・スクリプト・結末報酬は変更していない。

## 原本と現場

原本6経路・3結末を、29場面・35行動・21旅程へ展開した。実作業の場所は廃坑地下2層の防柵 (17,3)、地上側入口 (17,1)、奥の危険支柱 (11,1)、枝坑 (17,9)、巡回地点 (17,7) と、地上の搬出口・組合の交代受付・資料室。既存の地下マップの床タイルを変更せず、物語イベントと第2版の町施設で接続する。

坑夫のメルは依頼の代表だが、同時受注できるq011「塩の花嫁」の入口にいるメルを、地下2層へ重複配置しない。q020ではメルの依頼書と組合からの連絡を扱う。前任者、受付係、番兵二体は、同席・同行・地上での休息を別々の所在として保持する。

## 交代と現物引継ぎ

交代の申出、受付での正式受理、防柵へ戻る、王冠・鍵・監視簿・補修図の受取り、前任者の地上退避は独立した行動。申出と受付だけでは旧責任者は去らず、現物の保持者は変わらない。正式引継ぎをした経路では、補修前に持った王冠と鍵を二度受け取らない。組合の交代記録・現物・前任者の所在・閉鎖状態が一貫するよう、不変条件と一回限りの行動履歴を使う。

## 調査・補修・開放・閉鎖終了

入口と奥の支柱を個別に検査する。地上側の入口を補強して退路を確保したあと、奥の危険支柱を交換し、さらに不要な枝坑を閉鎖する。各工程の途中では `exitOpen=false` を維持する。三つの施工記録が揃ってから人数制限付き開放とし、組合で終了記録を受理させ、資料室で王冠・鍵・監視簿・補修図を現物返納したときに `roleEnded=true` を確定する。補修後も返納前に役目が完了したことにしない。

番兵二体との強行戦闘は既存 `boss_2` を使用し、勝利後にのみ `guardsDefeated=true` となる。勝っただけでは防柵を破らず、次の操作で `opening=forced` と `exitOpen=true` を確定する。この場合 `limitedTraffic=false`、補修・記録更新は未了で、前任者は王冠を保持したまま危険坑道へ戻る。敗北時は番兵未撃破・防柵閉鎖・王冠の前任者保持を維持する。

**範囲の区別**：本変更は物語イベントの進行、各現場への実移動、開放状態を実装したもの。予備出口から他マップ・地上への新しい汎用通過ショートカット（`world.cross` など）の開通制御は含めていない。通行可能な避難路の物語上の状態と、既存の一般出入口・ワールド移動コマンドを混同しない。新しい相互通過ルートが必要なら、別途地理・通行規制・帰路・旧保存を実装して検証する。

## 6経路と報酬

- `relieve → recruit`：一日監視・後任募集、compromise 44G/57EXP。
- `relieve → repair → shift`：正式交代後の調査と一日監視、compromise 44G/57EXP。
- `supports → shift`：責任者同行の調査後に正式交代、一日監視、compromise 44G/57EXP。
- `supports → brace`：責任者同行の調査後、入口・奥・枝坑の補修と返納、informed 69G/76EXP。
- `relieve → repair → brace`：交代・退避後に図面を使って補修し返納、informed 69G/76EXP。
- `fight`：番兵に勝った後、防柵を強制開放し補修を残す、contract 89G/54EXP（戦闘報酬とは別）。

旧 `flow.visit` と旧 `decision`・`review` の保存済み進行は、原本の命令列と戦闘条件を維持する。新経路へ自動変換しない。既に受注した依頼の報酬は一回のみ。
