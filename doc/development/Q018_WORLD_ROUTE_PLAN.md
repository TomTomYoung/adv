# q018 白い借金の現場接続前監査

第2版で現場の移動に未接続の83件の先頭。原稿は `authoring/catalog-q011-q020.mjs`、配布原本は `data/quests/q018.json`（Git blob `26ed5509ac73ed7853ef0db8f10e41f0b0e997a5`）。質屋のオウが、水に溶ける借用証の回収を頼む。借り手は最後の返済金を用意しており、返済役人が受理と原本の失効を記録する。3場面・7行動・6経路・3結末である。

## 六つの経路と確定点

1. `seize`（contract、89G・54EXP）。返済前に回収した塩板をオウへ渡す。オウは儀礼に来ず、借り手の金は未受理。原本を使って残額と延滞金を請求し、家に再び赤札が付く。完済は成立しない。
1. `copy → dissolve`（informed、69G・76EXP）。時刻と金額を確認したあと、双方の立会いで最後の支払いを受理し、紙に完済印と立会人を記録する。塩板を川で溶かし、オウに写しを届ける。
1. `both → dissolve` と `both → split`。先にオウを川辺に呼ぶ。協議に入った時点で返済金はまだ未受理。決めた方法に従い入金を受け付け、紙の記録を作り、塩板を溶かすか二分する。
1. `copy → meet → dissolve` と `copy → meet → split`。協議に入る前に役人が支払いを受理している。再開後も再徴収しない。溶解ならinformed、二分ならcompromise（44G・57EXP）。

二分では板全体に完済線を刻み、その線で割った二片を借り手とオウに一片ずつ手渡す。紙の記録も双方に渡す。溶解では塩板が失効して写しが残る。支払うのは借り手が用意した金であり、隊の所持金と原本の結末報酬は別に扱う。オウの所在と意思、役人が実際に受理した時点、原本・二片・紙の受領者を別々に保存する。

## 原本と旧受注の検証

第2版・現場開始・Lv1・seed1907。全6経路を基本・継戦・探索の3編成で完走した。18試遊とも現在は0歩。本文・選択・完了にまたがる138回の保存再読込で、直後の再保存が一致した。基本編成の重複を除くと24状態だった。

さらに旧 `flow.visit` の7試遊では、旧選択 `call` で儀礼から協議へ、`stamp` で協議から儀礼へ戻る往復を含め、途中保存から3結末に到達した。旧 `decision` と `review` は各3結末を確認。どちらもcontractで `guard_2` との戦闘が1回発生し、informedにはdecisionで手掛かり二つ、reviewで最初の手掛かりが必要。これらは旧受注で再開する動作である。

従来の現場は廃坑地下2層 (13,7)、調査点は (2,7)・(9,6)。原稿の儀礼は川辺で行われる。既存施設名を確認した範囲では川辺・返済窓口・質屋に対応する地点はない。地上の搬出口から川辺と町の質屋へ行ける配置を検討し、オウを呼びに行く往復と、役人が待つ場所を定める。地上の旅道具店は一般の補給施設なので、オウの既存店舗として扱わない。試遊の現場開始は町のシーンにも対応している（`src/application/quest-playtest.js` の `nextQuestPlace` と `arriveSettlement`）。新規受注は川辺から始められ、旧受注では従来の迷宮内の起動地点を維持する。
