# q017 二度掘られた墓の現場接続前監査

原稿は `authoring/catalog-q011-q020.mjs`、配布原本は `data/quests/q017.json`（Git blob `4c97150150181e98b8d6931b0847bdfd30e42def`）。2場面・5行動・4経路・3結末。地上には救助坑から戻った遺骨を納めた墓、地下には仲間たちが遺体未回収の時点で弁当箱を納めた墓がある。遺骨の所在は最初から地上で固定し、それを登場人物がいつ確かめるかを別に記録する。

## 原本の4経路

1. `family → both`（informed、69G・76EXP）。地上の埋葬記録と救助坑の回収記録を照合し、地下にあるのは弁当箱だけだと確認する。遺族と相談し、空墓の由来と建立者の名を地下に刻む。元の弁当箱は地下墓に残り、家族がそこへ花を供える。
1. `remove`（contract、89G・54EXP）。記録と中身の照合後、弁当箱を建立した仲間に返して地下墓を撤去する。移すべき遺骨は地下にない。遺族との相談も銘文の刻字も行わない。
1. `box`（compromise、44G・57EXP）。地下墓を開け、仲間の了承を得て元の弁当箱を家族に届ける。地下に遺骨がないことは分かるが、二つの記録は未照合で、遺骨が地上にあることまでは確認していない。
1. `family → box`（同じcompromise）。こちらは記録をすでに照合し、地上の遺骨の所在を把握している。その知識を保持して弁当箱を遺族に渡す。二つの受渡し経路とも刻字と撤去は行わず、後で仲間たちが置く共同の弁当箱は、遺族が受領した当人の弁当箱と区別する。

`peersConsent` は元の弁当箱を遺族へ持ち出す了承、`familyConsulted` は二つの墓をどう残すかについての相談を表す。品物を手渡すために家族と会っただけでは、後者を確定しない。

## 地点と作業の設計

既存の決定点は廃坑地下2層の (11,9)、調査点は (1,8) と (12,3)。地下墓の候補は従来の決定点、建立した仲間の作業場所の候補はその北2歩の (11,7)。間の (11,8) と (11,7) は既存オブジェクトのない通行可能床である。地上では灯帰りの礼拝堂に坑務記録窓口と遺族の照会室がすでにある。地上墓地と埋葬記録の保管場所は次工程で定め、既存の窓口と回収記録の原本の所在を照合する。

地上墓の記録を読む、救助坑の回収記録を入手する、二つの日付を照合する、地下墓を開いて中身を確かめる、建立した仲間の証言を聞くという作業に分ける。原稿で中身を見せると申し出た墓守、空墓を築いた仲間、地上の埋葬を知る家族は、発言と所在を区別する。地下の墓守が家族の同意を代行する演出や、地下と地上に同じ人物が同時に現れる表示を作らない。弁当箱については持ち出しの了承・現物受領・運搬・引渡しを追う。刻字する経路では遺族との相談、建立者と銘文の確認、地下墓での刻字と献花を分ける。撤去する経路では遺骨の所在確認と原物の返却を先に行う。移動中の帰還・全滅と保存再読込で、取得した記録・了承・弁当箱の保持者を保つ。
