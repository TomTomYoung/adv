# q029 赤い蜜の契約の接続前監査

[配布原本](../../data/quests/q029.json)のGit blobは `f0d6a3e935e5a0b3ecac5ff566c7f2c319873870` です。養蜂家のミナの依頼です。地下庭園2階の旧決着点は (10,11)、調査点は (5,3) と (13,2) です。買主の契約は樽一杯ですが、赤い蜜は蜂の越冬用です。花期の札を見て買主と話すと、契約に記した開花時期が一季ずれていたことが分かります。

原本は3場面・3結末で、買主との納期相談と少量採取の間を何度でも往復できます。巣の備蓄を残し、売約先に事情を説明して納期を改めると81G・84EXPです。少量の赤い蜜に、別の養蜂家から15Gで買った代替蜜を加えると52G・63EXPです。少量の蜜を巣に返して納期相談に戻る選択もあります。女王の護衛を倒して契約量を採ると101G・61EXPです。

返却0～2回を含む12経路を3編成・Lv3・現場開始・seed 1907で試遊し、36試遊、保存再読込388回、基本編成で異なる54状態、護衛戦3回を確認しました。旧flow.visitの同じ12経路と旧decision・reviewの各3結末は計18試遊、保存再読込164回、守護兵戦3回でした。旧decision・reviewのinformedには手掛かり二つが要ります。

別途、14Gでの購入拒否と資金不足の保存、15Gを用意しての再開を確認しました。購入は一度だけ課金され、15Gから払って報酬を受け取った後の所持金は52Gでした。護衛戦で全滅して町で保存し、現場に戻ると選択前の場面で再挑戦でき、勝利後に契約を完了できました。

次は、巣に残る越冬用の蜜、一行が預かる少量、購入した代替蜜、納品した量を個別に追跡します。返却を繰り返せる接続、買主が認めた誤記、売約先の合意、護衛戦の敗北・逃走、資金不足で戻った際に採取や購入が重複しないことが検証対象です。
