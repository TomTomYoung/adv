# q022 緑の寝息

薬師ハナが見守る採集者は、根喰みの地下庭園で腕を負傷し、眠っています。新しい第2版では、誰が患者と行動しているか、傷を洗ったか、包帯を巻いたか、いつ担架から降りたかを保存します。原本は[第1版の配布データ](../../data/quests/q022.json)、第2版の編集元は[物語原稿](../../authoring/editions/e2/story-q022.mjs)です。

## 6経路で起きること

自然覚醒の経路では、現場 (11,9) からハナと採集者を洗浄足場 (11,7) に運びます。洗浄と包帯は別の作業です。最初は血が滲み、次の検温で熱が下がって傷口が閉じ始めます。二度目に胞子が離れ、本人の指が動きます。ここで目を開けるまで待つと、ハナが担架を引き取り、隊は歩く本人に肩を貸して灯帰りの治療所へ戻ります。採集袋に「治療中」の札を結んで完了し、81G・84EXPを受け取ります。

担架で運び続ける機会は計4通りあります。すぐに運ぶ場合と、包帯を巻いてから検温0回・1回・2回のいずれかで搬送に切り替える場合です。移乗場所 (9,7) で胞子の試料をハナへ渡し、眠っている本人と一緒に治療所へ戻ります。包帯と検温回数が保存され、いずれも52G・63EXPです。

強制覚醒の経路では、患者とハナを現場に残して菌床 (9,6) に行き、守護兵二体と戦います。逃走・敗北後も再戦できます。勝利後は現場へ戻り、胞子を払って起こします。患者は支えられて歩き、治療所で傷の熱が戻ったことを確かめます。依頼報酬は101G・61EXPです。

## 保存と表示の検証

14場面・18行動・8旅程。各旅程の途中帰還と救助、現場作業後の救助と再訪、検温0～2回での保存再読込、自然覚醒前の選択制限、戦闘後の再戦、試料・包帯・担架の持ち主、同席する人物、依頼報酬の一回性を検査します。菌床で戦う間は負傷者とハナを表示しません。

受注済みの旧経路は旧命令列で再開します。旧 `flow.visit` は原本の6経路を維持します。さらに古い `decision` と `review` の informed には手掛かり二つ、縄1本、守護兵戦が必要です。縄を消費するのは前者が戦闘前、後者が勝利時です。それぞれの資材不足で保存し、補給後に元の命令列を再開して完了できることも検査します。[旧経路試験](../../tests/q022-legacy-route.test.mjs)

[専用試験](../../tests/q022-world-route.test.mjs)のほか、[通常試遊](../../tools/measure-green-sleep.mjs)は3編成・Lv3/4・受付/現場の両方から原本6経路を通ります。72条件が18～46歩で完走し、敗北・救助は0でした。[Chromium検査](../../.github/workflows/q022-world-route.yml)は通常の途中保存25件、各旅程で救助後に到着した8件、作業場面で救助後に戻った13件、旧受注の4件について、Scene／Classicと幅1440／390で本文と人物・選択肢を検査します。
