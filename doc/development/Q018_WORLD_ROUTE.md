# 第2版 q018 白い借金

灯帰りの搬出口の下に川辺と返済窓口があり、倉庫通りからオウの質屋と借り手の家に行ける。新規受注は川辺から始まる。20場面、26行動のうち9行動で実際の施設間を移動する。

借り手の最終返済金を役人が受理した時点と、塩板が失効して債務が終わる時点を区別する。先に支払ってからオウを呼んだ場合、協議の後は受領欄を確認する。先にオウを呼んだ場合は、協議の後に支払う。隊の所持金から返済金を引かない。

溶解では借り手・オウ・役人が川辺へ下り、板が溶けた後に双方へ紙の写しを渡す。二分では完済線を刻み、割った二片を役人が預かる。借り手へ渡した段階で中断しても、オウの一片と写しは役人の手元に残る。回収ではオウが受理前の原本を店で受け取り、自分の名で出した赤札を借り手の戸口に貼る。

[原本6経路・旧受注の検証記録](Q018_WORLD_ROUTE_PLAN.md)。[試遊画面](https://tomtomyoung.github.io/adv/quest-party-playtest.html?edition=e2&quest=q018&start=site&party=balanced&level=2&seed=1907&outcome=compromise)。

専用69試験で原本・報酬・旧保存・旅程途中および各作業中の救援を照合した。72通常試遊は全件成功し、施設間移動は6～14回、敗北・救助は0。45の途中状態、9旅程の救援後、19場面の救援後、旧受注4状態を、Scene／Classic・幅1440／390の計308画面条件で検証した。
