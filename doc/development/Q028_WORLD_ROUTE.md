# q028 庭師の空席

地下庭園2階の先代庭師の作業席 (8,13)、苗床 (11,13)、ユイの記録台 (14,13) を結びました。原本7経路・3結末を25場面・30行動・10旅程で扱います。ユイはq021と同じ庭師で、記録台に留まります。弟子は実演に同行し、最後まで手入れした場合は記録台でユイに説明します。[現行原稿](../../authoring/editions/e2/story-q028.mjs)・[配布原本](../../data/quests/q028.json)

弟子が水差しを入口側へ置き、二人で苗床へ行きます。乾いた土で刃を出しかけた時は、弟子が小刀を預かり、水差しを一行に戻します。苗は無傷です。制止、説明を受け入れること、水を注ぐことにはそれぞれ別の保存時点があります。水やりの後は席へ戻り、小刀、苗札の順に置きます。道具の配置がそろっても、苗をまだ剪定していない場合があります。

実演を完了する経路では、席で配置を写してから道具を苗床へ運び、剪定と札付けを順に行います。小刀は元の向きで席に戻り、実物の札は苗に残ります。弟子が説明し、ユイが言葉と配置を記録して81G・84EXPです。途中で保存する経路は、席の現状だけを伝えた場合、制止まで聞いた場合、水やりと道具配置を確認した場合で記録内容が変わり、いずれも52G・63EXPです。道具を箱に片付け、文字手順に統一する経路は101G・61EXPです。

[専用38試験](../../tests/q028-world-route.test.mjs)は10旅程それぞれの帰還・全滅、現場に残る道具、苗の状態、弟子の所在と説明、旧版の保存からの再開、報酬の一回性を確認します。[通常84試遊](../../tools/measure-gardeners-seat.mjs)は3編成・Lv3/4・受付／現場開始で6～97歩、敗北・救助は0件でした。[Chromium検査](../../.github/workflows/q028-world-route.yml)は80種類の保存をScene・Classicの幅1440・390で開き、本文・出演者・選択肢を照合します。
