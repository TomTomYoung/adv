# q020 坑道の王冠の現場接続前監査

現場の移動に未接続の81件の先頭。原稿は `authoring/catalog-q011-q020.mjs`、配布原本は `data/quests/q020.json`（Git blob `bdf14ee00b799bf5ec87085a692e12486879a7ea`）。廃坑の予備出口は防柵で閉じられ、組合の番兵二体が守っている。王冠は当番の職責標。メルが扱いたいのは、誰が出口を監視し、どこまで使える状態にしたかである。

## 原本6経路と3結末

`relieve → recruit` では交代を正式に届け出て、王冠・鍵・監視記録を引き継ぐ。前任者は地上へ休みに出る。次いで一日分の閉鎖監視と巡回を終え、翌日以降の交代者を募る。補修も開放も行わず、compromiseで44G・57EXP。

`supports → shift` は先に責任者の案内で入口と奥の支柱を調べ、それから正式に引き継いで一日務める。`relieve → repair → shift` は前任者がすでに地上へ出ている。交代した側が図と記録を読んで調査し、いったん引き継いだ鍵や王冠を二度受け取らずに勤務を続ける。どちらも出口は閉鎖を続ける。

`supports → brace` と `relieve → repair → brace` は、地上側の入口、奥の支柱、枝坑の順に作業を進める。補修後に人数制限付きの避難路として開き、常駐当番を終え、王冠と記録を資料室へ納める。informedで69G・76EXP。調査した時点で誰が責任者を務めていたかを二経路で区別する。

`fight` では番兵二体に勝ったとき初めて、防柵が破られて出口が開く。支柱は未補修。前任者は王冠を持って危険坑道へ向かう。contractで89G・54EXP（戦闘報酬とは別）。

## 保存・再開、旧命令列と敗北

原本3場面・7行動の6経路を基本・継戦・探索編成、Lv1、現場開始、seed1907で計18試遊した。移動は0歩で、戦闘は番兵と戦う経路のみ。開始時と各操作後の210回で保存が検証を通り、再読込した直後の再保存が一致した。基本編成の重複を除くと43状態。

## 次に実装する区間

旧現場は廃坑地下2層 (17,3)、調査点は (3,6)・(6,9)。既存の搬出口と地上の記録施設を照合し、予備出口の防柵、地上側の入口、奥の危険区画、閉じる枝坑、交代・記録の窓口の所在地を決める。通行できるようになった避難路と一般の出入口を地図上で区別する。

交代を申し出た段階、組合の記録が受理された段階、王冠・鍵・記録の引渡し、前任者の退避を分ける。先に交代した経路では前任者を調査へ呼び戻さない。補修の中断、監視中の帰還、番兵戦での敗北を、未成立の開放や重複した引継ぎを起こさず再開できるようにする。鍵の最終保管者は原本の完了状態と引渡しの描写を照合して決める。
