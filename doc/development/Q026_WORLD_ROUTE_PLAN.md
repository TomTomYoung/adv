# q026 実らない約束の接続前監査

[配布原本](../../data/quests/q026.json)のGit blobは `d57cbea352f6a8f8181bf5b411f56dedec243272` です。果樹番のレイの木は接ぎ木の台木です。実をつける枝を売った後も、台木は養分を送り続けています。地下庭園2階の旧決着点は (17,3)、旧調査点は (7,1) と (14,1) です。

原本は3場面・5経路・4結末です。台木を薪にすると101G・61EXPです。近くの木から別の穂をもらう経路は、最初から頼む場合と、買主の返還条件を聞いて断った場合の2通りで、どちらも52G・63EXPです。買主に代わりの苗を育てると約束した場合は元の穂を返してもらえます。元の穂を接いでレイに世話を任せる結末は81G・63EXP、翌季まで世話をして新芽と代わりの苗を確認する結末は81G・84EXPです。新芽と収穫は別の進行です。

基本・継戦・探索のLv3、現場開始、seed 1907で原本15試遊、開始時と各操作後の保存検証・再読込90回、基本編成で異なる16状態を確認しました。旧flow.visitの5経路と旧decision・reviewの各3結末も計11回完走しました。旧経路では保存再読込80回、守護兵戦4回です。旧informedには手掛かり二つと縄1本が要り、decisionでは戦闘前、reviewでは勝利時に縄を消費します。

次は台木、元の穂、別の穂、代わりの苗を区別して所在を保存します。売却先で聞いた条件、約束の成立、接ぎ戻し、世話の引き継ぎ、翌季の活着確認と苗の育成を現場に接続します。途中で帰還・全滅した場合も、既に渡った穂や成立した約束が二重に発生しないことが検証対象です。
