# q024 食べられる地図の接続前監査

[配布原本](../../data/quests/q024.json)のGit blobは `7628a9d46cdeb829f70a244357171e46bd9f0b71` です。虫が葉に描かれた道のうち花粉の濃い側を食べます。一つ目の分岐では低い方、二つ目では高い方の線が残るため、道の高さだけでは判断できません。

原本の2場面に5経路があります。初手で虫を取り除いて葉を薬で固めると101G・61EXPです。葉を持って歩き、残った線を0回・1回・2回たどった各時点で引き返すと52G・63EXPです。2回たどって三地点の食跡を比較した時だけ、食跡の読み方を凡例として残せます。報酬は81G・84EXPです。

通常経路5本を基本・継戦・探索のLv3、現場開始、seed 1907で15回完走しました。保存検査・再読込は114回、基本編成で重複を除くと18状態です。旧flow.visitの5経路、旧decision・reviewの各3結末も11回完走し、保存再読込76回、戦闘2回を確認しました。

地下庭園1階の旧決着点は(15,5)、旧調査点は(3,6)と(7,8)です。次は三地点の食跡、葉と写しの持ち主、地図に刻んだ確認済みの道、採集人の帰路を物理経路に接続します。途中帰還と全滅では観察済みの地点を保ち、三地点を比較する前は凡例を完成させないことが検証対象です。
