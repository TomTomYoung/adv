# q025 地下の雨乞い

地下庭園1階の歌場 (17,3)、上り口の当番札 (15,3)、天井の作業台 (15,1)、井戸 (17,7)、畑 (15,9) を接続しました。原本7経路・3結末を22場面・28行動・12旅程に分けています。歌い手は歌場、水運びのピノは井戸に留まります。畑の世話役は、作業台で次の当番を習う旅程で一行に同行します。[原稿](../../authoring/editions/e2/story-q025.mjs)・[配布原本](../../data/quests/q025.json)

一節目で弁を開けた水は井戸へ戻ります。畑は乾いたままです。井戸でピノと戻り水を確かめ、作業台に戻って二節目で開き直すことも、そこで手桶に替えることもできます。最初から二節目に合わせた場合と、開け直した場合のどちらも、畑で雨の浸透を確かめ、世話役と作業台へ戻ります。世話役が操作を習い、点検日を記すと81G・84EXPです。強引に開けた場合は畑の一角が水浸しになり、排水が必要な箇所を記録して101G・61EXPです。

手桶へ切り替える時点は祭の最初、当番札を読んだ後、作業台に上った後、一節目の誤操作を井戸で確かめた後の4通りです。水はピノがくみ、一行が受け取って運び、畝に注いだ時にだけ畑へ届きます。手運びを見た世話役が来年の当番に名乗り、52G・63EXPです。弁の操作を教えた履歴は正しい放水をした経路だけに残ります。

[専用42試験](../../tests/q025-world-route.test.mjs)は各旅程での帰還・全滅、現場作業後の救助と再開、人物・桶の所在、旧受注の命令列、報酬の一回性を確認します。[通常試遊](../../tools/measure-rain-song.mjs)は3編成・Lv3/4・受付／現場の84件を8～70歩で完走し、敗北・救助は0件でした。[Chromium検査](../../.github/workflows/q025-world-route.yml)は79種類の保存データをScene・Classicの幅1440・390で開き、本文、出演者、選択肢と幅390のSceneでの可読性を照合します。
