# q029 赤い蜜の契約

地下庭園2階の赤い蜜の巣箱 (10,11)、買主の契約台 (8,11)、隣の養蜂場 (12,11)、売約先の荷受け台 (13,9) を19場面・23行動・8旅程で結びました。ミナは巣箱、隣の養蜂家は養蜂場、荷受け人は荷受け台に留まります。買主は納期を説明する時に一行と売約先へ行き、署名後もそこで帳面を書き換えます。[現行原稿](../../authoring/editions/e2/story-q029.mjs)・[配布原本](../../data/quests/q029.json)

巣の蜜は、蜂が分けられる外縁の少量と、奥の越冬分に分けて所在を保存します。少量を持って隣の養蜂場に行き、買う代わりに巣へ持ち帰ることもできます。実際に注ぎ戻すまでは小瓶は一行の手元にあります。納期相談と少量採取は何度でも行き来でき、返却済みの蜜を重ねて受け取ることはありません。

巣に全量を残した場合は、買主と売約先が納期を改め、ミナが地下の暦を作って81G・84EXPです。購入経路は15Gの支払いと不足分の受領を同時に確定し、赤い小瓶と代替蜜を荷受け人に納めて52G・63EXPです。14Gでは支払いを保留でき、所持金を用意して同じ取引に戻れます。護衛戦の逃走・敗北では蜜は巣に残ります。勝利後に樽を満たして全量を納めると101G・61EXPです。護衛を退けた後に救助されても、空樽をまだ満たしていない時点から再開できます。

[専用42試験](../../tests/q029-world-route.test.mjs)は、全旅程での帰還・全滅、購入前後の残金と所在、旧版の金額不足・戦闘中の保存、5回続けた返却を含みます。[通常144試遊](../../tools/measure-red-honey.mjs)は返却0～2回を含む12経路、3編成、Lv3/4、受付／現場開始を組み合わせて5～115歩で完走し、敗北・救助は0件でした。[Chromium検査](../../.github/workflows/q029-world-route.yml)は資金不足、再開、護衛戦の逃走・敗北など98種類の保存をScene・Classicの幅1440・390で開きます。
