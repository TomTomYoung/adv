# q025 地下の雨乞いの接続前監査

[配布原本](../../data/quests/q025.json)のGit blobは `e404c3656c554f166aeecf3e47b4407f55acc4fc` です。水運びのピノの依頼では、祭の歌が天井の集水弁を動かす合図になっています。担当の引き継ぎが途切れたため、歌が合っていても雨が降りません。

原本は4場面・7経路・3結末です。弁をこじ開けると庭の一角が水浸しになり、101G・61EXPです。二節目で開けて次の当番に教える経路は81G・84EXPです。一節目で誤って開けた場合はいったん井戸へ水が戻り、二節目を聞き直せます。手桶へ切り替える時機は、最初、当番札を読んだ後、作業台に上がった後、弁を一度誤操作した後の4通りで、いずれも52G・63EXPです。

原本7経路を3編成のLv3・現場開始・seed 1907で21回完走しました。入力後の保存検証・再読込は開始時を含め150回で、基本編成の異なる保存は22件です。旧flow.visitの7経路と旧decision・reviewの各3結末は13回完走し、再読込88回、旧contractで各1戦を確認しました。

地下庭園1階の旧決着点は (17,3)、旧調査点は (4,5) と (3,13) です。次は歌い手、ピノ、作業台、井戸、畑を結び、弁を開いた節、実際に水が届いた場所、次の当番への引き継ぎを別々に保存します。手桶で終えた場合も、それ以前に見た当番札や井戸へ戻った水の履歴を残すことが検証対象です。
