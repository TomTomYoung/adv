# q051 釣銭のない店

眠れる地下市場1階の売台 (13,7)、共同食堂 (10,7)、市場出口の腰掛け (12,5) を結びました。依頼文で店主に精算を求める行商人のコノは売台に残ります。閉店後は店主が一行と食堂へ向かい、販売時に参加を選ぶ経路で売台へ戻ります。賄い役は食堂、初来店の客は腰掛けにいます。[現行原稿](../../authoring/editions/e2/story-q051.mjs)・[初版の原本](../../data/quests/q051.json)

店先で精算を求めた場合は、一行が預かった包みを客に渡して137G・82EXPです。閉店を待つと、常連が食べた一杯と、初来店の客がまだ使っていない釣銭の番号を帳面で照合できます。精算席を先に作った場合、客の包みは賄い役が預かり、食事か返金を選ぶ札は食堂に置かれます。報酬は76G・81EXPです。

未使用の釣銭を先に返した場合、客が受領してから一行が食堂へ報告します。届ける途中で全滅した時は一行が包みを持ったまま再開し、返金後に全滅した時は客が包みを持ったまま再開します。その後、コノが販売時の参加札を書いて売台に掲げれば117G・108EXP、食堂に精算席を作れば76G・81EXPです。返金済みの包みや常連が食事に使った分を精算席に戻すことはありません。

[専用26試験](../../tests/q051-world-route.test.mjs)で5旅程すべての帰還・全滅、受領後の再操作、旧版の精算方法選択と金庫の番獣との戦闘中のセーブを検査します。[通常試遊](../../tools/measure-change-counter.mjs)では4経路を3編成・Lv6/7・受付／現場開始で試し、全48回を3～48歩で完走しました。敗北と救助は0件です。[画面検査](../../.github/workflows/q051-world-route.yml)は35種類のセーブをScene・Classicの幅390・1440で開きます。
