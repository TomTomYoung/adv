# q051 釣銭のない店の接続前監査

行商人のコノの店では釣銭が閉店後の共同食堂への前払いになっています。常連は知っていますが、初来店の客には説明がありません。[配布原本](../../data/quests/q051.json)のGit blobは `1169dbd9f07708b40b6b1697dbeeea26b9c6cb10` です。現在の決着点は地域6の1階 (13,7)、旧調査点は (5,3)、(11,4) です。

原本の4経路を3編成・Lv6・現場開始・seed 1907で試し、12試遊と39回の保存再読込を完了しました。現在の原本では4経路とも戦闘はありません。自分たちで釣銭を取り戻すと137G・82EXP、閉店後に食堂の精算席を作ると76G・81EXPです。未説明分を返した後、販売時の参加札を作れば117G・108EXP、食堂の精算席を続ければ76G・81EXPです。同じ精算席の結末でも返金が先に済んだかどうかに違いがあります。

旧decision・reviewからの6試遊・14回の保存再読込では、返金だけを求めるcontractで2回、元の戦闘に入りました。原本のrefundで返金を済ませた直後に全滅し、町で保存して現場へ戻る追加試験では、consentから再開してdeskの結末まで進めました。

次は販売時、閉店後の精算、食堂での受け取りを現場に接続します。初来店の客への説明、申出を受けた返金、既に食べた客の前払い、食事か返金を選ぶ札の所在を区別します。返金後の救助で二重払いが発生しないこと、初版の戦闘が旧セーブで続くことを照合します。
