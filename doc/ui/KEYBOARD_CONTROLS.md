# 決定・キャンセル・十字キー

更新日: 2026-09-19。PR #29反映済みのmaster `59abddd`を起点に、ダンジョンの基準操作を修正しました。

## 共通操作

初期値はEnter・Spaceが決定、矢印キーが上下左右、Escapeが一段戻る操作です。ダンジョン探索中は上下で前進・後退、左右で方向転換、決定で足元・正面を調べます。会話・選択肢・戦闘・町・管理画面では矢印で有効なボタンを選び、決定で実行します。「記録 → キー設定」で主キー・副キーを変更できます。操作の意味と戻る順序は共通です。[キー設定仕様](KEY_CONFIG.md)を参照してください。矢印は本文・画像・無効な項目へフォーカスせず、ブラウザのスクロールを起こしません。選択先が一覧の外なら、その項目が見える位置へスクロールします。Tabとマウスも引き続き使用できます。

会話は「続きを読む」、選択肢は先頭の有効な項目、戦闘の各手番は先頭の有効な行動へフォーカスします。探索から会話・選択肢へ入った瞬間に方向入力の用途を切り替え、その間は移動しません。終了後は「調べる」にフォーカスし、矢印の直接移動へ戻ります。町や一覧では同じ画面の再描画後も選択を保持します。WASD移動とEの調査は探索中だけ使える補助です。

探索の決定は、移動・帰還・携帯品のボタンに以前のフォーカスが残っていても調査を始めます。補助的にTabで明示的なボタン移動へ入った場合は、そのボタンを決定できます。方向入力・キャンセル・再描画で探索の基準に戻します。決定キーの押しっぱなしで、調査や会話の確定を連続実行しません。

## 対象・装備・記録

戦闘は「行動を決定 → 敵または仲間を選択 → 決定」で実行します。対象を選んでいる間のEscapeは行動一覧へ戻ります。全体・自分対象の技能は対象の選択を省きます。対象を選ぶだけでは手番・MP・道具を消費しません。

道具・装備の仲間、転職先、交代相手、掲示板の絞り込み、記録画面の設定はボタンから候補一覧を開きます。矢印で候補を選び、Enterで反映、Escapeで変更せず閉じます。「職業・成長」もボタンで開閉します。再描画時には操作中の項目と開いていた詳細を保持します。

記録は枠を選んで保存・読み込みできます。保存後も同じ枠へ戻ります。新しい旅の確認からのキャンセルは記録画面へ戻り、再度キャンセルすると元の画面へ戻ります。文字入力、ファイル選択、音量の細かな調整には通常の入力操作も使えます。

## キャンセルの順序

最前面の候補一覧、開いた詳細、管理画面の順で一段ずつ戻ります。戦闘の対象選択に管理画面を重ねている場合は、その画面を先に閉じてから行動一覧へ戻ります。その後、町の親地点へ戻ります。記録・ヘルプが最前面なら、その内部から先に戻ります。町で繰り返すと最初の広場へ戻り、ダンジョンでは管理画面を閉じ、方向入力で直接移動できる探索状態になります。記録・ヘルプを閉じたときも同様です。最上位でキャンセルしても別の画面を開きません。

調査・帰還確認は既存の取消選択肢を実行します。シナリオは作者が用意した「中断」「探索へ戻る」の無処理の選択肢だけを取消先として投影します。安全な取消先がある確認画面は未読ページがあっても閉じられます。取消先のない本文・必須判断や強制戦闘をキャンセルで勝手に終了させません。逃走・帰還には通常の選択とゲーム側の判定が必要です。

## 責務と確認

ボタンの候補一覧、フォーカス、戦闘の未確定対象、詳細や管理画面の開閉はViewの状態です。既存のintentだけを送信し、キャンセルのために資源・乱数・セーブ形式を変えません。Applicationは取消可能な既存選択肢のIDを明示し、Viewは日本語のラベルから進行を推測しません。背景内表示と従来表示に同じ入力処理を適用します。

検証結果は[PROGRESS.md](../PROGRESS.md)、配置の仕様は[IN_SCENE_VIEW.md](IN_SCENE_VIEW.md)を参照してください。

## 固定メッセージ領域（1.15.0）

本文は決定で次ページ、最後のページから次の台詞・選択肢へ進みます。同じ本文に続く選択肢は最後の本文ページを引き継ぎます。安全な取消先を持つ確認は従来どおりキャンセルで閉じ、取消先のない会話では前ページへ戻ります。選択肢が右枠の外へ続いていても、方向入力で選んだ項目まで自動スクロールします。固定高さと人物の仕様は[CHARACTER_STAGING.md](CHARACTER_STAGING.md)。
