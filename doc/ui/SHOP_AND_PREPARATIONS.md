# ショップと旅支度

更新日: 2026-09-26。背景内表示・従来表示で共通の操作です。

## ショップ

町のショップへ移動し、「ショップを見る」から開きます。従来表示ではその場所にいる間だけ「ショップ」タブも表示します。旅支度には商品一覧を混在させません。

所持金はショップの上部に大きく表示し、一覧をスクロールしても見える位置に固定します。商品には名前・説明・装備枠・能力補正・価格を表示します。

品物を選ぶと、顔画像・名前・現在の職業が付いた仲間の選択肢を表示します。装備品は各人の「装備可」「装備不可」を示します。装備できない仲間も持ち運べます。購入した品物を自動装備することはありません。

選択中は価格と購入後の所持金を表示します。仲間を決定した時点で1個だけ購入し、その人の持ち物に入れます。所持金不足・隊全体の所持数上限・会話や戦闘中は購入できません。Coreでも店の所在・品物・相手・価格・上限を再検査します。「品物に戻る」やキャンセルではお金も品物も変わりません。

## 旅支度

管理メニューまたはタブの「旅支度」から開きます。最初に共通の袋と仲間の顔画像付きボタンを並べ、持ち主を選ぶとその人の所持品を表示します。

品物は説明・個数・装備枠・能力補正を確認できます。「使う」は対象の仲間を選んで実行し、選択中の持ち主から消費します。全員回復などの効果範囲は各品物の定義を使います。鍵・素材・迷宮専用道具には汎用の使用ボタンを付けず、探索や仕掛け側の操作を使います。

「渡す」は別の仲間または共通の袋へ1個ずつ渡します。複数所持している場合は「全部渡す」も選べます。受け渡しで隊の総数・ゴールド・歩数は変わりません。

装備品の「装備する」から顔画像付きの装備先を選べます。装備できない職業・倒れている仲間・外す品物の所持数上限を理由付きで表示し、実行できない選択肢を無効にします。装備先が持ち主と異なる場合はその品物を渡して装備します。交換して外れた品物は装備していた人の持ち物へ戻します。

個人の持ち物画面には現在の武器・防具・装飾品も表示し、「装備を外す」でその人の持ち物へ戻せます。探索中でも会話・戦闘のない状態なら着脱・受け渡しが可能です。会話・戦闘中は内容の確認のみです。待機中の仲間の装備回収は従来どおり町の隊画面から行えます。

方向入力で選択肢を移動し、決定で実行します。Escapeまたは設定済みキャンセルは相手選択から元の品物へ戻り、もう一度で管理画面を閉じます。相手選択だけではゲーム状態を変更しません。

## 所持品と保存の整合

`state.inventory` は従来のシナリオ・戦闘・材料判定が参照する隊全体の未装備品の総数です。非装備品の `state.carried[actor][item]` はその総数のうち個人が持つ個数です。差分が共通の袋であり、別の在庫を追加したわけではありません。

装備品は既存の `state.gear.items` にある個体を使い、未装備品の `holder` で持ち主を記録します。`holder` がない未装備品は共通の袋、装備中は既存の `gear.equipped` が所在です。受け渡し・着脱・転職では個体IDと腐食の塩状態を維持します。購入は新しい個体を作って指定された人へ渡します。

旅支度からの使用は指定した持ち主から消費します。戦闘・シナリオ・仕掛け・調合は隊の品物を共用でき、共通の袋を先に消費し、不足分を隊列順の個人所持品から消費します。報酬・調合生成物など、相手を指定しない入手品は共通の袋へ入ります。隊から離れる仲間の未装備品は共通の袋へ戻し、装備中の品物は本人に残します。

所在はセーブ対象です。読込時に保持者・種類・正の整数個数・総数超過・装備中との重複を検査し、不正な記録で現在の状態を書き換えません。同じ内容版で所在を持たない従来の記録は共通の袋として扱います。別内容版への移行を追加するものではありません。
