# ショップ・スキル屋と旅支度

更新日: 2026-10-24。背景内表示・従来表示で共通の操作です。

## ショップ

町の旅道具店へ移動し、「ショップを見る」から開きます。従来表示ではその場所にいる間だけ「ショップ」タブも表示します。購入画面には品物だけを並べ、技能の習得は広場の別施設「スキル屋」、容器改修・保管油は旅道具店の「補給・工房」で扱います。

所持金はショップ上部に固定します。商品一覧の各項目は品物名と価格（G）の組です。選んだ項目の説明・装備枠・能力補正を右側へ表示し、商品一覧と同時に確認できます。初期表示では先頭の商品を選びます。

下部には選択商品の購入先となるキャラクターカードを常時表示します。顔画像・名前・現在職に加え、装備可否、その品物の個人所持数、装備中の個数を示します。未装備の所持数と装備中の個数を合算しません。共通の袋の個数は商品詳細に表示します。商品・詳細は各領域内でスクロールし、狭い画面では下部カードを横にスクロールできます。

背景内表示では、ショップを「閉じる」の見出しを除いた実際の残り高さへ収めます。外側の本文をスクロールして見出しや購入先が隠れる構造にはせず、商品一覧・詳細・購入先カードの各領域でホイールとキーボードのスクロールを受けます。低いウィンドウでは余白とカードの寸法を縮め、商品一覧と購入先を同時に操作できる高さを確保します。

カードを決定した時点で1個だけ購入し、その人の持ち物に入れます。装備不可でも持ち運べます。購入による自動装備は行いません。購入後も選んだ商品・詳細・カードを表示し、ゴールドと所持数を更新します。所持金不足・上限・会話や戦闘中は購入カードを無効にし、商品説明は引き続き確認できます。Coreも店の所在・品物・相手・価格・上限を再検査します。

商品を決定すると購入先の最初の有効カードへフォーカスします。キャンセルはその商品へ戻り、もう一度で管理画面を閉じます。商品とカードを選び直すだけではゴールド・品物・歩数を消費しません。

## スキル屋

篝火広場の「スキル屋」へ移動し、「スキル屋を見る」から開きます。旅道具店とは別の町ロケーション `hikarigaeri_skill_shop` です。従来表示ではこの施設にいる間だけ「スキル屋」タブを表示し、技能の購入APIも現在地を検査します。

上部に技能宝石と習得人物の選択を置き、技能一覧だけを縦にスクロールします。人物選択が横幅に収まらない場合は、その列を横にスクロールします。各技能には説明・習得済みLv・次Lvの費用・購入できない理由を表示します。技能名だけの閲覧や人物の切替では宝石を消費せず、習得ボタンの決定時に消費します。購入条件と価格、人物別の習得履歴は[技能教習の仕様](../dungeons/EXPEDITION_IMPLEMENTATION.md#技能宝石と教習)を引き継ぎます。

選択人物と一覧の操作位置は再描画で保持し、背景内表示と従来表示を切り替えても選択人物を引き継ぎます。キャンセルで施設の画面へ戻り、次のキャンセルで広場へ戻ります。既存の旅道具店にいるセーブを読み込んでも位置を自動変更せず、広場を経由してスキル屋へ移動します。

## 補給・工房

旅道具店の「補給・工房を見る」から開きます。技能宝石の支払いとは分け、所持金・携行容器の改修・補給所の保管油を確認できます。容器の改修は製法と120G、保管油の受け取りは携行空き容量など、既存の条件を使います。画面が低い場合はこのパネルの本文をスクロールできます。武器の再製作は、ショップの商品詳細にある製作ボタンを引き続き使います。

## 旅支度

管理メニューまたはタブの「旅支度」から開きます。最初に共通の袋と仲間の顔画像付きボタンを並べ、持ち主を選ぶとその人の所持品を表示します。

品物は説明・個数・装備枠・能力補正を確認できます。「使う」は対象の仲間を選んで実行し、選択中の持ち主から消費します。全員回復などの効果範囲は各品物の定義を使います。鍵・素材・迷宮専用道具には汎用の使用ボタンを付けず、探索や仕掛け側の操作を使います。

「渡す」は別の仲間または共通の袋へ1個ずつ渡します。複数所持している場合は「全部渡す」も選べます。受け渡しで隊の総数・ゴールド・歩数は変わりません。

装備品の「装備する」から顔画像付きの装備先を選べます。装備できない職業・倒れている仲間・外す品物の所持数上限を理由付きで表示し、実行できない選択肢を無効にします。装備先が持ち主と異なる場合はその品物を渡して装備します。交換して外れた品物は装備していた人の持ち物へ戻します。

個人の持ち物画面には現在の武器・防具・装飾品も表示し、「装備を外す」でその人の持ち物へ戻せます。探索中でも会話・戦闘のない状態なら着脱・受け渡しが可能です。会話・戦闘中は内容の確認のみです。待機中の仲間は加入させてから旅支度で装備を回収します。隊の状態の概要に装備操作は置きません。

方向入力で選択肢を移動し、決定で実行します。Escapeまたは設定済みキャンセルは相手選択から元の品物へ戻り、もう一度で管理画面を閉じます。相手選択だけではゲーム状態を変更しません。

## 所持品と保存の整合

`state.inventory` は従来のシナリオ・戦闘・材料判定が参照する隊全体の未装備品の総数です。非装備品の `state.carried[actor][item]` はその総数のうち個人が持つ個数です。差分が共通の袋であり、別の在庫を追加したわけではありません。

装備品は既存の `state.gear.items` にある個体を使い、未装備品の `holder` で持ち主を記録します。`holder` がない未装備品は共通の袋、装備中は既存の `gear.equipped` が所在です。受け渡し・着脱・転職では個体IDと腐食の塩状態を維持します。購入は新しい個体を作って指定された人へ渡します。

旅支度からの使用は指定した持ち主から消費します。戦闘・シナリオ・仕掛け・調合は隊の品物を共用でき、共通の袋を先に消費し、不足分を隊列順の個人所持品から消費します。報酬・調合生成物など、相手を指定しない入手品は共通の袋へ入ります。隊から離れる仲間の未装備品は共通の袋へ戻し、装備中の品物は本人に残します。

所在はセーブ対象です。読込時に保持者・種類・正の整数個数・総数超過・装備中との重複を検査し、不正な記録で現在の状態を書き換えません。同じ内容版で所在を持たない従来の記録は共通の袋として扱います。別内容版への移行を追加するものではありません。

## 実装と検証

判定と所在は[Core](../../src/core/inventory.js)、描画用の情報は[Application](../../src/application/inventory-projection.js)、画面は[共通View](../../src/view/inventory-view.js)です。Viewは価格・装備可否・個数を判定せず、投影された情報を描画して操作意図を通知します。

[専用試験](../../tests/inventory.test.mjs)と[キー操作試験](../../tests/keyboard-controls.test.mjs)で購入・取消・所在保存・使用元・受け渡し・装備個体・両画面の操作を検査します。実ブラウザーで確認した範囲は[検証記録](../development/PROGRESS.md)に区別して記載します。

[ショップの実ブラウザー試験](../../tools/browser-shop-smoke.mjs)では、マウスホイールによる商品・技能一覧の末尾到達、購入先への実クリック、購入後の一覧位置、低い画面での見出し・購入先の可視性を確認します。自動クリックによる強制スクロールだけを、通常操作での到達確認として扱いません。
