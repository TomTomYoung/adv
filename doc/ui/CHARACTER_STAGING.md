# 人物配置と固定メッセージ領域

更新日: 2026-09-27。作品版1.23.0。

## 固定する領域と表示専用のページ送り

背景内表示の下部は、通常画面ではゲーム画面の高さ28%（最低200px）、高さ550px以下では48%を使います。本文が短くても枠を縮めません。2026-09-19の追加調整で、44%時点の「足元・正面を調べる」ボタン付近へ上端を下げました。本文とページ操作を保つため、通常画面では最低200pxを確保します。通常会話では本文が左、選択肢・プレイヤーコマンドが右です。戦闘中も行動者と階層コマンドが右、本文・ログが左です。背景内表示のダンジョンでは探索・イベント・戦闘の下部の高さを揃え、狭い画面は最低240px、低い横画面は最低220pxを確保します。戦闘中会話では右側に無効な移動パッドを残し、その下で会話を進めます。シナリオ本文とその選択肢は同じmessage-windowに属し、表示領域だけを左右に分けます。

本文は実際の幅・高さ・フォント・改行を使って分割します。文字数150の分割はレイアウトを持たない試験環境での代替です。ブラウザでは画像や文字サイズ、画面幅の変化を反映し、画面を変えたときは読んでいた本文位置を含むページを保ちます。絵文字の結合文字列を途中で分断せず、全ページを連結すると元の本文になります。

決定で次ページへ進み、最後の本文ページを読み終えるまでCoreへadvanceやchooseを送りません。続くchoiceが同じ本文なら最後のページから選択肢を表示し、先頭から読み直させません。前ページボタンで読み返せます。キャンセルは作者が用意した安全な取消先を優先し、取消先のない会話では前ページへ戻ります。必須の会話・判断を取り消したことにはしません。

選択肢・コマンドの一覧はoverflow:autoで固定枠の中だけをスクロールします。方向入力で選択した有効なボタンが枠外にあれば、scrollIntoViewのnearest指定で枠内へ戻します。決定・キャンセル・方向の割り当てはキー設定と共通です。本文を読むための縦スクロールは使いません。

## 立ち絵とカード

背景内表示は人物を大きな立ち絵として背景と下部UIの間に置きます。標準の高さはゲーム画面の78%。本文が長くなっても人物のサイズや足元を押し上げません。狭い画面では高さ70%を基準に、顔が見えるよう画像を上へ揃えます。

一人は中央、二人は左右、三人以上は左右に重ねる中立的な初期配置を持ちます。場面の関係が重要な場合はシナリオで明示します。発話者は現在の座標を保ち、重なり順だけを手前へ上げます。左右反転は人物画像だけに適用し、名前・台詞・選択肢は反転しません。

従来表示は人物カードを維持します。背景内表示でもmodeをcardsにすればカードを表示します。大きな表示にはcharactersのsprite、なければsprite_人物IDの画像、最後にportraitを使います。カードは元のportraitを使います。透過素材がまだない人物は既存肖像の背景を含む表示となるため、必要な場面から透過spriteを追加します。

## シナリオJSONでの配置

既存のstory.scenesのcastにはdisplayを追加できます。人物の同席条件・所在条件と表示指定は別々です。castModeはstageまたはcards、省略時はstageです。

```json
{
  "title": "灯番詰所",
  "place": "post",
  "requires": true,
  "castMode": "stage",
  "cast": [
    { "entity": "elder", "display": { "x": 23, "layer": 1 } },
    { "entity": "rookie", "display": { "x": 40, "flip": true, "layer": 2 } },
    { "entity": "rine", "display": { "x": 76, "layer": 3 } }
  ]
}
```

display.positionはleft・center・right。display.xは画面左端からの百分率0〜100で、positionより優先します。display.yは画面下端からの百分率−25〜50、既定値−2。display.scaleは標準サイズに掛ける倍率0.5〜1.5、既定値1。display.flipは真偽値、既定値false。display.layerは0〜99の整数で大きいほど手前。発話者には表示時だけ100を加えます。display.assetで既存の画像アセットIDを指定すれば、その場面の立ち絵を差し替えられます。任意URL・CSSは受け取りません。

場面の途中や物語状態モデルを持たないスクリプトでは、scene.castで表示人物を置き換えます。最大8人で、同じ人物の重複は受け付けません。含めなかった人物は退場し、空配列なら全員退場します。scene.cast.clearは上書きを解除して場面の標準配置へ戻します。

```json
[
  {
    "op": "scene.cast",
    "mode": "stage",
    "cast": [
      { "character": "elder", "display": { "position": "left" } },
      { "character": "rookie", "display": { "position": "right", "flip": true } }
    ]
  },
  { "op": "say", "character": "rookie", "text": "怖いです。今も。でも、二人とも、ここにいるから。" },
  { "op": "scene.cast.clear" }
]
```

say.characterはcharactersのIDです。表示名は人物定義から取得し、必要ならnameまたはspeakerで表示名だけを上書きします。発話者はspeakerIdとして本文・続く選択肢・セーブに保ちます。既存のname/speakerだけの台詞も使用でき、表示中の人物名と一致する場合はその人物を手前へ出します。narrateは通常、人物IDを付けずに地の文を表示します。

演出の上書きはpresentation.castに保存します。新しいルートスクリプトの開始・物語場面の切り替え・スクリプト終了時には解除します。会話途中の保存再開では配置と発話者を復元します。命令は人物の物理的な所在・加入・移動・費用・乱数に作用しません。

## 2026-09-27：時間を指定する人物演出

`scene.cast` と `scene.cast.clear` に任意の `transition` を追加しました。指定を省略した既存の原稿は即時表示のままです。RPGツクールMZの「ピクチャの移動」にある時間・イージング・完了までウェイトを参考に、人物IDを維持して切り替えます。参考：[公式ヘルプ](https://rpgmakerofficial.com/product/MZ_help-en/01_10_08.html)。

`enter` は追加人物のフェードイン、`exit` は外れた人物のフェードアウト、`move` は残る人物の位置・倍率・角度・不透明度の補間、`change` は画像アセット・左右反転のクロスフェードです。各値は0〜10000ミリ秒の整数で、省略値は0。`easing` は `linear`・`ease-in`・`ease-out`・`ease-in-out`、省略値は `linear` です。複数人物・複数種の変化は同時に開始します。

`display.opacity` は0〜1、既定値1。0でも人物は配置に残ります。`display.angle` は−360〜360度、既定値0で、足元中央を基準に回転します。既存の `x`・`y`・`scale` も `move` の時間で補間します。名前・台詞は左右反転しません。従来表示と `mode: cards` ではカードのフェード・画像切替・倍率・角度・不透明度に対応し、舞台のx/y配置は適用しません。stage/cardsの切替は即時です。

`transition.wait: true` は設定された四つの時間の最大値だけ進行を止めます。既定値falseでは次の命令へ進み、台詞を読みながら演出できます。待機中には「続きを読む」や選択肢を表示せず、完了後はアプリケーションの時計からCoreへ完了を通知します。戦闘内イベントでも同じ命令を使えます。連続する演出を一つずつ見せる場合、各命令にwaitを指定してください。待機のない命令を同じ処理内で連続実行すると、中間の配置は描画されません。スクリプト末尾の退場にもwaitを指定し、退場完了まで現在の場面を保持します。

```json
[
  {
    "op": "scene.cast",
    "cast": [{ "character": "rookie", "display": { "x": 25 } }],
    "transition": { "enter": 500, "wait": true }
  },
  { "op": "say", "character": "rookie", "text": "迎えに来ました。" },
  {
    "op": "scene.cast",
    "cast": [{ "character": "rookie", "display": { "x": 65, "scale": 1.1, "angle": 5, "opacity": 0.8 } }],
    "transition": { "move": 600, "easing": "ease-in-out", "wait": true }
  },
  { "op": "wait", "duration": 300 },
  { "op": "scene.cast", "cast": [], "transition": { "exit": 500, "wait": true } }
]
```

表情差分は同じ人物の `display.asset` に登録済み画像IDを設定し、`transition.change` を指定します。`scene.cast.clear` は現在の上書きを解除して物語場面の配置へ戻す命令です。全員を消す場合は例のとおり `cast: []` を使います。

追加の `wait` 命令は0〜10000msの間を置きます。0は即時継続。既存の `effect.play` にも `wait: true` を指定でき、遅延と効果時間が終わるまで待ちます。例えば `{"op":"effect.play","effect":"field_shake","wait":true}` は揺れの後に次の命令へ進みます。効果音は従来どおり `audio.se` と組み合わせます。

### 再表示・保存・軽減設定

人物レイヤーを保持するため、台詞送り・管理画面の開閉でフェードは再発しません。退場人物の表示だけを終了時まで残し、途中で別命令を受けた人物は現在の描画位置から切り替えます。同じ人物が再登場した場合、古い退場処理で消えないよう取消します。発話者の変更は重なり順にだけ作用します。

保存には目標配置とVMの待機位置を記録します。読込ではアニメーションを再生し直さず、目標配置を即座に表示します。演出待ち中の記録はその待機時間を最初から数え、その後の命令へ一度だけ進みます。残りミリ秒や中間画像は保存しません。古い画面・古いセッションの完了通知は拒否します。記録メニューと非表示タブでは進行時計を一時停止します。

画面演出「切」では即座に目標を描画し、「動きを控える」またはOSの動作軽減では位置・回転・倍率を即時反映してフェードを最大150msへ短縮します。シナリオで指定した待ち時間は維持します。Web Animations非対応時も即時描画で進行できます。

q001の戦闘中に新人が駆けつける場面へ400msの登場フェードを適用しました。物語上の移動・加入・戦闘結果は変えません。検証は `tests/cast-transitions.test.mjs`、実ブラウザ用は `tools/browser-cast-smoke.mjs` です。
