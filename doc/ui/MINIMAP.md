# ミニマップと拡大地図

更新日: 2026-09-25。背景内表示・従来表示の両方で同じ地図描画を使います。

## 正方形と素材

セルは幅に対する縦横比を1に固定し、等幅の列へ並べます。画像と境界線はセル内へ絶対配置するため、プレイヤーの向き・記号・本文フォントによって行高は変わりません。文字の矢印は使わず、同じ正方形の現在地素材を0・90・180・270度回転します。

[assets/images/map](../../assets/images/map) に24×24、同じviewBoxのSVG素材を18点置きます。小表示・拡大表示とも同じ素材です。文字要素を使わず、編集可能な図形で作成しています。

地形はunknown・floor・wall・water・pit、現在地はplayer、配置物はstairs・exit・chest・door-closed・door-open・clue・decision・trap・torch-lit・torch-unlit・control・markerです。専用図形のない仕掛けはmarkerを使い、名前をセルの説明へ残します。

床・壁などの地形、照明色、配置物、境界線、現在地、エッジ上の灯火を重ねます。壁灯は中央の現在地とは別に該当辺へ表示します。説明と凡例に名前を残し、画像だけに意味を依存させません。

## 暗所の踏査記録

踏査済みセルは照度0でも地形素材の明るさを85%残します。照度0〜8に対して85〜125%へ変化し、最大28%の暖色を重ねます。現在地・配置物・灯火記号にはこの減光を掛けません。

未踏査セルは専用の暗い無地タイルとし、地形・配置物・照度・説明を表示しません。発見範囲・光源・照度の計算は変更せず、[Coreから投影された照明](../dungeons/FIELD_LIGHTING.md)を表示するだけです。

## 拡大と復帰

ミニマップの「拡大」または背景内表示の管理メニュー「地図」で、画面を広く使う拡大図を開きます。小画面でミニマップを隠す場合も管理メニューから開けます。

「元に戻す」、Escapeまたは設定済みのキャンセル操作で元の画面へ戻ります。開閉は表示側だけで完結し、歩数・向き・燃料・HP・戦闘・物語の状態を変更しません。開いている間は背後の操作をinertにし、移動・調査・数字による選択肢の実行を止めます。Tabは拡大図内を循環し、閉じると呼び出したボタンへフォーカスを戻します。

拡大図では1セルの幅を最低24px確保します。収まらない地図は地図部分を縦横へスクロールし、復帰ボタンは地図のスクロール外に置きます。

## 実装と確認

共通描画は[minimap.js](../../src/view/minimap.js)、開閉と入力は[view.js](../../src/view/view.js)、背景内表示への組込みは[scene-view.js](../../src/view/scene-view.js)です。ゲーム判定や光源の計算をViewへ持ち込みません。

[minimap.test.mjs](../../tests/minimap.test.mjs) は素材の寸法・文字要素不使用、四方向、参照の存在、暗所と未踏査の区別、両ビューでの開閉・入力遮断・セーブ不変・復帰後の移動を確認します。DOM試験ではCSSの実寸を模擬しません。画面上で確認した範囲は[検証記録](../development/PROGRESS.md)へ区別して記載します。
