# メッセージウィンドウとコマンドウィンドウ

仕様確定日: 2026-09-18。通常会話、調査、仕掛け操作、イベント中の選択に適用する。

## 役割

プレイヤーコマンドは、プレイヤーが行動を起こすための操作である。移動、足元・正面を調べる、帰還などをコマンドウィンドウに置く。携帯品の操作やその場での待機も、必要なダンジョンではプレイヤーコマンドとして扱う。

シナリオ選択肢は、会話やイベントの本文を受けた返答・判断である。同じメッセージウィンドウ内で、背景内表示では本文の右、従来表示では本文の下に表示する。選択肢だけの独立した常設ウィンドウは設けない。選択肢の表示中も、判断の対象となる本文と話者を維持する。

給排水・出入口・現地調査など、仕掛けごとの常設操作パネルは廃止する。現地で「調べる」を実行してから、対象の説明と選択肢をメッセージウィンドウに表示する。ダンジョンの形状、状態、ミニマップ上の目印は従来どおり表示する。

## 操作の流れ

便利調べるは有効な無料操作が一つなら直接実行する。任意調べるで操作盤を選ぶと、現在の水路の状態と「給水を止めて排水」「扉を閉じて給水」「対象一覧へ戻る」を表示する。消費がある場合は便利調べるでも選択を省かない。[調査仕様](INSPECTION.md)を参照する。選択後は同じメッセージウィンドウに実行結果を表示し、読み終えると探索へ戻る。

扉・階段は現地への到達を必要とする。移動コマンドによる既存の区画通過を維持し、「調べる」からも現地の接続を扱う。水没している区画への侵入条件はCoreで検査する。

任意調査は足元・正面の対象を調べて起動する。条件を満たさない依頼の調査選択肢や、遠方にある仕掛けの操作を常設表示しない。複数の対象がある場合は対象を選べるようにし、操作不能な理由はその対象の説明内に表示する。

「帰還」はプレイヤーコマンドである。実行するとメッセージウィンドウに費用を提示し、「帰還する」「やめる」を選ぶ。費用の支払いと移動は選択の確定時に行う。ブラウザの別モーダルで帰還確認を行わない。

指定セルへの進入・条件成立による強制イベントは従来どおり自動起動する。調べるボタンや選択肢を追加の開始条件にしない。戦闘中のシナリオ会話・選択肢にも共通のメッセージウィンドウを使う。

## 入力と状態

本文のみの場合は「続きを読む」で進める。選択肢がある場合は選択肢の確定を待ち、本文送りでは選択を確定しない。無効な選択肢は実行できない。表示条件を満たさない選択肢は表示しない。

メッセージ・選択肢の処理中は、移動、調べる、帰還、道具使用などの通常コマンドを受け付けない。戦闘中のイベント会話では戦闘コマンドも停止する。中断・保存再開でも未確定の選択肢を勝手に実行しない。

コマンドの選択画面を表示すること、キャンセル、結果文を閉じることだけで歩数・燃料・水位・料金を消費しない。実際の行為を確定した時点で、その行為に定義された消費とフィールドイベントの判定を行う。

## 実装上の責務

Coreはプレイヤーコマンドとイベント選択を区別し、現在地・向き・条件・資源・会話中かどうかを実行時に再検査する。コマンド由来の選択では、保存された任意の操作を実行せず、現在の対象から選択内容を再構築する。

Applicationは共通のメッセージ表示データと、コマンドウィンドウの表示名・操作意図・使用可否を作る。Viewはその本文・選択肢・コマンドを描画して操作意図を返す。Viewでシナリオ条件・費用・給排水・イベント進行を計算しない。

## 受入確認

通常の探索画面に給排水・区画の出入口・依頼と現地の調査の常設パネルがないこと。操作盤と任意調査が「調べる」から起動できること。本文と選択肢が同じメッセージウィンドウに表示されること。帰還の確認・取消・費用徴収、複数対象、条件不足、イベント中の入力停止、保存再開、既存の強制イベントを確認する。

## 実装先

共通コマンド・対象選択・帰還確認は `src/core/player-commands.js`。既存の各仕掛けが返す近傍対象とplanの判定を再利用する。複数対象は名前を選んでから操作へ進む。単独の配置物・クエスト調査は既存のシナリオ本文へ直接入る。

シナリオ本文の保持は `src/core/script.js`、待機状態の保存検査は `src/core/save.js`、表示データは `src/application/projection.js`、両ウィンドウの描画は `src/view/view.js`、入力の意味と割り当ては `src/view/key-bindings.js`、通常画面への振り分けは `src/view/keyboard.js`、記録画面への振り分けは `src/view/system-controls.js`。詳細な表示契約は [VIEW_CONTRACT.md](VIEW_CONTRACT.md) を参照する。

## 固定領域と人物演出（1.15.0）

背景内表示は本文を左、選択肢を右に配置します。論理上は同じmessage-windowなので、シナリオ選択肢を独立したゲームモードにしません。下部領域の高さを固定し、本文は実寸でページ分割、選択肢は右枠内のスクロールとします。最後まで読んだ本文に続くchoiceは最終ページを保持します。方向入力の選択にスクロールを追従させます。

人物は背景上の立ち絵として表示でき、位置・左右反転・重なり順と発話者はシナリオが指定します。カード表示も保持します。データ形式、固定する寸法とキャンセルの扱いは[人物演出と固定領域](CHARACTER_STAGING.md)を参照してください。
