# キー設定

更新日: 2026-09-25。PR #29のキー設定に、探索と選択画面での共通キーの用途を明記しました。保存形式と操作IDは維持しています。

## 対象と入口

「記録 → キー設定」から開きます。共通の決定・キャンセル・上下左右と、探索専用の補助キー（前進・後退・左右の旋回・調査）を変更します。各操作に主キーと任意の副キーを指定できます。

初期値は決定がEnterとSpace、キャンセルがEsc、上下左右が矢印です。ダンジョン探索中は上で前進、下で後退、左右で方向転換、決定で調べます。会話・選択肢・町・戦闘・管理画面では、同じ方向キーが項目の選択、決定キーが実行になります。通常の冒険はこの共通入力で進めます。

W/S/A/D/E/Rは探索専用の補助キーです。Eは便利調べる、Rは任意調べるです。旧設定には未使用の場合だけRを追加し、Rが他の操作に割り当てられていれば既存設定を保って任意調べるを未設定にします。共通の上キーをI、決定キーをZへ変えれば、探索はIで前進・Zで調べる、選択画面はIで上の項目・Zで確定になります。既存の保存済み設定もそのまま使います。設定画面の操作名と説明、探索の操作案内にこの用途を表示します。

## 変更・適用・取消

変更したい割り当てを決定すると入力待ちになります。次に押した一つのキーを候補へ設定します。キーを押し続けた自動リピートや日本語変換中の入力を割り当てには使いません。Escは入力待ちを取り消します。

変更は下書きとして保持し、「適用して戻る」で保存・反映します。それまでは現在の操作設定を使います。画面から戻ると未適用の変更を破棄します。「初期値に戻す」も下書きへの変更であり、適用するまで現在の設定を変更しません。

共通の決定・キャンセル・上下左右には最低一つの割り当てを必要とします。副キーと探索専用の補助キーは解除できます。他の操作が使っているキーは重複として拒否し、競合する操作名を示します。勝手に入れ替えたり、片方を無効化したりしません。

## 固定操作と入力範囲

Escによる一段戻る・入力待ちの取消と、Tabによるブラウザのフォーカス移動は回復用として残します。Escは他の行為へ割り当てません。全体の初期値復帰ボタンを常に表示します。

文字・数字、矢印、Enter、Space、Backspace、Home/End、PageUp/PageDown、通常の記号キーを対象とします。修飾キーとの組み合わせ、ファンクションキー、ゲームパッドは初回の対象外です。キーはKeyboardEvent.codeを基本に扱い、物理位置を保存します。テンキーEnterは通常のEnterと同じ決定キーとして扱います。

検索などの文字入力中は文字・方向キーをゲームへ渡しません。Escで戻る動作は共通です。数字のシナリオ選択は、その数字がキー設定の別操作に割り当てられていない場合にだけ使用できます。

## 保存と責務

ブラウザのsettings.keyBindingsへ版付きで保存します。ゲーム本体の記録ファイル・セーブ形式・進行状態には含めません。保存に失敗した場合は現在の設定を維持し、画面内に失敗を表示します。未設定なら初期値、不正な版・割り当て・重複を含む保存内容なら全体を初期値へ戻し、その旨を通知します。

`src/view/key-bindings.js` が割り当ての定義・検査と入力の意味への変換、`key-config.js` が編集画面、`keyboard.js` と `system-controls.js` が通常画面と記録画面への適用を担当します。ViewからCoreへ渡すintentは変更しません。

背景内表示・従来表示・戦闘対象・候補一覧・記録画面で同じ設定を使います。変更したキーでの操作、旧キーの不意なネイティブ決定、重複拒否、取消、保存失敗、不正設定からの復旧、初期化を検証します。
