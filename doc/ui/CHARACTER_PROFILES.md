# キャラクタープロフィールと隊の状態

更新日: 2026-10-10。背景内表示と従来表示で表示内容・操作意図を共有します。

## 町のキャラクターカード

背景内表示では左上の隊カード、従来表示では隊のサイドカードを選ぶと、その人物のプロフィールを開きます。画像・名前・職業・説明・HP/MP・能力値・戦闘時アクション・装備品を表示します。

「プロフィール／転職／スキル／魔法／所持アイテム」のボタンでページを切り替えます。転職の条件と成長・装備返却の判定は既存のCoreを使います。人物やページの選択だけではゲーム状態を変更しません。取消で概要へ戻り、もう一度で町へ戻ります。

## 隊の状態の配置

左上はパーティーのキャラクター選択、右上はその選択人物のプロフィールです。左下は酒場の待機人物の選択、右下はその選択人物のプロフィールです。上下それぞれの人物選択・ページ位置は独立しています。カード一覧とプロフィール本文には独立したスクロール領域を設け、下側の酒場一覧も人数が増えたらスクロールできます。

カードは画像・名前・HP・MPに絞ります。パーティー側の編成操作は「待機」1個、酒場側は「加入」1個です。カードの選択後、各ボタンで選択人物だけに実行します。満員、最後の一人、最後の生存者、会話・戦闘中などの実行不能条件は既存のcanJoin/canLeaveに従って無効にします。交代・休息・転職・装備解除のボタンはこの一覧へ置きません。休息は施設、装備操作は旅支度を使います。

待機・加入ボタンの右に、並べ替えの「△」「▽」を横並びで置きます。選択中の人物を同じ一覧内で一つ上／下へ移します。先頭の△、末尾の▽、選択対象がない場合、会話・戦闘中は無効です。移動後もその人物と詳細ページの選択を保持し、同じ矢印を続けて操作できます。端へ着いたら選択人物のカードへフォーカスを戻します。並べ替えは町で行い、加入・待機やHP・MP・所持品・ゴールド・歩数の変更は伴いません。

パーティー順は実際の隊列（members）を更新し、町の隊カード・ショップの購入先・旅支度などにも反映します。酒場順は独立したrosterOrderとして保存し、在隊者を除いた表示順で入れ替えます。加入時は酒場一覧から外れ、再び待機すると保存した酒場順の位置に戻ります。両方の順番は記録・再読込で保持します。同じ内容版の既存記録にrosterOrderがない場合は定義順を使い、重複・欠落・未知の人物を含む順序は読込時に拒否します。

プロフィールの概要は職業・説明・能力値・戦闘時アクション・装備を表示します。「プロフィール／スキル／魔法／所持アイテム」で切り替えます。概要には魔法使用ボタンや転職を置きません。探索特技の使用は該当するスキル・魔法ページ内にまとめ、戦闘用の技は説明と用途を表示します。ダンジョンではパーティーの選択とプロフィールだけを表示し、酒場・加入・待機を隠します。

## 表示データと操作

[Applicationの分類](../../src/application/character-profile.js)が技能・魔法の区分と個人所持品を投影し、[共通View](../../src/view/character-profile.js)が描画します。MP消費や炎属性だけで魔法と推測しません。既存の祈祷・術・刻印・魔法剣などのIDを明示的に魔法へ分類し、調合・歌・調息・武技などと分けます。新しい魔法を追加した場合は同じ分類へ登録します。戦闘の技能一覧・習得条件・効果は変更しません。

個人所持品は未装備品のみで、装備中は概要の装備欄へ表示します。共通の袋は旅支度で確認します。離隊時に未装備品を共通の袋へ戻す既存仕様を維持するため、待機人物の所持アイテムは空になります。装備中の品は本人に残ります。

スキル／魔法の使用一覧は、現在職と本人の習得レベルを満たす技能だけを表示します。未習得の探索特技も一覧から除き、町のプロフィール・隊の状態・酒場の待機人物に同じ条件を適用します。習得済みでMPや場所の条件を満たさない技能は、使用不可理由とともに表示します。対応する仕組みがない迷宮では「この迷宮ではこの探索スキルを使えません。」と表示します。書庫の借用・封印・返却も現在の付与状態に従います。転職画面の職業説明は、今後習得する技能と必要レベルを引き続き案内します。

カード選択・ページ切替・スクロールはViewの状態で、セーブ対象ではありません。加入・待機はparty、並べ替えはparty.order（group: party/tavern、actor、direction: up/down）、転職はjob.change、探索特技はjob.action、戦闘外の回復技能はfield.skillの既存操作を確定時のみ通知します。両ビュー切替時に選択人物・ページを引き継ぎます。[ショップ](SHOP_AND_PREPARATIONS.md)の個数表示も同じ所持情報を使います。

## 個人の成長と戦闘外の回復（1.23.0）

人物カードと隊カードは各人のLvを表示し、プロフィールに累積経験値・次のレベルまでの残量を表示します。Lv30は最高レベルと表示します。魔法／スキルページでは戦闘外使用が許可された回復技能に名前による対象選択を設け、技能全体に共通する使用不可理由を示します。[詳細](../battle/PROGRESSION_AND_REWARDS.md)。

### 回復技能の対象一覧（2026-10-10）

各技能の対象は名前だけのボタンをパーティー順に並べ、欄の幅に応じて折り返します。使用可能な名前は通常表示、使用不可の名前は暗転して無効化します。対象欄には名前以外のHP/MP・状態・個別理由・「使う」のラベル・状態カードの枠を追加しません。全体技能は「仲間全員」の一つ、自分用の技能は術者名の一つだけを表示します。

名前ボタンの操作領域は幅・高さとも44px以上とし、狭い欄でも同じ折返し配置を使います。対象一覧の末尾まで本文のスクロールで移動できます。

MP不足、術者の戦闘不能、場所や会話中の制限など、技能全体に共通する理由は技能ごとに一度だけ表示します。使用者の現在MPは人物カードで確認し、技能カードには重複表示しません。対象ごとの理由は本文にもツールチップにも表示しません。

使用可否と理由は[Coreの使用計画](../../src/core/field-skills.js)で判定し、[Applicationの投影](../../src/application/character-profile.js)から対象ID・名前とともに受け取ります。Viewでは理由文を解析して可否を再判定しません。名前を決定すると既存のfield.skillを通知します。使用後は状態とMPを更新し、対象順を保ちます。同じ対象へ再使用できる間はそのボタンに留まり、使えなくなったら現在の魔法／スキルページボタンへフォーカスを戻し、別技能の誤実行を防ぎます。本文のスクロール位置を保持し、使用操作の読み上げ名には対象と技能名を含めます。
