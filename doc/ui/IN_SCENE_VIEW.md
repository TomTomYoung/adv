# 背景内ビューと従来ビュー

更新日: 2026-09-27。作品版1.24.0。ダンジョンのイベント中も移動パッドの座標を維持し、戦闘操作を右へ揃えます。

## 切り替えと責務

「記録 → 画面配置」で背景内表示（scene）と従来表示（classic）を切り替えます。初期値は背景内表示。設定はブラウザのsettingsへ保存し、ゲームの記録ファイル・進行・乱数・判定には含めません。従来のGameViewを残し、新しいSceneViewは同じViewModelとdispatchを使います。core・シナリオJSONは変更しません。Applicationが既存の取消先と道具の対象種別を明示します。

町の背景または探索・戦闘の描画を一つのゲーム画面に広げ、上に表示情報を置きます。右上の手帳・旅支度・隊・記録、左上の現在地、下部のメッセージとコマンドは画面内に収めます。隊はHP等の短い表示、地図は探索中だけの小表示にします。本文と選択肢は同じメッセージウィンドウに置き、移動・調べる・帰還はコマンドとして分離します。戦闘中会話の間は戦闘操作を表示しません。

町で左上の人物カードを選ぶと、選んだ人物のプロフィールを表示します。隊の状態は上段がパーティー、下段が酒場で、各左側にカード、右側にプロフィールを置きます。ショップは商品名と価格の一覧・選択詳細・下部の購入先カードを同時表示します。[人物画面](CHARACTER_PROFILES.md)、[ショップ](SHOP_AND_PREPARATIONS.md)。

## 一覧・入力・長文

手帳・旅支度・ショップ・隊・個人プロフィール・依頼掲示板・迷宮選択は画面内のウィンドウで開きます。一覧だけが内部スクロールし、閉じると同じ場面へ戻ります。開閉と表示切り替えだけではdispatchしません。表示中は背景の操作をinertにし、WASD・E・背面の会話送り・数字の選択を遮断します。矢印とEnterは開いている画面のボタンを操作します。Escapeで候補一覧・詳細・管理画面を一段ずつ閉じ、最後は町ならコマンド選択、ダンジョンなら方向入力で直接移動する探索へ戻します。記録・ヘルプのシステムダイアログにも同じ画面内の表示範囲を適用します。

下部UIの高さを画面の28%・最低200px（低い横画面は48%）に固定します。左の本文は実際の幅・高さ・フォントと改行に合わせてページ送りし、右の選択肢は固定領域の中だけをスクロールします。最後の本文ページまでゲーム側のadvance/chooseを送りません。本文から同文の選択肢へ進む場合は最後のページを保ちます。枠外の選択肢も方向入力で選ぶと自動的に見える位置へ移ります。ウィンドウ再描画では検索欄のフォーカス・入力位置と一覧のスクロール位置を可能な限り保持します。

## カニ歩きと探索ウィンドウ表示

探索中は Shift を押したまま左右入力すると、向きを変えずに左右へ一セル移動します。矢印左右だけでなく、キー設定上の左旋回・右旋回に割り当てたキーも同じ扱いです。通常の左右入力は従来どおり旋回です。カニ歩きはCoreの `move` へ `strafe_left` / `strafe_right` として渡し、通常移動と同じ通行判定、共有エッジ、滑る床、崩れ床、セル進入イベント、遭遇判定を通します。向きは移動前後で変えません。

背景内表示のダンジョンでは右上に「ウィンドウを消す」を表示します。探索中に押すと下部の説明・コマンドウィンドウを隠し、同じ右上位置の「ウィンドウを戻す」で復帰します。非表示中も方向入力とカニ歩きは有効です。手帳等の管理画面を開く、会話・選択肢・演出待ち・戦闘へ入る場合は自動的に表示へ戻し、進行に必要な本文や選択肢を隠したままにしません。表示切替自体はゲーム状態・乱数・セーブを変更しません。

## ダンジョンのイベントと移動連打

背景内表示のダンジョンでは、右枠上部の十字キーを探索中・会話中・選択中・演出待ちで同じ位置と寸法に保ちます。イベント中は4ボタンを暗くしてdisabledにし、移動ボタンの場所へ会話送りや選択肢を重ねません。「続きを読む」「次のページ」とイベント選択肢は、十字キーの下の「便利調べる」などが出る領域へ表示します。本文とイベント操作は引き続き同じメッセージウィンドウに属します。

通常コマンドとイベント選択肢は下側の領域だけをスクロールし、キー選択による自動スクロールでも十字キーを動かしません。幅760px以下では十字キーを矢印表示にし、探索・イベント・戦闘共通の下部領域を最低240px（高さ550px以下は最低220px）に広げます。移動名は読み上げとツールチップに保持し、長い選択肢のクリック領域を確保します。イベント終了時は同じ位置で移動を再開します。イベント中のキーボード方向入力は従来どおり選択肢の移動に使い、Enterで決定します。ダンジョン内の戦闘中会話・選択でも同じ無効な移動パッドを使います。

## 重なりと狭い画面

戦闘中は左に戦闘メッセージ、右にコマンドを並べます。背景内表示では右枠の幅・上端・下端を探索と揃えます。下部は通常28%・最低200px、低い横画面48%を基準とし、ダンジョンの狭い画面では前節の最低240px／220pxを戦闘にも適用します。右は行動者と現在の階層だけを表示し、「攻撃・防御・スキル・アイテム・逃走」から選びます。スキル／アイテムの個別候補、単体対象の選択は同じ右枠を切り替えます。候補一覧は縦スクロールし、行動者の見出しを残します。

右枠の「○○ の行動」の下へ「行動？」の見出し行を設けます。攻撃を選んだ際はこの行を「攻撃の対象」へ切り替え、攻撃ボタンと先頭の生存対象ボタンの左端・上端・幅を揃えます。探索の「前へ」の位置には操作できない見出し領域が来るため、移動の連打では攻撃を選びません。攻撃を選んだ後は、同じ位置の次のクリックで先頭の対象を確定できます。対象選択を開くだけでは行動・資源を消費せず、取消は攻撃へ戻します。

戦闘コマンドから英語の戦闘・ラウンド見出し、常設キー説明、使用不能理由の一括表示、探索装置のsummaryを外しました。スキル個別の費用・説明・使用不能理由は項目のラベルやtitleで確認できます。戦闘ログと解析済みの敵情報は左枠内でスクロールし、最新の内容を表示します。背景内表示の戦闘中会話も左本文・右操作です。従来ビューも右コマンド・左ログと同じ見出し行を使い、戦闘パネル内を240pxで固定します。探索からの座標継続は背景内表示で検証します。

探索・町の説明欄と会話メッセージは、背景色の不透明度を65%にして背後の景色を透かします。文字・選択肢・コマンドボタンの不透明度は保ちます。探索中のミニマップは幅180px、各セルは正方形とし、24×24のSVG素材を縮小表示します。向きを変えてもセルの寸法は変わりません。「拡大」または管理メニュー「地図」で大きく開き、「元に戻す」かキャンセルで復帰します。隣の通知欄は地図の幅を空けます。詳細は[ミニマップ仕様](MINIMAP.md)。ダンジョン内の「？」など素材のない地点記号は、背景内ビューでは描画面の高さ49%を文字の基準線にし、固定した下部枠の上に収めます。従来ビューは61%の位置を使います。

背景・人物・敵、雰囲気と効果、通常UI、一覧ウィンドウの順で重ねます。照明は背景だけに掛け、文字と操作は暗くしません。効果は画面内へ切り取り、表示切り替えだけで再生し直しません。中央の人物と敵を見せる余白を取り、戦闘対象の選択をメッセージや地図で覆わない配置にします。

狭い画面でも本文と右側の選択領域を固定し、コマンドを右枠内で縦に並べます。隊を短い表示、地図を開閉式にします。文字を縮めて押し込まず、一覧と長い選択肢の内部スクロールを使います。テーマの色・文字サイズを両ビューで共有し、従来テーマの隊の左右指定は従来ビューだけに適用します。

人物は標準で画面高さ78%の立ち絵にし、下部UIの背後へ続けます。シナリオJSONが位置・拡大率・左右反転・重なり・発話者を指定し、同じ人物を町背景と会話で二重に出しません。q001では帰還した二人を左、リネを右にまとめます。従来表示とcards指定の人物カードを維持します。詳細は[人物演出仕様](CHARACTER_STAGING.md)。

## 検証

戦闘配置の再現用は `tools/browser-battle-smoke.mjs` です。実際のGameEngineで階層選択・対象取消・道具の確定消費・次手番を確認し、候補数の負荷確認には投影モデルへ24件の仮スキルを足します。座標検査ではテスト専用の進入イベントから実際の戦闘を起動し、「前へ」の中央と四隅の反復クリック、攻撃と先頭対象の座標一致・同一点での確定、戦闘開始時の会話・選択を確認します。画面寸法・スクロール・左右配置は実Chromiumで計測します。仮イベントや仮スキルの検査は、本編全体の通し確認と区別します。

Nodeの既存UI試験と人物演出・保存・投影の試験に加え、tools/browser-scene-smoke.mjsで実Chromiumを起動します。固定高さ、実寸ページ分割、改行と結合絵文字の保持、本文ページ送り中のセーブ完全一致、キャンセル、同文choiceへの引継ぎ、18候補の末尾までの方向選択・自動スクロール・決定を確認します。

実画面では1280px・900px・390px・320pxと844×390の横画面を確認し、文字24pxでも本文の収まりと横方向のはみ出し、選択肢への到達を検証します。実行結果は[PROGRESS.md](../development/PROGRESS.md)。以前のPRで未確認だった音声、キー設定の全経路、全管理画面、多人数戦闘の実画面確認まで完了したという意味ではありません。
