# 背景内ビューと従来ビュー

更新日: 2026-09-23。作品版1.18.0。基準master `79f43e3`（PR #39まで反映済み）。戦闘の左コマンド・右メッセージと階層式選択を追加しました。

## 切り替えと責務

「記録 → 画面配置」で背景内表示（scene）と従来表示（classic）を切り替えます。初期値は背景内表示。設定はブラウザのsettingsへ保存し、ゲームの記録ファイル・進行・乱数・判定には含めません。従来のGameViewを残し、新しいSceneViewは同じViewModelとdispatchを使います。core・シナリオJSONは変更しません。Applicationが既存の取消先と道具の対象種別を明示します。

町の背景または探索・戦闘の描画を一つのゲーム画面に広げ、上に表示情報を置きます。右上の手帳・道具・隊・記録、左上の現在地、下部のメッセージとコマンドは画面内に収めます。隊はHP等の短い表示、地図は探索中だけの小表示にします。本文と選択肢は同じメッセージウィンドウに置き、移動・調べる・帰還はコマンドとして分離します。戦闘中会話の間は戦闘操作を表示しません。

## 一覧・入力・長文

手帳・道具・隊・依頼掲示板・迷宮選択は画面内のウィンドウで開きます。一覧だけが内部スクロールし、閉じると同じ場面へ戻ります。開閉と表示切り替えだけではdispatchしません。表示中は背景の操作をinertにし、WASD・E・背面の会話送り・数字の選択を遮断します。矢印とEnterは開いている画面のボタンを操作します。Escapeで候補一覧・詳細・管理画面を一段ずつ閉じ、最後は町ならコマンド選択、ダンジョンなら方向入力で直接移動する探索へ戻します。記録・ヘルプのシステムダイアログにも同じ画面内の表示範囲を適用します。

下部UIの高さを画面の28%・最低200px（低い横画面は48%）に固定します。左の本文は実際の幅・高さ・フォントと改行に合わせてページ送りし、右の選択肢は固定領域の中だけをスクロールします。最後の本文ページまでゲーム側のadvance/chooseを送りません。本文から同文の選択肢へ進む場合は最後のページを保ちます。枠外の選択肢も方向入力で選ぶと自動的に見える位置へ移ります。ウィンドウ再描画では検索欄のフォーカス・入力位置と一覧のスクロール位置を可能な限り保持します。

## 重なりと狭い画面

戦闘中は左下にコマンド、右に戦闘メッセージを並べます。下部全体の高さは既存の28%・最低200px（低い横画面48%）を維持し、両枠の上端・下端を揃えます。左は行動者と現在の階層だけを表示し、「攻撃・防御・スキル・アイテム・逃走」から選びます。スキル／アイテムの個別候補、単体対象の選択は同じ左枠を切り替えます。候補一覧は縦スクロールし、行動者の見出しを残します。狭い画面でも左右の配置を維持します。

戦闘コマンドから英語の戦闘・ラウンド見出し、常設キー説明、使用不能理由の一括表示、探索装置のsummaryを外しました。スキル個別の費用・説明・使用不能理由は項目のラベルやtitleで確認できます。戦闘ログと解析済みの敵情報は右枠内でスクロールし、最新の内容を表示します。戦闘中会話も操作を左、本文を右に配置し、通常の戦闘コマンドを置き換えます。従来ビューも同じ階層と左右配置を使い、戦闘パネル内を240pxで固定します。戦闘後の通常会話は従来どおり左本文・右選択肢です。

探索・町の説明欄と会話メッセージは、背景色の不透明度を65%にして背後の景色を透かします。文字・選択肢・コマンドボタンの不透明度は保ちます。探索中のミニマップは幅180px、地図記号は11pxとし、隣の通知欄も地図の拡大分だけ幅を空けます。ダンジョン内の「？」など素材のない地点記号は、背景内ビューでは描画面の高さ49%を文字の基準線にし、固定した下部枠の上に収めます。従来ビューは61%の位置を使います。

背景・人物・敵、雰囲気と効果、通常UI、一覧ウィンドウの順で重ねます。照明は背景だけに掛け、文字と操作は暗くしません。効果は画面内へ切り取り、表示切り替えだけで再生し直しません。中央の人物と敵を見せる余白を取り、戦闘対象の選択をメッセージや地図で覆わない配置にします。

狭い画面でも本文と右側の選択領域を固定し、コマンドを右枠内で縦に並べます。隊を短い表示、地図を開閉式にします。文字を縮めて押し込まず、一覧と長い選択肢の内部スクロールを使います。テーマの色・文字サイズを両ビューで共有し、従来テーマの隊の左右指定は従来ビューだけに適用します。

人物は標準で画面高さ78%の立ち絵にし、下部UIの背後へ続けます。シナリオJSONが位置・拡大率・左右反転・重なり・発話者を指定し、同じ人物を町背景と会話で二重に出しません。q001では帰還した二人を左、リネを右にまとめます。従来表示とcards指定の人物カードを維持します。詳細は[人物演出仕様](CHARACTER_STAGING.md)。

## 検証

戦闘配置の再現用は `tools/browser-battle-smoke.mjs` です。実際のGameEngineで階層選択・対象取消・道具の確定消費・次手番を確認し、候補数の負荷確認だけは投影モデルへ24件の仮スキルを足します。画面寸法・スクロール・左右配置は実Chromiumで計測します。仮スキルを本編で習得・使用したという検証には含めません。

Nodeの既存UI試験と人物演出・保存・投影の試験に加え、tools/browser-scene-smoke.mjsで実Chromiumを起動します。固定高さ、実寸ページ分割、改行と結合絵文字の保持、本文ページ送り中のセーブ完全一致、キャンセル、同文choiceへの引継ぎ、18候補の末尾までの方向選択・自動スクロール・決定を確認します。

実画面では1280px・900px・390px・320pxと844×390の横画面を確認し、文字24pxでも本文の収まりと横方向のはみ出し、選択肢への到達を検証します。実行結果は[PROGRESS.md](../PROGRESS.md)。以前のPRで未確認だった音声、キー設定の全経路、全管理画面、多人数戦闘の実画面確認まで完了したという意味ではありません。
