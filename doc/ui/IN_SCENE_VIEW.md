# 背景内ビューと従来ビュー

更新日: 2026-09-19。表示の追加はPR #27で反映済み。共通キー操作の実装起点はmaster `5eae7c1`。

## 切り替えと責務

「記録 → 画面配置」で背景内表示（scene）と従来表示（classic）を切り替えます。初期値は背景内表示。設定はブラウザのsettingsへ保存し、ゲームの記録ファイル・進行・乱数・判定には含めません。従来のGameViewを残し、新しいSceneViewは同じViewModelとdispatchを使います。core・シナリオJSONは変更しません。Applicationが既存の取消先と道具の対象種別を明示します。

町の背景または探索・戦闘の描画を一つのゲーム画面に広げ、上に表示情報を置きます。右上の手帳・道具・隊・記録、左上の現在地、下部のメッセージとコマンドは画面内に収めます。隊はHP等の短い表示、地図は探索中だけの小表示にします。本文と選択肢は同じメッセージウィンドウに置き、移動・調べる・帰還はコマンドとして分離します。戦闘中会話の間は戦闘操作を表示しません。

## 一覧・入力・長文

手帳・道具・隊・依頼掲示板・迷宮選択は画面内のウィンドウで開きます。一覧だけが内部スクロールし、閉じると同じ場面へ戻ります。開閉と表示切り替えだけではdispatchしません。表示中は背景の操作をinertにし、WASD・E・背面の会話送り・数字の選択を遮断します。矢印とEnterは開いている画面のボタンを操作します。Escapeで候補一覧・詳細・管理画面を一段ずつ閉じ、最後は町ならコマンド選択、ダンジョンなら方向入力で直接移動する探索へ戻します。記録・ヘルプのシステムダイアログにも同じ画面内の表示範囲を適用します。

長い本文はビュー内のページ送りで読み、最後のページまでゲーム側のadvance/chooseを送りません。選択肢が多い場合はメッセージ内をスクロールして全候補と条件を読めます。ウィンドウ再描画では検索欄のフォーカス・入力位置と一覧のスクロール位置を可能な限り保持します。

## 重なりと狭い画面

探索・町の説明欄と会話メッセージは、背景色の不透明度を65%にして背後の景色を透かします。文字・選択肢・コマンドボタンの不透明度は保ちます。探索中のミニマップは幅180px、地図記号は11pxとし、隣の通知欄も地図の拡大分だけ幅を空けます。ダンジョン内の「？」など素材のない地点記号は、描画面の高さ61%を文字の基準線にして従来の66%から少し上へ移します。

背景・人物・敵、雰囲気と効果、通常UI、一覧ウィンドウの順で重ねます。照明は背景だけに掛け、文字と操作は暗くしません。効果は画面内へ切り取り、表示切り替えだけで再生し直しません。中央の人物と敵を見せる余白を取り、戦闘対象の選択をメッセージや地図で覆わない配置にします。

狭い画面はコマンドを下側へ並べ直し、隊を短い表示、地図を開閉式にします。文字を縮めて押し込まず、一覧と長い選択肢の内部スクロールを使います。テーマの色・文字サイズを両ビューで共有し、従来テーマの隊の左右指定は従来ビューだけに適用します。
