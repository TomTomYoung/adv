# 100件のクエストカタログ

全件が `data/quests/` の独立JSONとして実装されています。地域別の索引から、各クエストの概要と実装JSONを参照できます。

概要には真相と結末を含みます。二つの手掛かりを調べて「事情を踏まえた決着」を選ぶ流れを軸に、何を調べ、何が分かり、どう行動すると何が変わるかを記しています。「ほかの結末」には残る二つの選択肢と結果を併記しています。

各件には二つの観察地点と決着地点があります。行動名・必要条件・ほかの結末は、実装JSONの選択肢と結末に対応しています。

### q001 帰らない灯番

依頼人：灯番組合のリネ／場所：地下1層／[実装JSON](../data/quests/q001.json)

概要：戻らない灯番を捜して地下水道へ入り、乾いた灯の芯と新品の油瓶、新人と老人の足跡を調べます。灯番が迷った新人へ油を渡して立ち往生していると分かり、予備油で二人の帰路を照らすと、新人を責める代わりに油の扱いを教え直し、夜番は二瓶持つ規則ができます。

この流れで選ぶ行動：「予備油を分け、二人の帰路を照らす」（手掛かり2つ）。

ほかの結末：

- 「通路の魔物を掃討して灯番を運ぶ」（戦闘あり）→ 道は通りましたが新人は名乗れず、灯番は自分の不始末として始末書を書きました。
- 「救助隊へ位置を伝えて戻る」（戦闘を伴わない決着）→ 夜明けに二人は帰還しました。あなたの地図が救助隊の足を早めました。

### q002 骨の荷札

依頼人：運送人のベルト／場所：地下1層／[実装JSON](../data/quests/q002.json)

概要：流れてきた骨の荷札を回収するため、骨の標本番号と配達先・受領印を照合します。医学校の標本が失踪者を装う保険詐欺に使われていると見抜き、証拠を揃えて告発すると、失踪届は撤回されて骨は学校へ戻りますが、証言した荷役人は職を失います。

この流れで選ぶ行動：「荷札と標本番号を照合して告発する」（手掛かり2つ・補修用の縄1本（消費）・戦闘あり）。

ほかの結末：

- 「骨を守る骸兵を倒し荷札だけ渡す」（戦闘あり）→ 保険金は支払われ、骨はまた水に捨てられました。依頼人は約束以上の金を置いて去ります。
- 「標本だけ救い、金の流れは追わない」（戦闘を伴わない決着）→ 学校の授業は再開しました。帳簿に残る架空の死者は、別の依頼の種になります。

### q100 百の帰還

依頼人：帰還者たち／場所：地下2層／[実装JSON](../data/quests/q100.json)

概要：他の99件を終えて深淵の門へ進み、そこに映る地図・補給・救助の記録と、征服の語が後から足された銘文を調べます。門が次の冒険者へ帰還方法を渡す仕組みだと分かり、記録を公開して迷宮を共同管理すると、新しい依頼が掲げられ、次の隊を帰す手順が町の財産になります。

この流れで選ぶ行動：「帰還記録を公開し迷宮を共同で管理する」（手掛かり2つ・戦闘あり）。

ほかの結末：

- 「深淵の守護者を倒し門の鍵を独占する」（戦闘あり・逃走不可）→ あなたの隊は迷宮の管理者になりました。帰還を許す責任も、閉ざす責任も、その鍵の重さとして残ります。
- 「最奥を封じ、救助と研究の通路だけ残す」（戦闘を伴わない決着）→ 町はしばらく静かな朝を迎えました。未踏の場所は残り、いつ開くかを決めるための記録も残ります。
