## 現状の一言要約

本リポジトリは Phaser 3.60.0 を CDN から読み込む、800x600 固定のブラウザ向け分岐型アドベンチャーゲーム試作です。

ゲームループ、文字送り、選択肢、シーン遷移、フラグ、BGM/SE、メニュー、localStorage セーブ/ロードの基礎は `index.html` 1ファイルに実装されています。

一方、現在定義されている6シーンから参照される遷移先のうち8シーンが未定義です。全17選択肢中9選択肢が未定義シーンへ向いているため、現状は「一通り遊べるゲーム」ではなく、ADVエンジン機能を確認するためのプロトタイプとみなすのが適切です。

また、コードから参照される `assets/` 以下の画像・音声ファイルはリポジトリに存在せず、フォールバック描画・エラー許容を前提とした構造になっています。
