# 黒潮の沈没城

更新日: 2026-10-01。作品版1.25.0。ID `region_7`、推奨Lv.7、2区画。

[ダンジョンカタログ](../DUNGEON_CATALOG.md) ／ [専用ページ一覧](README.md) ／ [探索文書](../README.md)

## 概要と進み方

水の下に沈んだのは、城だけではなかった。

空気の残る地点を次の補給先として、水中の経路を選びます。戦闘でも空気が減るため、移動距離だけでなく戦闘が長引く余裕を残す必要があります。

浮上装置を動かすと、新たな補給地点と通路ができます。空気のあるセルへの移動で満量になり、その場の補給操作でも補充できます。空気が尽きると窒息ダメージを受け、全滅時は通常の救助処理へ進みます。

沈没城の空気システムと、灯守の地下水道の完全水没区画への進入禁止は別の仕組みです。

## 入口と区画間の移動

入口`main`：黒潮の沈没城・地下1層 (1, 1)。

地下二層への階段：黒潮の沈没城・地下1層 (14, 11) → 黒潮の沈没城・地下2層 (1, 1)。

地下一層への階段：黒潮の沈没城・地下2層 (1, 1) → 黒潮の沈没城・地下1層 (14, 11)。

## 固有の仕組みと現在の数値

### 空気の残量 (air_supply)

現在有効な部品です。

空気の最大値は36、警告は10以下。水中移動で1、戦闘開始で2、戦闘ラウンドで2消費します。

空気0の消費機会には、最大HPの12％を切り上げた窒息ダメージを受けます。初期補給地点24か所、浮上装置4基です。
