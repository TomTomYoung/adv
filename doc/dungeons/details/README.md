# ダンジョン専用ページ

作品版1.25.0。13迷宮の専用ページです。[カタログ](../DUNGEON_CATALOG.md) ／ [探索文書](../README.md)。

[篝火の迷宮](kagaribi.md)：火を整え、近道と補給路を復旧しながら深火の祭壇へ進む、3層9区画の迷宮。

[灯守の地下水道](region_1.md)：水密扉の外から水路を排水し、乾いた区画と地下関所を結ぶ10区画の迷宮。

[塩哭きの廃坑](region_2.md)：装備に積もる塩を洗い落とし、装備を食べる魔物と破壊壁に対処する廃坑。

[根喰みの地下庭園](region_3.md)：種と培養土から植物を育て、回復・遭遇率・橋・茨・ツタを使い分ける庭園。

[鏡沈みの礼拝堂](region_4.md)：行き先の異なる鏡を組み合わせ、階層をまたいで進む礼拝堂。

[灰時計の書庫](region_5.md)：自分の技能を一つ封じ、本から別の技能を借りて封印と戦闘に対応する書庫。

[眠れる地下市場](region_6.md)：通行料・物々交換・護衛で道を開き、戦闘による警戒を管理する地下市場。

[黒潮の沈没城](region_7.md)：移動と戦闘で空気を消費し、残存空気と浮上装置を足場に進む沈没城。

[鉄胎の機関廟](region_8.md)：共有の動力を配分し、扉・門番・昇降機・修復装置を動かす機関廟。

[星欠けの地下観測所](region_9.md)：天球儀を操作して地形配置を切り替え、横道を選ぶ地下観測所。

[帰還者の深淵](region_10.md)：床の流れに逆らう移動で能力低下が積み重なる、帰路が難しい深淵。

[祈りの届かない谷](prayerless_valley.md)：境界の内外で祈祷・呪い・護符の有効性が変わる谷。

[巨獣上の移動集落](moving_village.md)：巨獣が自発的に姿勢を変え、足場と建物の間の経路が変わる集落。
