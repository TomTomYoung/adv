# 根喰みの地下庭園

更新日: 2026-10-08。作品版1.25.0。ID `region_3`、推奨Lv.3、2区画。

[ダンジョンカタログ](../DUNGEON_CATALOG.md) ／ [専用ページ一覧](README.md) ／ [探索文書](../README.md)

## 概要と進み方

陽の届かない庭で、育てるものと刈るものを選ぶ。

入口の育苗箱で資材を受け取り、植床に種や胞子と培養土を使います。成功した移動と生長待ちで育ち、種類ごとに周囲への効果や通路が変わります。追加資材は町で補給できます。

回復用の胞子、敵を引き寄せる花、遭遇を抑える苔を使い分けます。地形用の植物は根橋・塞道茨・階渡りツタとなり、採取すればその効果と地形も消えます。

範囲効果は同じマップの縦横距離で判定し、壁越しにも届きます。橋の上からその橋を取り除く操作はできず、隊の足元を塞ぐ生長も待機します。

## 入口と区画間の移動

入口`main`：根喰みの地下庭園・地下1層 (1, 1)。

地下二層への階段：根喰みの地下庭園・地下1層 (14, 11) ↔ 根喰みの地下庭園・地下2層 (1, 1)。
