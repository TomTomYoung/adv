# 鉄胎の機関廟

更新日: 2026-10-08。作品版1.25.0。ID `region_8`、推奨Lv.8、2区画。

[ダンジョンカタログ](../DUNGEON_CATALOG.md) ／ [専用ページ一覧](README.md) ／ [探索文書](../README.md)

## 概要と進み方

古い命令と新しい暮らしのあいだで、歯車が軋む。

配電盤で系統を選ぶと、その系統に接続された装置へまとめて給電します。扉を開く操作で同じ系統の門番も起動するため、接続された装置と必要動力を先に確認します。

装置の前で機関部品を外すと電力計算から切り離せます。門番を先に外して扉だけを動かすなど、必要な装置へ動力を回します。部品を戻すと再接続できます。

昇降機は階層間を移動し、修復装置は隊を回復します。隊を動力扉の中へ閉じ込める切断操作は拒否します。

## 入口と区画間の移動

入口`main`：鉄胎の機関廟・地下1層 (1, 1)。

地下二層への階段：鉄胎の機関廟・地下1層 (12, 13) → 鉄胎の機関廟・地下2層 (1, 1)。

地下一層への階段：鉄胎の機関廟・地下2層 (1, 1) → 鉄胎の機関廟・地下1層 (12, 13)。

### 動力の配分 (power_grid)

現在有効な部品です。

動力容量3を迷宮全体で共有します。配電盤4か所、装置8基。修復は探索ごとに計3回です。

## 区画と設備

座標は各マップ左上が (0, 0)、xが右、yが下です。通常遭遇は7成功歩ごとに抽選し、安全なセルや配置物の地点では止めます。掲載する遭遇率は隊・環境による補正前の値です。固有条件による遭遇の置き換えやシナリオの固定戦闘は別に判定します。
