# 2D区画の接続と水密扉

作品版1.21.0、確認日2026-09-26。通常ロードは33件すべて2Dマップです。表示は従来の一人称画面を保ち、地形の接続単位は平面のセルマップとします。

## 使用するマップ

q001の篝火の迷宮は3マップ、q002〜q010の灯守の地下水道は10マップ、q011〜q020の塩哭きの廃坑は2マップ、q021〜q030の根喰みの地下庭園は2マップです。この4ダンジョンの通常のマップ移動を `map_connections` に統一しました。火・装備の塩・植物の成長など各ダンジョンの固有処理は保ちます。

地下水道以外の既存2D地形とq001・q011〜q030のイベント座標は保持しています。地下水道は旧19×15セルの2フロアを、11×5セルの乾いた操作室・待避場6マップと、11×3セルの直線水路4マップに再構成しました。水路の通行セルは横9マスです。

q031以降のシナリオ原稿は変更していません。同じダンジョンを使う追加依頼も、通常の接続経路で現場へ到達できます。全200件の分岐と100件の通常キャンペーンを既存試験で確認します。q004以降の物語内の全行動を探索移動へ変更したという意味ではありません。

## 水と地形・描画の整合

1. 完全水没は水路マップ全体の状態です。水が一セルの境界で垂直に止まる壁は作りません。プレイヤーが立てる現在区画は乾燥状態です。
2. 水路の両端は壁面に取り付けた水密扉です。給水時は扉の圧力錠が掛かり、移動・調べる・接続操作・直接移動のいずれでも入れません。潜水具で扉を抜けることもできません。
3. 給水を止めると床下の排水管へ排水し、区画全体が乾燥して圧力錠が解除されます。扉面の錠の表示、ミニマップの扉記号、行き先の説明、操作の許可は同じ状態を使います。通過時に扉を開け、通過後は自閉する設定です。隣のマップを透視する描画は行いません。
4. 給排水盤は水路の外の乾いた区画にあります。同じ弁の取っ手を両端側に置き、どちら側からでも排水できます。水路の中から遠隔で給水したり、滞在中の区画を給水したりする操作は拒否します。
5. 上下階は乾いた荷揚げ場と操作室の階段で接続します。完全水没マップを階段・ロープ・落とし穴につなぐ構成は定義検証で拒否します。上階の水が開いた穴の上に留まる表現は成立させません。
6. 旧フロア全体の潮汐、潜水中の水位上昇・溺水、立体ポンプ操作は退避資料と専用テストに残します。今回の地下水道の水没状態は給排水盤で切り替え、歩数では変化させません。

## 配置と経路

入口操作室 → 第一水路 → 荷揚げ場 → 排水支路 → 鐘と浮子の点検室、という上層の経路です。荷揚げ場の乾いた階段から下層操作室へ降り、給金箱の水路 → 棺の待避場 → 避難水路 → 奥の水門詰所へ進みます。全接続は往復可能です。

q002の荷札・箱・運搬人は荷揚げ場、q003の警報地点は荷揚げ場、通行人の所在は点検室です。q004の関所は荷揚げ場、q005の排水調査は上層支路、q006の給金箱は下層水路、q007の声とq008の棺は下層待避場、q009・q010の決着地点は奥の水門詰所へ配置しました。手掛かりの座標も各正本に記述しています。

q002・q003の `story.worldPlaces`、全配置イベント、案内先、作者向けカタログを同時に更新します。物語の選択肢・結末・実行スクリプトは保持します。q001のセル進入、消灯、強制戦闘、新人の戦闘中イベント、帰還報告も保持します。

## 実装と編集元

1. [config/connected-maps.json](../../config/connected-maps.json)：新しい平面地形、退避する配布マップとスクリプト一覧。
2. [config/dungeons/region_1.json](../../config/dungeons/region_1.json)：水路・乾いた操作盤・出入口の明示的な接続。ほかの3ダンジョンも各JSONの `systems.connections` が接続の正本です。
3. [map-connections.js](../../src/core/systems/map-connections.js)：接続口での移動許可・到着位置・向き・扉の表示状態。リンクのa/bは各マップ側の歩ける接続セルです。扉は `side` が指す隣の壁面に描きます。階段には水平の扉面を指定しません。
4. [compartment-water.js](../../src/core/systems/compartment-water.js)：区画全体の水没、乾いた場所からの給排水、保存検証、排水手段の到達性。全水密扉が閉じた状態から、排水できる区画を順に解放できることを検証します。
5. [build-connected-maps.mjs](../../tools/build-connected-maps.mjs)：旧生成器の後で2D原稿を適用し、旧階段オブジェクトによる別移動経路を除きます。Viewは投影結果の描画とdispatchのみを担当します。

扉の正面へ歩くと接続を試みます。階段は接続セルで調べるか、その場に表示される接続操作を使います。離れたセルからの移動操作は拒否します。通過は1歩を消費し、到着セルでフィールドイベントを評価します。同じ到着イベントは会話の保存・再開だけでは再発しません。

マップ間の移動でイベント地点へ直接転送せず、接続口へ到着してから現場まで歩きます。「目的地で続きを進める」UIは使用しません。入口ボタンによる町からダンジョン入口への出発は保持します。

## 退避と保存

[退避原稿](../../authoring/legacy/2026-09-18-map-layout/README.md)に、変更前の立体原稿・地下水道・q002〜q010・関連スクリプトを基点コミットとSHA-256付きで保存しています。旧3D実装と元の配布ファイルは削除していません。通常の `data/game.json` から貯水立坑と立体専用スクリプトの参照を外しています。

保存内容版は1.21.0です。旧版セーブは従来方針どおり新規開始します。同版の区画・排水状態・会話・戦闘は保存再開できます。完全水没区画に滞在する不正な保存は拒否します。
