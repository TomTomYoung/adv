# ダンジョンカタログ

更新日: 2026-10-08。作品版1.25.0。13ダンジョン・39件の2Dマップ・200クエスト。

ダンジョン名から専用ページへ進めます。各ページに概要、区画と経路、固有の仕組み、設備と通常遭遇、室内、関連クエスト、保存状態、編集元をまとめています。

[専用ページ一覧](details/README.md) ／ [探索・ダンジョン文書](README.md) ／ [現在の状態](../CURRENT_STATUS.md)

## 1. [篝火の迷宮](details/kagaribi.md)

火を整え、近道と補給路を復旧しながら深火の祭壇へ進む、3層9区画の迷宮。 推奨Lv.1、9区画。

## 2. [灯守の地下水道](details/region_1.md)

水密扉の外から水路を排水し、乾いた区画と地下関所を結ぶ10区画の迷宮。 推奨Lv.1、10区画。

## 3. [塩哭きの廃坑](details/region_2.md)

装備に積もる塩を洗い落とし、装備を食べる魔物と破壊壁に対処する廃坑。 推奨Lv.2、2区画。

## 4. [根喰みの地下庭園](details/region_3.md)

種と培養土から植物を育て、回復・遭遇率・橋・茨・ツタを使い分ける庭園。 推奨Lv.3、2区画。

## 5. [鏡沈みの礼拝堂](details/region_4.md)

行き先の異なる鏡を組み合わせ、階層をまたいで進む礼拝堂。 推奨Lv.4、2区画。

## 6. [灰時計の書庫](details/region_5.md)

自分の技能を一つ封じ、本から別の技能を借りて封印と戦闘に対応する書庫。 推奨Lv.5、2区画。

## 7. [眠れる地下市場](details/region_6.md)

通行料・物々交換・護衛で道を開き、戦闘による警戒を管理する地下市場。 推奨Lv.6、2区画。

## 8. [黒潮の沈没城](details/region_7.md)

移動と戦闘で空気を消費し、残存空気と浮上装置を足場に進む沈没城。 推奨Lv.7、2区画。

## 9. [鉄胎の機関廟](details/region_8.md)

共有の動力を配分し、扉・門番・昇降機・修復装置を動かす機関廟。 推奨Lv.8、2区画。

## 10. [星欠けの地下観測所](details/region_9.md)

天球儀を操作して地形配置を切り替え、横道を選ぶ地下観測所。 推奨Lv.9、2区画。

## 11. [帰還者の深淵](details/region_10.md)

床の流れに逆らう移動で能力低下が積み重なる、帰路が難しい深淵。 推奨Lv.10、2区画。

## 12. [祈りの届かない谷](details/prayerless_valley.md)

境界の内外で祈祷・呪い・護符の有効性が変わる谷。 推奨Lv.10、1区画。

## 13. [巨獣上の移動集落](details/moving_village.md)

巨獣が自発的に姿勢を変え、足場と建物の間の経路が変わる集落。 推奨Lv.10、1区画。

## 読み方と保守

掲載数値・配置は現在の配布JSONから生成しています。推奨Lvは迷宮全体の目安です。関連クエストの掲載は現地イベントの配置に基づき、全場面の実移動が接続済みであることを意味しません。物語内の行動を出発・到着へ全面接続した範囲はq001〜q004です。

[解説原稿](../../authoring/dungeon-page-notes.json)と配布データを更新し、`npm run build:docs`でカタログと専用ページをまとめて再生成します。検査は`npm run check:docs`です。ゲームデータを変更した場合は、先に`npm run build:dungeons`等の対応する生成処理を実行してください。

[共通部品の設計](DUNGEON_SYSTEM_DESIGN.md)、[区画接続](CONNECTED_2D_MAPS.md)、[素材と現地調査](DUNGEON_ART_AND_SCENARIOS.md)を参照できます。旧3D・潮汐の退避原稿は現行マップへ数えません。現行内容版のセーブは旧内容版から移行せず、読込に失敗した場合は新規開始します。
