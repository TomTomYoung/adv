# 既存100件の現場・帰路と移設の残作業

2026-10-26。[移設前の実行検証](REGIONAL_RELOCATION_CHECK.md)と[配分台帳](../scenarios/REGIONAL_QUEST_ALLOCATION.md)に対応する実装作業票。全件の旧本文・選択・真相・報酬は保持する。q031〜040・q061〜070・q131〜140・q161〜170と巡礼路は実装済み。沈没城・観測所は村へ入口・40件の受付・帰路を接続済み。残る60件は既存原稿の行為に必要な場所と保持者の作業票であり、実装済みとはしない。

## 採用前に通す共通条件

1. 国境宿場→石橋の交易市→巡礼台地／旧王領の村の徒歩経路と、灯帰り→既存学術都市サロメの高台街道を作る。オッドランド側の3街道は実装済み。サロメ高台街道は未実装。国境宿場の子施設に全迷宮の入口を並べて到達扱いにしない。
2. 同じ部屋の会話や実験は同じ実座標へ結ぶ。場面数だけ移動を増やさない。地下牢、民家、工房、前線、他国への出張など、原稿で移動している場面は到着・同行者・保持者を結ぶ。配置だけを理由に全事件を迷宮内の出来事へ書き換えない。
3. PR #135での一回限りの互換切断はユーザー指示による。保存改訂2より前のe2は原文を保護して非対応とし、旧遠征の移行は作らない。初版は維持する。今後の改訂2の進行には保存互換を維持する。 旧保存の入国・訪問を捏造せず、読込失敗時に現在進行を変えない。
4. 改訂2のVM・物語状態・旅程・報酬の保存再開を検査する。完了済みの受渡しや費用を再実行しない。旧改訂1からの各命令位置の変換は対象外。礼拝堂後半10件と沈没城20件の旧改訂2の命令列は保持し、受注済みはその経路で続行する。
5. 受付拠点と迷宮出発拠点を区別し、手帳・通常出発・中継・室内・地上出口からの迂回を検査する。旧 `q.region` とIDを保持する。q100の前提である旧99件は削除せず、個人80件や地域新作10件で代用しない。

旧4世代の移行試験は改訂1までの歴史的基準。現在は[前半10件の実装](../scenarios/editions/e2/CHAPEL_FIRST_TEN.md)と礼拝堂の入口・受付を巡礼台地へ接続済み。[後半10件](../scenarios/editions/e2/CHAPEL_SECOND_TEN.md)も接続し、新規受注では20件の移設を採用した。旧改訂2で受注済みの後半10件は旧経路を保持する。[沈没城前半10件](../scenarios/editions/e2/SUNKEN_FIRST_TEN.md)に加え[沈没城後半10件](../scenarios/editions/e2/SUNKEN_SECOND_TEN.md)も接続し、新規受注での採用は計40件。次は観測所20件の現場を結ぶ。観測所の入口・受付・帰路は村へ移したが、個別場面は旧イベント方式のまま。サロメは高台街道と既存施設の統合を先に通す。新作OD051〜080より先にこの判定を更新する。

## サロメの既存個人連作

`e2_academy` は現在 `e2_road` の子で、灯帰りを根とする施設群。`e2_archive`・`e2_stacks` はイルのq241〜250、`e2_workshop`・`e2_relic`・`e2_storage` と広場はミカのq281〜290の実移動先である。これら20件を地域40件に混ぜて数えない。

今後は改訂2の記録が対象となる。根だけをサロメへ変更すると、施設内の旧保存にはサロメ訪問記録がなく、新しい拠点検証で拒否される。所在地が現にこれらの施設である保存は訪問の証拠になる。一方、受注済みであるだけの保存は証拠にならない。室内保存・施設へ向かう途中・施設から灯帰りへ戻る途中・現場到着済みの各状態を、会話と旅程を維持して移行する必要がある。

書庫の技能貸出、機関廟の動力状態と修復回数、礼拝堂の鏡、沈没城の残り空気と浮上、観測所の天球儀は別々の固有状態を持つ。今後の改訂2の遠征を移行時に開始し直す方式ではこれらが失われる。通常出口・帰還印・敗北のそれぞれについて、旧遠征中と新規出発後の帰還先を分けて検査する。

沈没城・観測所では上記の旧遠征保持を実装済み。旧帰還先が灯帰りの探索は国表示と地上出口を維持し、村訪問や入国を追加しない。次に村から出た探索だけ村帰還へ切り替わる。空気残量・浮上・天球儀の非初期状態と、通常出口・帰還印・敗北・再出発を検査する。
