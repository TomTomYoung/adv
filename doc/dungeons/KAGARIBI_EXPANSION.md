# 篝火の迷宮：1〜10Fと既存区画の拡張

作品版1.25.0、2026-10-01。既存の火・種火・くらがりの規則を使い、往路で設備を直し、復路で開いた近道と補給を使う探索を追加しました。[探索文書](README.md)、[火の基本仕様](KAGARIBI_DUNGEON.md)へ戻れます。

2026-10-10追補: 火台の配置・操作位置の説明を現在の定義・実装に照合しました。q001の帰路は北・南の2地点と通常のくらがり遭遇から同じ救援へ進めるようにしました。

## 区画と通常経路

現行1.27.0の順序は、1F巡回路 → 2F油蔵 → 3F配油分岐室 → 4F交差路 → 5F煤けた回廊 → 6F炭焼き場 → 7F中継広間 → 8F最後の巡回路 → 9F納骨堂 → 10F祭壇です。表示階と固定IDは別で、既存ID・依頼座標は変えません。

新規開始では5F→7Fの直行は6Fの掛け金、8F→10Fの直行は10Fの掛け金で開ける近道です。6F→7Fの主経路は掛け金を開ける前でも通れます。油蔵から旧交差路へ直行する接続は旧セーブで訪問済みの場合だけ維持し、新規の主経路は3Fを通します。[現行台帳](KAGARIBI_TEN_FLOORS.md)。

元の3マップの地形とq001の既存イベント座標は保持し、6区画を追加しました。旧階段オブジェクトの直通経路を外し、移動は共通の接続口へ統一しています。q001「帰らない灯番」の受注中は巡回路から新しい区画へ出られず、救援後の町への報告を終えると探索できます。未受注時の自由探索は可能です。

q001で老人を介助する帰路は、既存の北 (9, 1) に加え、南 (13, 5) の `q001_return_south` でも同じ消灯・くらがり戦・新人救援を起こします。この2地点が、老人から他区画へ抜ける徒歩経路を覆います。途中の通常歩行抽選で `kuragari_hunt` が当選した場合も、その実遭遇セルで同じイベントへ進みます。火切れだけでは即戦闘にせず、戦闘と救援会話のために座標を移しません。救援は一度だけで、救援前の全滅では従来のチェックポイントから老人との再遭遇をやり直します。往路の油切れ確認は従来の北 (9, 1) のままです。[詳しい条件](KAGARIBI_DUNGEON.md#老人同行中の消灯はイベント戦闘)。

## 火と近道

火台は既存9基に7基を加えた16基です。油蔵の守り火、交差路の中継篝火、炭焼き場の誘い火と静め火、中継広間の大篝火、最後の巡回路の篝火、納骨堂の記録灯を追加しています。

交差路・中継広間・最後の巡回路の篝火は、初点火時に周囲の地図を開示し、整備の記録を一度だけ残します。点火を含む火台の操作は配置セルに立って行います。壁面松明は、その壁が属するセルで指定方向を向いて操作します。操作候補と探索画面の印も同じ位置条件を使います。点火は局所の火の守りを作り、通常魔物の完全な出現停止には深火が必要です。携帯火は90成功歩、警告は残り25歩と8歩。詰所へ入っても燃料は回復しません。

搬送門は油蔵の荷車を修理し、交差路 (1, 9) の西側の留め金を外すと、巡回路 (3, 7) へ通じます。中継広間 (1, 9) の西側の留め金は同区画の大篝火を点けると操作でき、煤けた回廊 (3, 1) へ戻れます。祭壇 (1, 7) の西側の留め金は祭壇側から開け、最後の巡回路 (1, 9) へ抜けられます。炭焼き場 (7, 1) の北側の搬出口も内側から開き、中継広間 (15, 1) と接続します。

開通は `flags.kagaribi` に保存します。以降の消火・帰還・再入場で再施錠しません。開く前は両側とも歩行・接続操作を拒否し、扉の表示と必要条件も一致させます。

## 四つの小事件

「戻らない油樽」は油蔵の荷札と荷車を調べる事件です。工具箱 (3, 9) からロープ1本と松明2本を一度だけ回収でき、荷車 (11, 5) の修理にロープ1本を使います。修理で松明3本と30Gを受け取り、搬送門を開ける条件が成立します。資材不足の修理選択肢は必要量を示して無効になります。

「交代の来ない詰所」は搬送門を開け、油蔵 (11, 1) の交代要員を送り、交差路の詰所で当直へ報告して完了します。報告で20Gを一度受け取り、補給窓口が開きます。松明は1本6Gで、所持金不足または99本所持時は購入できません。記録係は小事件の進捗と各層の火・経路を案内します。

「赤い火に寄るもの」は炭焼き場の搬出口を開け、(9, 5) の誘い火を点けて炉守りの亡霊を誘う戦闘です。台座の初期効果だけでなく、移した種火を含めた現在の効果が `lure` であることを確認します。勝利時に40Gと松明3本を一度受け取ります。戦闘自体の経験値・所持金・宝箱抽選は通常の戦闘リザルトで別に処理します。逃走・敗北では完了せず、条件を整えて再挑戦できます。

「持ち帰られた空の火入れ」は納骨堂 (11, 5) の記名板を持ち帰り、町の灯番詰所で遺族の火入れと照合する事件です。返却で記名板を消費し、35Gを一度受け取ります。深火の蘇生伝承の真偽は確定せず、人物の蘇生や回復効果を加えていません。

これらは `kagaribi.*` の現地スクリプトと永続フラグで進める小事件です。この拡張時点では番号付き依頼の200件・結末629件を増減させませんでした。後続のq201〜q210追加により、現在は210件・659結末です。材料・金・品物の支払いと報酬は既存DSLで処理し、選択中・戦闘中・報酬後の保存再開に対応します。

## 詰所と通常魔物

詰所 `kagaribi_post` は交差路 (8, 1) の戸口から明示して入るダンジョン室内です。同じ探索状態を保持し、当直・補給・記録の3サービスを利用できます。町の宿泊・編成・転職・新しい探索の開始はできません。共通室内で使えるサービスを `interior: true` で明示し、現在地に登録された機能だけ表示・実行します。

第一層に煤ネズミ・燭蝋スライム、第二層に灯蛾・赤錆の番兵、第三層に鎖引き骸骨・灰積みゴーレムを配置しました。炭焼き場では灰積みゴーレムが早く登場します。各区画の通常遭遇候補は単体2候補と2体編成1候補で、重み50・35・15です。通常遭遇率は基本22％、炭焼き場27％に、既存の隊・火の補正を適用します。通常敵のHPは27〜70、炉守りは95です。くらがりの能力・撃退規則は保持しています。

追加敵7種と詰所は既存の画像素材を再利用しています。新しい専用画像は追加していません。通常敵の数値は初期調整で、長時間の連続探索における資源収支は継続して調整する対象です。

## 正本・生成・検証

地形の正本は [cell-layers.json](../../config/cell-layers.json)、区画名・配置物・会話・敵・道具・サービスは [kagaribi-content.json](../../config/kagaribi-content.json)、火台・接続・点火イベントは [dungeons/kagaribi.json](../../config/dungeons/kagaribi.json)、詰所は [locations.json](../../config/locations.json)、敵の宝箱は [battle-rewards.json](../../config/battle-rewards.json) です。

`npm run build:dungeons` と `node tools/build-schemas.mjs` で配布データ・索引・設定編集用カタログ・スキーマを再生成します。この拡張の導入時は作品内容版1.25.0で、当時の旧版セーブは移行しませんでした。正常な1.25.0・1.26.0・1.27.0のセーブを1.28.0へ検証後に移行し、既存進行・設備・購入技能を保持します。地下水道の旧下層へ到達済みなら乾いた階段を開通済みにし、報酬は追加しません。1.25.0には遠征状態を追加します。その他の内容版は移行対象外です。同版では火・近道・小事件・室内位置を保存できます。2026-10-10のq001帰路追加でも内容版・物語改訂・既存チェックポイントを維持し、同版の既存セーブから継続できます。

[拡張試験](../../tests/kagaribi-expansion.test.mjs)は10区画の実歩行、深火を採って戻る経路、条件付き扉、資材不足、補給、二重報酬の防止、保存読込、固定戦闘、遺品返却、q001の寄り道制限、両ビューの室内操作を検査します。[Chromium試験](../../tools/browser-kagaribi-smoke.mjs)は1280×856と390×844で4区画の描画、詰所での購入・退出、横幅の収まり、素材取得とJavaScriptエラーを検査します。画面試験は位置と進捗を設定して描画する試験で、実歩行の確認はCore試験が担当します。実行結果は[検証記録](../development/PROGRESS.md)へ記録します。
