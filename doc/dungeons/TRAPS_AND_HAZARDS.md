# トラップ・ダメージ床・環境危険

採用方針の決定日: 2026-10-11。本書は、セル進入イベントを基盤にしたトラップ・ダメージ床の標準パッケージと、原因解消まで続く環境危険をまとめる。現行作品1.25.0にはこの一般化された再発方式と標準パッケージはまだ実装していない。

[セル・エッジ仕様](CELL_LAYERS.md) ／ [火の仕様](FIRE_SYSTEM.md) ／ [帰還封印](DUNGEON_RESTRICTIONS.md)

## 基本方針

トラップ・ダメージ床の根本処理は、セルを実際に占有したときに発火する「セル進入イベント」と同一でよい。専用の第二イベントエンジンは作らず、よく使う危険だけを制作向けの標準パッケージとして用意する。

パッケージは、発生方式、発生確率、発生回数上限、効果、地形変更、移動先、解除条件などを構造化して設定し、各迷宮で同じスクリプトを複製しない。特殊な演出や物語処理が必要な場合は、共通パッケージから追加スクリプトへ接続する。

## 進入イベントの発生方式

発生の仕方は「発生判定」と「発生上限」の2軸で表す。

| 発生判定 | 発生上限 | 意味 |
| --- | --- | --- |
| 毎回 | 無制限 | 進入するたびに必ず発生する |
| 確率 | 無制限 | 進入するたびに確率判定し、当選時だけ発生する |
| 毎回 | N回 | 発生回数がN回に達するまで、進入ごとに必ず発生する |
| 確率 | N回 | 進入ごとに確率判定し、当選した発生回数がN回に達すると停止する |

確率判定に外れた侵入は、発生回数を消費しない。回数は配置されたイベント単位で数えることを基本とし、保存・再開後も維持する。既存の `once: true` は「毎回発生・上限1回」、`once: false` は「毎回発生・無制限」に相当する。

実装時には少なくとも、発生確率、発生上限、既発生回数を表現する。回数を迷宮再入場で戻すか、仕掛け修理・再装填で戻すか、永久に使い切りかは配置ごとに明示する。回数リセットを暗黙に決めない。

## 標準トラップ・ダメージ床

| パッケージ | 基本効果 | 補足 |
| --- | --- | --- |
| 落石 | ダメージ | 単体・隊全体、威力は配置側で指定する |
| 落盤 | 大ダメージ＋道を塞ぐ | 発生後にセル・エッジ・障害物等を変更し、経路を閉鎖する |
| 針 | パラメータ異常 | 付与する異常・強さ・持続を配置側で指定する |
| 矢 | ダメージ＋パラメータ異常 | ダメージと異常付与を一つの発生として処理する |
| ガス | 強いパラメータ異常 | 通常の針等より強い異常を想定するが、具体値は状態異常仕様で定める |
| 魔法陣 | 魔物発生／魔術系異常 | 遭遇開始または魔術系の異常を起こす。両方を組み合わせる配置も許容する |
| 落とし穴 | 階層・区画移動 | 行き先はダンジョンごとに定義する。固定の「一階下」にはしない |
| 爆発 | 大ダメージ＋道の障害物破壊 | 破壊対象は明示し、クエスト上必要な障害物を暗黙に壊さない |
| 落滴 | 火を消す | トラップとして発生し、対象となる固定火台・携行火台／松明の点灯中の火を消す |

「パラメータ異常」「魔術系異常」の具体的な分類、重複、持続、解除、保存は、このパッケージだけで独自定義しない。トラップ群を実装し終えた段階で状態異常の共通仕様を別文書へまとめる。

### 地形を変えるトラップ

落盤は発生後に道を塞ぎ、爆発は道の障害物を破壊する。この二つは単純なHP・状態変更だけでなく、現在のセルレイヤー・エッジ・配置物・仕掛けのいずれかを変更する。

地形変更は既存の状態パッチと同じ原則で保存する。再入場・セーブ再開で元に戻らず、解除・修理・再生成の規則を明示した場合だけ戻す。どのレイヤーを変更するかは対象の種類に合わせ、セル種とイベントの双方で同じ変化を二重発火させない。

### 落とし穴

落とし穴は単なるダメージ床ではなく移動を発生させる。行き先はダンジョン側に定義し、別階層・別区画・同階層の別地点を指定できるようにする。

落下先へ到着した後は、通常の移動・転送と同様に、その地点の進入イベントや物語到着条件との競合順を一つに定める。落とし穴自身が同じ入力で再帰的に発火し続けないよう、同一入場中の処理済み管理を維持する。

## 火と相互作用する危険

### 落滴

落滴は進入イベント型のトラップ。発生したとき、対象となる固定火台または携行火台／松明で現在点いている火を消す。

火を消すだけであり、火台・油の生成用効果を書き換えない。消火後の残油・燃料の扱いは [火の仕様](FIRE_SYSTEM.md) で確定する燃料規則に従う。

### 漏水

漏水は一回の進入イベントではなく、原因を解消するまで有効な環境危険。対象範囲では固定火台・携行火台／松明へ着火できない。

漏水を解消した後は、通常の着火規則へ戻る。漏水中に既に点いている火を自動消火するかどうかは、この時点では定めず、実装時に明示する。落滴による消火とは別の効果である。

### ガス漏れ

ガス漏れも、原因を解消するまで有効な環境危険。対象範囲で固定火台・携行火台／松明へ着火すると爆発する。

爆発は標準の「爆発」パッケージへ接続し、大ダメージと必要な障害物破壊を同じ規則で処理する。既に点いた火を持ち込んだ場合、火の範囲が外部から届いた場合など、着火操作以外の発火条件は実装時に明示する。

漏水・ガス漏れは、原因となる設備・イベント・仕掛けの状態を参照する。原因を解消するまでは、セルへ入り直した回数で勝手に解除しない。

## 現行実装との対応

現行の [CELL_LAYERS.md](CELL_LAYERS.md) では、セル種は `events` に進入イベントIDを持ち、イベントは `trigger: enter`、`script`、`once`、任意の `condition` を持つ。毒沼の3ダメージはこの共通機構で実装済みで、`once: false` により再入場ごとに発生する。

現行で一般化されている発生回数は「無制限」か「一度だけ」の二択で、任意確率、N回上限、確率＋N回上限は未実装。落石・落盤・針・矢・ガス・魔法陣・落とし穴・爆発・落滴という制作向けパッケージも未実装である。

崩れやすい床、滑る氷床、安全地帯、腐食床などは既にセルパラメータや既存仕掛けへ接続されている。これらを無理にトラップパッケージへ置き換えず、作用タイミングと責務が同じものだけを共通化する。

## 実装時の検査

1. 毎回／確率と無制限／N回上限の4組み合わせを、再入場・保存再開を含めて検査する。
2. 確率判定が外れた場合に残り発生回数を消費しないことを検査する。
3. 同じパッケージを別セルに置いた場合、発生回数を別々に保持することを検査する。
4. 落盤・爆発による地形変更が通行・表示・遮光・保存へ一致して反映されることを検査する。
5. 落とし穴の移動後に、到着先イベントを二重発火せず正しい順序で処理する。
6. 落滴・漏水・ガス漏れが火の生成・消火・着火判定と同じCore規則を通り、画面だけの禁止にならないことを検査する。
7. 実装後、状態異常の共通仕様を `doc/battle/STATUS_EFFECTS.md` として新規作成するか、同等の既存文書があれば更新し、トラップ側から参照する。

## 編集元と保守

セル種・進入イベントの正本は [config/cell-layers.json](../../config/cell-layers.json)。地形変更を伴う危険は各迷宮の仕掛け・状態パッチと責務を分ける。火との相互作用は [FIRE_SYSTEM.md](FIRE_SYSTEM.md) の採用仕様を基準にする。

本書は採用する設計を記す手書き文書であり、未実装の標準パッケージを現行データへ登録済みと扱わない。実装時はSchema・設定編集UI・生成器・Core・保存検証・文書を同時に更新する。
