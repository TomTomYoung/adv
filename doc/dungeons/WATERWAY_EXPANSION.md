# 地下水道の水張り凹床と地下関所

更新日: 2026-09-26。作品版1.21.0。[セル仕様](FLOOR_DEPRESSIONS.md)、[q004の実移動](../scenarios/Q004_WORLD_ROUTE.md)、[室内の共通仕様](../world/WORLD_LOCATIONS.md)。

## 配置

灯守の地下水道の10区画を拡張した。4水路は11×3から11×7、操作室・点検室など5区画は11×5から11×9、荷揚げ場は11×5から17×9に広げた。既存の水密扉、操作盤、乾いた階段とq002・q003等のイベントへの道を維持している。

浅い水張り凹床は0.3mで通行可。深い水張り凹床は1.5m、底の見えない水張り凹床は底面省略で、いずれも通行不可。深い水路には歩ける岸を沿わせ、浅瀬で接続する。上層では細い深水路と作業場脇の浅い溜まり、下層奥では底の見えない水溜まりを配置した。各区画の入口・対岸・岸の端には照度3の光源セルを置いた。

配置数: 浅い水張り76セル、深い水張り69セル、底の見えない水張り23セル。

同じ深度の内部側面は出さず、水面の高さを揃えて一続きに描画する。深いセルの `passage` は `#` だが、見た目と遮光は壁にしない。泳ぎ・落下・溺死は追加していない。

## 給排水との関係

4水路の完全水没と水密扉は従来どおり。外の操作盤で通路の高さまで排水すると進入できる。くぼみの残水は地形の一部として残り、通路の排水を深いくぼみの通行許可に変換しない。水面だけが隣のセルを遮る壁にもならない。給水中の区画へ潜水装備や転送で進入することはできない。

## 詰所

荷揚げ場 `region_1_landing` の (13, 3) が戸口、(13, 5) がイナの待つ関所の外。戸口のセルで調べて「詰所に入る」を選ぶと、町の施設と同じ背景・人物・選択肢の室内へ遷移する。受付から留置室前へ進める。受付の「詰所を出る」または取消で、戸口 (13, 3) へ南向きに戻る。隣のセルからは入れない。

室内では探索番号、排水状態、灯油と歩数を保持する。入退室だけで灯油を補充せず、町への移動、別の迷宮への出発、酒場の仲間の呼出しや転職は行えない。町へ戻るときは詰所を出て地下水道の出口へ向かう。室内は完全水没する区画へ設置できない。
