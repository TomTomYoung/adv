# ダンジョンの封印・禁止

2026-09-27、作品版1.22.0。[探索仕様の一覧](README.md)、[イベント](../scenarios/EVENT_SYSTEM.md)、[命令](../scenarios/SCRIPT_REFERENCE.md)。

封印・禁止は、トラップやイベントの結果として発生する状態です。クエスト名を帰還ボタンへ埋め込まず、発生・解除を原稿の命令列へ記述します。現在の禁止対象は `return_mark`（帰還印の使用）と `return`（帰還印と入口からの町への帰還）です。

## 状態と適用範囲

`state.dungeonRestrictions` に `dungeon`、`action`、`source`、`reason` を持つ配列として保存します。同じ迷宮・対象・発生元の再付与は一件を更新し、別の発生元は併存します。解除命令は指定した一件だけを取り除くため、クエスト封印の解除で別の罠の封印は消えません。`reason` は実装IDを含めないプレイヤー向け説明です。

対象迷宮で探索している間に効きます。階層移動、探索画面と迷宮内の室内の移動、会話中断、保存・再読込で消えません。町や別の迷宮では適用しませんが、明示的な解除までは記録を保持し、再入場時に再び適用します。残歩数やターン数による自動解除はありません。

`return_mark` だけなら徒歩で入口へ戻って脱出できます。`return` は両方を拒否します。通常戦闘の勝利・逃走・撃退や火の点灯だけでは解除しません。

全滅時は既存の救援費・回復処理で町へ戻ります。進行中の[イベントチェックポイント](../scenarios/EVENT_CHECKPOINTS.md)があれば、対象区間が付与した封印と進行を開始時へ戻します。q001では封印を取り消し、老人との再遭遇からやり直します。対象外の罠による封印は個別の解除条件に従い、巻き戻しへ巻き込みません。

## イベントからの設定と解除

トラップ、セル進入、条件付きイベント、物語、戦闘中イベントの命令列で共通に使用します。

```json
[
  {
    "op": "dungeon.restriction.set",
    "dungeon": "kagaribi",
    "action": "return_mark",
    "source": "trap.return_seal",
    "reason": "罠により帰還印が封印されている。"
  }
]
```

解除側のイベントには同じ迷宮・対象・発生元を指定します。

```json
[
  {
    "op": "dungeon.restriction.clear",
    "dungeon": "kagaribi",
    "action": "return_mark",
    "source": "trap.return_seal"
  }
]
```

DSLの実行、配布データ検査、JSONスキーマ、セーブ検査が迷宮・禁止対象・発生元を検査します。未知の禁止対象を任意文字列で登録して実装済みと扱うことはありません。将来、道具や魔法などの禁止を追加するときは、共通の対象一覧へ登録し、該当操作のCore判定と表示を接続します。

## 帰還処理と表示

Coreの `returnTown` は封印を確認してから帰還費・迷宮の退場処理・位置・同行状態を変更します。直接の `retreat`、プレイヤーコマンドの確認前と確認時、入口の調査、スクリプトの `town.return` からも封印を迂回できません。拒否によるゴールド、燃料、歩数、乱数、所持品の消費はありません。

帰還印ボタンは「帰還印封印中」として無効になり、コマンド欄に理由を表示します。入口の調査も帰還禁止なら無効にし、同じ理由を示します。表示とキー操作・実行の判定は同じCore状態から取得します。解除後は通常の帰還費確認に戻ります。

## q001 帰らない灯番

正本は `authoring/story-q001.mjs` です。`q001.v11.old` に入った直後、老人の会話を表示する前に、`dungeon: kagaribi`、`action: return`、`source: q001.elder_rescue` を一度付与します。老人を介助する選択の前に会話を中断しても封印は維持します。

帰路の消灯・くらがりとのイベント戦闘・新人の発言まで封印を保持します。`q001-F-kuragari` の `battle.end` による強制終了後、`on_interrupt` の先頭でq001由来の一件を解除し、同じセルの `q001.v11.rescue` へ進みます。新人の会話開始時や戦闘開始時には解除しません。

早期勝利・逃走・撃退も既存の新人救援イベントを通してから解除します。新人救援前の敗北では区間を巻き戻し、封印・消灯済みフラグ・最後の壁灯の変更を取り消します。老人は支道、新人は入口へ戻り、再入場後は老人セルへの再遭遇からやり直します。救援成功時は区間を確定し、その後の全滅で救援を取り消しません。詳細な本文と命令位置は[q001専用ページ](../scenarios/QUEST_Q001.md)を参照してください。

作品版変更を伴います。既存方針どおり旧版セーブの移行は行いません。検証は[回帰試験](../../tests/dungeon-restrictions.test.mjs)と[進捗記録](../development/PROGRESS.md)を参照してください。
