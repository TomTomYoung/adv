# 4迷宮・各20FとLv30までの進行設計

実装状況の追記：[1.26.0の共通機能と既存区画への接続](EXPEDITION_IMPLEMENTATION.md)を着手しました。本書の20F構成・深層敵・武器・成長予算は引き続き設計値です。

2026-10-15。設計第2案。ゲーム未実装、数値は試遊前の仮配分。[篝火の初案](KAGARIBI_PROGRESSION_DESIGN.md)を、ユーザーの「他の迷宮も3つ程度、全部20Fを攻略できる頃にLv30」という指定に合わせて拡張する。[敵・武器・技能の設計](../battle/FOUR_DUNGEON_COMBAT_DESIGN.md)と一組で読む。

## 1. 到達体験と対象

ユーザー指定は、修復による永久進行、汲んで持ち出せる無限の油、設備からの次回出発、10Fまでの足場作りと11F以後の難化、Lv15〜25での技能中心の報酬、選択内容に応じた依頼報酬。篝火10FでLv15〜16は維持し、4迷宮15F前後でLv25、4迷宮20Fの攻略が揃う頃にLv30とする。階数を人物Lvの通行条件にはしない。

追加する3迷宮と各階の割当は設計提案。既存の仕掛けを活かせる水道・廃坑・庭園を選ぶ。地上から各入口へは従来どおり入れ、篝火10Fまで他迷宮を禁止しない。順序の基準例は篝火先行だが、先に水道へ行った場合も報酬は同じ一回分で数える。

迷宮：篝火の迷宮 / 10Fまでに取り戻す設備：配油網・荷車路・中継篝火 / 11F以後の主課題：長い帰路、火、支援役と不死の混成 / 他迷宮へ持ち帰る成果：範囲攻撃、対不死、耐熱技術

迷宮：灯守の地下水道 / 10Fまでに取り戻す設備：排水弁・渡り板・水門リフト / 11F以後の主課題：水位で変わる経路、濡れ、後方からの術 / 他迷宮へ持ち帰る成果：防水容器、耐水・雷対策、複数対象術

迷宮：塩哭きの廃坑 / 10Fまでに取り戻す設備：洗浄槽・巻上機・坑道線路 / 11F以後の主課題：塩害、硬い前衛、予告突進 / 他迷宮へ持ち帰る成果：大型容器、貫通・破甲、武器の製法

迷宮：根喰みの地下庭園 / 10Fまでに取り戻す設備：灌漑・種床・栽培通路 / 11F以後の主課題：育成と収穫の取捨、増援、状態異常 / 他迷宮へ持ち帰る成果：回復節約、足止め、帰路確保

20Fは今回の攻略区切り。既存の残りの迷宮は任意の寄り道として残し、この4迷宮の全体EXPに収入を足し込まない。初案で挙げた対象外の迷宮を順番に回るモデルは、本案の標準経路から外す。

## 2. 階層と探索の共通規則

1. 1〜3Fは短い導入。4F・7F・10Fの設備を修復すると、安全な給油キャンプと次回の出発点になる。給油管の修復と移動設備の起動は別フラグにし、片方だけ直しても成果を得る。
1. 油は無制限に汲んで持ち出せる。油の価格・再利用回数で制限せず、隊全体の容器容量、帰路の距離、MP・回復品で遠征を組む。無料のプレーン油を売ってGに換えられない扱いは初案を継承する。
1. キャンプでは敵が出ない。HP・MPの自動全回復、転職、隊員入替は付けない。遠征を終えて町へ戻る価値を残す。
1. 次回出発は町から解放済み4F・7F・10Fへ。探索中のどこからでも転送できる機能にはしない。進行中セーブの再開とは区別し、既存の封鎖条件も確認する。
1. 11〜20Fには追加の無限給油所・新出発点を置かない。12F・15F・18Fに、現地から開ける帰路短縮を置く。深部を歩いて帰る仕組みは残す。
1. 1遠征の主目標は「設備1つ、近道1本、技術書1つ、主の討伐1体」のいずれか。討伐できなくても調査済み経路・修理・取得物は持ち帰れる。既存の全滅損失は別途適用する。
1. 必須修理部材は固定配置・依頼の確定支給・通常購入のいずれか。低確率ドロップや特定の依頼結末だけを進路の鍵にしない。
1. 10Fから先の目的を地図・手帳へ「未修理弁」「帰路を短縮できる扉」「未回収の製法」の形で残す。未探索の座標や正解手順まで自動公開しない。

### 油の容量と帰路

初期180、篝火7Fで270。330への改良は追加3迷宮のどれかの7Fで製法を発見、390はどれかの12F、450はどれかの16F。どの迷宮でも同じ改良段階を進められ、同じ段階の重複取得は予備部材になる。特定迷宮の20Fを倒さないと別迷宮20Fへ届かない循環条件を作らない。

改良は各段階で固定部材1個＋町工賃120／240／360Gの案。必要部材は近道側に確定配置し、各迷宮の一度きりの取得状態を保存する。パーティ人数や容器分割で隊全体の上限は増えない。携行火台・予備容器内の全油種を合算する。

探索帯：11〜12F / 標準の容量：330 / その帯の近道が未開通の目標往復：240〜280歩 / 開通後：170〜210歩 / 経路作成時の条件：前の270でも偵察往復160〜190歩は可能

探索帯：13〜15F / 標準の容量：390 / その帯の近道が未開通の目標往復：300〜340歩 / 開通後：230〜270歩 / 経路作成時の条件：12Fまでの開通済み経路を出発点に計測

探索帯：16〜18F / 標準の容量：450 / その帯の近道が未開通の目標往復：350〜390歩 / 開通後：270〜310歩 / 経路作成時の条件：15Fの近道を使用、追加の寄り道は予備消費

探索帯：19〜20F / 標準の容量：450 / その帯の近道が未開通の目標往復：380〜410歩 / 開通後：320〜350歩 / 経路作成時の条件：18Fの近道を使用、主討伐後に出口側の短縮

標準消費1単位／成功歩、灯番・特殊油なしで、正しい帰路を選べば約10%以上残して帰れる基準。待機や状態による追加消費は経路検証に含める。有限油箱は追加の寄り道や失敗を支える一度きりの備えで、主再挑戦に毎回必要とはしない。燃費が違う火・水中経路・特殊な消費は、この標準値へ上乗せして別計測する。

篝火初案の最大460歩は、素の450容量で帰還不能になり得るため、今回は標準攻略経路を410歩以下へ改める。長い任意枝道は燃費技能か追加補給を計画して挑む。油の効果が給油・移火で保存される既採用仕様は変更しない。
