# 給油・中継所・技能教習の現行実装

初回は2026-10-15、内容版1.26.0。現行は2026-10-23、内容版1.29.0。ユーザーの実装着手指示に基づき、[4迷宮の進行設計](FOUR_DUNGEON_PROGRESSION_DESIGN.md)の共通機能を既存マップへ接続しました。これは4迷宮80階の完成版ではありません。

## 遊び方

「帰らない灯番」完了後、設備のあるセルで「調べる」から給油設備を選びます。ロープ1本で修理すると、何度でも無料で油を汲めます。中継設備の起動は別操作です。起動後は篝火広場の「迷宮へ」から、その場所を次の出発点に選べます。遠征中の瞬間移動や、帰還封印の解除には使えません。

給油自体はHP・MPを回復しません。初回修理のEXPでレベルアップすると既存の回復が発生します。篝火・地下水道・廃坑では設備と備品箱のセルが通常歩行遭遇の安全点です。庭園は修理済みの設備セルが安全点です。周囲の通路やクエスト戦まで安全になるものではありません。

篝火は1/3/4/7/9/10Fに給油設備があり、新規開始の中継出発は4/7/10Fです。3F配油管の修理で4F修理、6F搬出口の開錠で7F修理、10Fの主討伐で中央設備の修理を許可します。各給油点にロープ1本の一度きりの備品箱があり、使い切った場合は町で購入できます。1/3/9Fは給油専用で、旧版で起動済みの1F中継は互換として残します。

地下水道の既存3F荷揚げ場・8F待避場を給油所として残し、4/7/10Fへ3設備を追加しました。新規の中継は4/7/10F、旧3/8Fで起動済みの中継は維持します。4F修理で7F修理、10F水門獣の討伐で中央修理を許可します。水没中の4/7Fへは中継出発できません。[水道の座標と経路](WATERWAY_TEN_FLOORS.md)。廃坑は旧1/2F設備・中継を保ち、4/7/10Fへ3設備を追加しました。4F修理で7F修理、殻砕き獣勝利で10F修理が可能です。[廃坑の洗浄・帰路](MINE_TEN_FLOORS.md)。庭園の2設備を含め全18設備です。庭園の4/7/10F化は後続です。[篝火の座標と経路](KAGARIBI_TEN_FLOORS.md)。

## 油の携行と保管

初めて給油設備を修理したとき、隊共通の携行管理が有効になります。容量は180単位、中継篝火の広間の中継設備起動で270単位。330・390・450の改良は後続実装です。

容量には携行灯の燃料、予備油、灯油瓶の中身を含めます。灯油1瓶は90単位。個人へ渡した瓶も隊の所持総数に含まれるため、持ち主の変更で容量を増やせません。

旧所持品や拾得品が容量を超えた分は補給所へ保管します。旅道具店の技能教習画面から空き容量まで取り出せます。満杯のときの灯油購入は支払い前に拒否します。予備油90単位を既存の灯油1瓶へ詰め、依頼への受け渡しにも使えます。油からGや技能宝石への換金は設けません。

篝火の携帯松明・固定火台への給油は予備油を優先します。予備油がなければ灯油瓶を1本使います。予備油が不足している場合はその量だけを移します。給油は生成済みの火の効果を保持し、種火からの移火も油を消費します。固定火台へ入れた油は隊の携行量から減ります。魔法による点火など既存のMP消費機能は維持します。

他迷宮では「携帯松明を扱う」内の「予備油を携行灯へ補充」を使います。漏水による着火拒否、ガスによる引火を通します。帰還・通常出発・中継出発は油を全快させず、残量を引き継ぎます。修理前のセーブは従来の燃料処理を継続します。

## 技能宝石と教習

宝石は隊共通の専用通貨です。敵ごとの確定量を勝利リザルト時に1回付与します。通常敵1体につき3〜16個、報酬なしの敵は0個。逃走・撃退・敗北では付与しません。リザルト途中から再開しても重複しません。

設備修理の初回宝石は篝火1/3/4/7/9/10Fに24/18/36/48/24/30、水道3/4/7/8/10Fに80/40/50/100/70、廃坑1/2/4/7/10Fに80/100/40/50/70、庭園80/100の合計1040個。篝火・水道・廃坑の主は各40個です。廃坑4/7/10Fの修理EXPは300/400/600、合計1300です。水道4/7/10Fの修理EXPは250/350/600、合計1200です。篝火3/4/7/10Fの初回修理EXPは600/800/1200/2000で合計4600。q201〜q210は結末別のG・EXP・技能宝石を支払います。完了済みの報酬は遡及変更せず、EXP曲線も維持します。

旅道具店の「技能教習所」で人物を選んで購入します。購入履歴は人物別で保存し、使用できるのは現在の職業と武器が対応しているときです。転職しても購入履歴は残ります。既存の職業技能は無料のままです。

初回12技能を維持します。篝火4F修理後に横列払い、構え崩し、貫通突き、連環火弾、氷結針、渡り雷、応急連携、清水の手当、調律拍を販売します。篝火7F修理と中継起動後に防潮刻印、精密穿ち、連結護符を販売します。地下水道の修理・中継と、廃坑・庭園の既存設備でも解放します。旧版で解放済みの棚は移行時に保持します。追加5技能を含め17技能（戦闘15・探索2）です。設計32技能の全階層別の棚は未完了です。

習得価格は120〜180個。明示された強化だけLv2＝基礎価格の2倍、Lv3＝4倍を追加支払いして販売します。渡り雷、防潮刻印、調律拍、祓いの追撃、節油の種火、帰路測定はLv1のみ。他の11技能はLv3まで購入でき、使用回数による自動強化はありません。強化による対象数増加も使用許可へ反映します。

追加の戦闘3教習は各設備を修理した後、町の旅道具店で購入します。価格・解放・職業は次のとおりです。

1. 4F「再起の呼吸」：120宝石・MP5。戦士／狂戦士／拳闘士、剣・斧・拳具。現在の巡に防御し、次の本人の行動の物理威力を20%強化します。Lv2で30%、Lv3でMP4。HP回復はありません。移動・道具・防御・行動不能でも次の行動機会を消費し、複数対象の攻撃は行動全体を強化します。無効な入力では消費しません。
1. 9F「祓いの追撃」：160宝石・MP7。祈祷師／聖騎士／祓魔師、杖・剣。生存敵1体へ光攻撃、基礎値はmax(3, 0.9INT＋0.35STR＋8−0.25対象VIT)。Frontlineで戦闘不能のまま残る不死者の敵だけは攻撃の代わりに除去します。味方や生存者は除去せず、Lv1のみです。
1. 10F「受け流しの号令」：180宝石・MP8。騎士／吟遊詩人／軍師、楽器・剣・道具。生存味方2人が受ける物理被害を各1回20%軽減します。付与した巡を含む2巡以内、魔法や防御Lv3の被害0では消費しません。Lv2で3人、Lv3で30%軽減。同じ補正は最強倍率だけを採用します。

9Fの通常遭遇だけを新IDへ接続し、能力・報酬が従来の浅層鎖引きと同じ「納骨堂の残骸兵」を追加しました。Frontlineでは撃破後も残り、Classic/Gridの勝利条件・対象規則は従来どおりです。既存敵と遭遇は変更していません。復活や蘇生は追加していません。戦闘補正は既存の付与元付き保存形式を使い、使用済みの補正レコードを削除します。次の行動までの補正は巡による減算の対象外です。

具体的な式・対象数・職業・強化は[技能カタログ](../battle/SKILL_CATALOG.md)と[正本JSON](../../config/expedition-content.json)を参照してください。Classicの複数敵技能は遭遇順で上限まで、Grid/Frontlineでは明記した射程・範囲で判定します。応急連携・清水の手当はHP割合の低い生存者を優先します。精密穿ちは今回、投射を含む射程1〜5として実装しています。範囲・射程・価格は数値調整の対象です。

## 探索教習の使用と帰路

7F修理と中継起動後の「節油の種火」は160宝石・MP10、灯番の杖／道具で使用します。「隊の状態」→灯番→「魔法」で使うと、次の60成功歩のうち2歩ごとに携行灯・携帯松明の油消費を1回省きます。灯番の常時3歩節油は携帯松明にも適用し、一時補助とは有利な間隔だけを採用します。60歩では通常の60消費に対して30消費、常時節油の40消費からは追加10単位の節約です。固定火台は節約対象外で、既存の火の種類・遭遇効果・残量は使用時に変更しません。

旋回・壁への失敗移動・メニュー・戦闘では残り歩数が減りません。階層接続と滑走は実際に消費した歩数で減算します。再使用は残り60歩へ更新し、効果を重ねません。階層移動・保存・戦闘を越えて維持し、町への帰還・敗北救助で終了します。指定された使用禁止区域では節油補助を停止し、残り歩数は進みます。

10F中央修理後の「帰路測定」は180宝石・MP6、斥候／測量士／巡礼者の弓／道具で使用します。「隊の状態」→対象人物→「スキル」で、同じ迷宮の最寄りの修理済み給油設備への最短経路を測ります。発見済みの平面セル、開いている扉・境界、通行可能な区画接続を使い、区画接続も1歩として数えます。水没・閉鎖・崩落・滑走条件を反映し、未知のセルや扉を通過・開示しません。旧3Dマップ、スクリプトによる転送・庭園の階渡りツタ等は計算対象外です。帰還封印を解除する機能ではありません。

「任意調べる」で「節油の種火」の残り歩数と「帰路測定」の方角・区画・残り歩数を確認できます。測定済みの道を歩くと追加MPなしで残り歩数が減ります。経路から外れた場合、または測定経路が閉鎖された場合は再測定を案内します。通行条件を読むだけで扉を開けたり、未知セルを発見したり、乱数を消費したりしません。通路が確認できなければMPを消費せず拒否します。戦闘・罠・移動後の通路変化は別に対応が必要です。

両教習はLv1のみです。購入は既存の人物別履歴を共有し、許可するAPIを技能定義から選びます。戦闘の技能候補には現れません。残り歩数と測定済み経路は遠征状態の任意項目として保存し、項目がない旧セーブはそのまま読めます。不正な残り歩数・未知地点・不連続経路は読み込み時に拒否します。経路が後から閉じた正当なセーブは受理し、表示時に再測定を案内します。

## 保存と正本

正常な1.25.0〜1.28.0のセーブを1.29.0へ検証後に移行し、既存進行・装備の塩・設備・購入技能を保持します。1.25〜1.27で地下水道の旧下層へ到達済みなら乾いた階段を開通済みにします。1.28からは内容版だけを更新し、新しい設備・帰路・報酬を付与しません。1.25.0には遠征状態を追加します。既存の人物、依頼、会話、戦闘、リザルト、マップ、火、排水状態を保持し、遠征管理の初期値だけを追加します。q201〜q210がまだ存在しない1.25.0の正常なセーブは、その既知の追加依頼も補完します。旧内容版全般を無条件で読み込む処理はありません。

正本は `config/expedition-content.json`（設備・宝石・商品）、`config/jobs.json`（技能・式・補助・射程）。`npm run build:jobs` で配布JSON・文書・編集画面・配信情報へ反映します。設備の変更は `build:dungeons` からも反映できます。

`tests/expedition.test.mjs` と `tests/expedition-field.test.mjs` は実際の操作・消費・使用許可・保存を検証します。既存のq001〜q210、移動・封印・イベント・戦闘・両画面の回帰試験も維持します。
