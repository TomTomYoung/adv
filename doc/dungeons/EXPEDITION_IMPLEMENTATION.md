# 給油・中継所・技能教習の現行実装

初回は2026-10-15、内容版1.26.0。現行は2026-10-20、内容版1.27.0。ユーザーの実装着手指示に基づき、[4迷宮の進行設計](FOUR_DUNGEON_PROGRESSION_DESIGN.md)の共通機能を既存マップへ接続しました。これは4迷宮80階の完成版ではありません。

## 遊び方

「帰らない灯番」完了後、設備のあるセルで「調べる」から給油設備を選びます。ロープ1本で修理すると、何度でも無料で油を汲めます。中継設備の起動は別操作です。起動後は篝火広場の「迷宮へ」から、その場所を次の出発点に選べます。遠征中の瞬間移動や、帰還封印の解除には使えません。

給油自体はHP・MPを回復しません。初回修理のEXPでレベルアップすると既存の回復が発生します。篝火では設備と備品箱のセルが通常歩行遭遇の安全点です。他迷宮は修理済みの設備セルが安全点です。周囲の通路やクエスト戦まで安全になるものではありません。

篝火は1/3/4/7/9/10Fに給油設備があり、新規開始の中継出発は4/7/10Fです。3F配油管の修理で4F修理、6F搬出口の開錠で7F修理、10Fの主討伐で中央設備の修理を許可します。各給油点にロープ1本の一度きりの備品箱があり、使い切った場合は町で購入できます。1/3/9Fは給油専用で、旧版で起動済みの1F中継は互換として残します。

地下水道の荷揚げ場・待避場、廃坑と庭園の既存1/2層は従来の6設備を維持します。全12設備です。他3迷宮の4/7/10F化は後続です。[篝火の座標と経路](KAGARIBI_TEN_FLOORS.md)。

## 油の携行と保管

初めて給油設備を修理したとき、隊共通の携行管理が有効になります。容量は180単位、中継篝火の広間の中継設備起動で270単位。330・390・450の改良は後続実装です。

容量には携行灯の燃料、予備油、灯油瓶の中身を含めます。灯油1瓶は90単位。個人へ渡した瓶も隊の所持総数に含まれるため、持ち主の変更で容量を増やせません。

旧所持品や拾得品が容量を超えた分は補給所へ保管します。旅道具店の技能教習画面から空き容量まで取り出せます。満杯のときの灯油購入は支払い前に拒否します。予備油90単位を既存の灯油1瓶へ詰め、依頼への受け渡しにも使えます。油からGや技能宝石への換金は設けません。

篝火の携帯松明・固定火台への給油は予備油を優先します。予備油がなければ灯油瓶を1本使います。予備油が不足している場合はその量だけを移します。給油は生成済みの火の効果を保持し、種火からの移火も油を消費します。固定火台へ入れた油は隊の携行量から減ります。魔法による点火など既存のMP消費機能は維持します。

他迷宮では「携帯松明を扱う」内の「予備油を携行灯へ補充」を使います。漏水による着火拒否、ガスによる引火を通します。帰還・通常出発・中継出発は油を全快させず、残量を引き継ぎます。修理前のセーブは従来の燃料処理を継続します。

## 技能宝石と教習

宝石は隊共通の専用通貨です。敵ごとの確定量を勝利リザルト時に1回付与します。初期値は有報酬の敵1体につき4〜16個、報酬なしの敵は0個。逃走・撃退・敗北では付与しません。リザルト途中から再開しても重複しません。

設備修理の初回宝石は巡回路120、交差路80、中継篝火120、中央100、3/9Fは0、水道80/100、廃坑80/100、庭園80/100の合計960個。篝火の主は40個です。3/4/7/10Fの初回修理EXPは600/800/1200/1800で合計4400。既存の依頼報酬やEXP曲線は今回変更していません。

旅道具店の「技能教習所」で人物を選んで購入します。購入履歴は人物別で保存し、使用できるのは現在の職業と武器が対応しているときです。転職しても購入履歴は残ります。既存の職業技能は無料のままです。

初回12技能を維持します。篝火4F修理後に横列払い、構え崩し、貫通突き、連環火弾、氷結針、渡り雷、応急連携、清水の手当、調律拍を販売します。篝火7F修理と中継起動後に防潮刻印、精密穿ち、連結護符を販売します。他3迷宮の既存設備でも従来どおり解放します。旧版で解放済みの棚は移行時に保持します。設計32技能の全階層別の棚は未完了です。

習得価格は120〜180個。明示された強化だけLv2＝基礎価格の2倍、Lv3＝4倍を追加支払いして販売します。渡り雷、防潮刻印、調律拍はLv1のみ。他の9技能はLv3まで購入でき、使用回数による自動強化はありません。強化による対象数増加も使用許可へ反映します。

具体的な式・対象数・職業・強化は[技能カタログ](../battle/SKILL_CATALOG.md)と[正本JSON](../../config/expedition-content.json)を参照してください。Classicの複数敵技能は遭遇順で上限まで、Grid/Frontlineでは明記した射程・範囲で判定します。応急連携・清水の手当はHP割合の低い生存者を優先します。精密穿ちは今回、投射を含む射程1〜5として実装しています。範囲・射程・価格は数値調整の対象です。

## 保存と正本

正常な1.25.0・1.26.0のセーブを1.27.0へ検証後に移行し、既存進行と旧版で訪問済みの近道・設備・購入技能を保持します。1.25.0には遠征状態を追加します。既存の人物、依頼、会話、戦闘、リザルト、マップ、火、排水状態を保持し、遠征管理の初期値だけを追加します。q201〜q210がまだ存在しない1.25.0の正常なセーブは、その既知の追加依頼も補完します。旧内容版全般を無条件で読み込む処理はありません。

正本は `config/expedition-content.json`（設備・宝石・商品）、`config/jobs.json`（技能・式・補助・射程）。`npm run build:jobs` で配布JSON・文書・編集画面・配信情報へ反映します。設備の変更は `build:dungeons` からも反映できます。

`tests/expedition.test.mjs` は実際の操作・消費・使用許可・保存を検証します。既存のq001〜q210、移動・封印・イベント・戦闘・両画面の回帰試験も維持します。
