# 地下水道・廃坑の固有設定

2026-09-26: [水路拡張と地下関所](WATERWAY_EXPANSION.md)を実装済み。

確認日: 2026-09-25。作品版1.20.0。現行の区画給排水、装備個体の塩、破壊壁を扱います。旧地下水道の潮汐・潜水・濡れと戦闘補正は[保存原文](../legacy/2026-09-25/WATERWAYS_SALT_MINE.md)、退避した立体区画は[保守仕様](VOXEL_TERRAIN_AND_WATER.md)に分けています。

## 現行の地下水道

乾いた操作室・荷揚げ場6区画と、水密扉で閉じた4水路を接続します。外の給排水盤を調べて排水し、接続口から移動します。排水状態は永続保存し、歩数による水位変動や潜水による扉通過はありません。現在地への給水と、完全水没区画への進入は拒否します。[2D区画仕様](CONNECTED_2D_MAPS.md)を参照してください。

セル・共有エッジの通水属性は保持しますが、区画単位の給排水からセル間の流体計算へ変更していません。浅水路・深水路の固定水深と、マップ全体が通行不可になる完全水没は別の設定です。[セル仕様](CELL_LAYERS.md)に適用範囲を記載しています。

## 廃坑の装備個体と塩

戦闘開始時に、生存する出撃隊員の装備個体それぞれへ塩を1加算します。逃走や敗北でも加算は取り消しません。戦闘中の保存再読込では重複加算しません。

`state.gear` は装備個体ID、道具の種類、塩、袋・人物の装備欄の所在を保持します。同じ種類の剣も別個体です。持替え・受渡しでは個体の塩を維持し、袋から装備するときは最も塩の少ない個体を選びます。袋の種類別個数と人物の装備IDは既存UI用に保持し、個体台帳との一致を保存検証します。

装備の正の能力補正それぞれから塩の累積数を引きます。str+5なら5戦で0、6戦で−1です。最終最大HPは1、他の能力は0を下限にします。装備変化で最大HP・MPが減れば現在値も範囲内へ収め、洗浄による自動回復は行いません。

上層・下層それぞれの(4,1)に水没した洗浄場所があります。進入すると所持・装備中の全個体の塩が落ちます。当面の仕様として廃坑からの退出時にも落ちます。既に失った装備は戻りません。

塩4以上の個体を持っていると通常遭遇にソルトイーターが現れます。初期HP35の弱い敵ですが、敵の行動時に生きていれば塩が最も多い対象1個を食べます。袋・装備欄のどちらにあっても個体を削除し、保存後も永久に失われます。同名の他個体をまとめて失わせません。

## 破壊壁

破壊壁は上層(6,1)・(3,6)、下層(6,1)・(10,9)。発破薬1個（基準25G）、または戦士・拳闘士Lv1の「岩砕き」（MP3）を使います。距離・対象・技能・費用を支払い前に検査します。開通は退出後も保存し、再操作では消費しません。

## 編集と保存

区画と接続は `config/connected-maps.json` と `config/dungeons/region_1.json`、廃坑は `config/dungeons/region_2.json`、セルは `config/cell-layers.json`、道具・技能は `config/dungeon-content.json` と `config/jobs.json` が正本です。[正本の対応](../authoring/CONFIG_EDITOR_SOURCES.md)を参照してください。

排水状態は `state.dungeons.persistent.region_1.systems.water.controls` に保存します。control IDごとのtrueが給水、falseが排水済みです。破壊壁は該当部品の永続状態 `broken`、装備個体は `state.gear` に保存します。旧内容版の移行は行いません。検査結果は[PROGRESS.md](../development/PROGRESS.md)を参照してください。
