# 戦闘と探索のバランス検証

更新日: 2026-09-18。対象: 作品版1.14.0。現在の敵は59定義、遭遇は82定義です。全13ダンジョンの環境補正を含め、配布JSONを検証の入力とします。敵ごとの基礎能力と出現先は[MONSTER_CATALOG.md](MONSTER_CATALOG.md)、職業は[JOB_SYSTEM.md](JOB_SYSTEM.md)を参照してください。

## 現在の調整対象

基準隊はアダ・ニオ・セラ・イルの4人です。最大5人まで編成でき、30職を選べます。地域別の推奨Lvは1〜10ですが、転職履歴、装備、技能の貸出、材料、残りHP・MPによって実際の戦力は変わります。人物定義の旧skills配列から現在の技能を推定しません。

敵の基礎数値は config/entities.json と config/dungeon-content.json、職業・技能・成長は config/jobs.json、各迷宮の補正は config/dungeons/*.json を編集します。全体の消費・成長・戦闘式の生成元は tools/build-content.mjs です。生成後の実値は data/system.json、data/formulas.json、data/enemies.json と各迷宮定義で確認します。

通常遭遇の確認は成功した移動7歩ごとです。マップ側の遭遇率・重み、暗闇の加算、職業、火・植物・護衛などの倍率が作用します。単一の18%を全マップへ固定した仕様として扱いません。固定戦闘、通常遭遇、用心棒・門番を分けて確認します。

## 自動検証と測定の範囲

`npm run check` は参照検査と回帰試験を実行します。現在の結果は[PROGRESS.md](PROGRESS.md)を参照してください。報酬・技能の成立条件・支払い・旧セーブ・通常資源による本編100本の進行を検査します。これは全200本を人が通して遊んだ結果ではありません。

`node tools/simulate-balance.mjs` は wild_ で始まる通常遭遇を対象に、初期4人とルカ・トーマ・ミカ・ドーラ・レンの5人隊を20seedで測定します。推奨Lv、HP・MP満タン、追加装備なし、戦闘中の道具とデバッグ回復なしの固定技能選択です。全勝、中央値6ラウンド以下、最長10ラウンド以下を検査します。出力先は doc/BALANCE_RESULTS.json で、その実行時の作品版を記録します。

`node tools/simulate-jobs.mjs` は基準隊のアダだけを30職へ替え、Lv1/5/10/30、3seed、計360戦を測定します。適合する武器と技能材料を支給し、固定方針で勝敗・行動数・ラウンド・最大HP欠損を記録します。出力先は doc/JOB_BALANCE_RESULTS.json です。単職だけの隊や最適な技能運用の比較ではありません。

両ツールのHP欠損は、各行動後の最大HPに対する不足HPの最大比率です。途中の回復を含むため累積被ダメージではありません。測定値は入力版・隊・装備・成長・seedと一緒に保存し、古い結果のversionだけを書き換えません。

## 固有環境を含む次の測定

満タンからの単発戦闘に加え、廃坑の腐食、沈没城の空気消費、深淵の逆行累積、谷の術制限、植物・火・護衛の倍率を伴う往復探索を測定対象にします。戦闘勝利率だけでなく、帰還時のHP・MP・材料・救援費と、通行可能な帰路を記録します。現在の単発シミュレーターだけで長期探索の難度を保証しません。

かばう・全体防御・バフの重複と期限、回復のMP・材料消費、MP回復の自己使用、敵のMP不足時の代替行動、禁止技能を使う敵AIを回帰対象として維持します。追加100本の移動距離・消耗・文量と、全200本の全経路監査は継続課題です。
