# 立方体地形・六面の境界・水と移動

仕様確定日: 2026-09-14。対象: 次期作品版1.8.0。利用者が承認した立方体モデルを実装します。従来の二次元マップは高さ0の通路として互換読込し、灯守の地下水道の貯水立坑から立体地形を導入します。

## 空間の単位

座標はmapと整数のx・y・z。zが1増えると立方体一個分上がります。一個は人物一人が立って収まる空間です。地形は密（#）と空（.）。密は岩・土・建材などが占め、人物も水も入りません。水は空の立方体の内容量であり、地形を密へ変更しません。

空間は東西南北と上下の六方向で接続します。二つの立方体は一つの境界面を共有します。境界面には通行、通水、足場の支持を独立して指定し、壁・水門・格子・床板・排水蓋を表します。密の上は床、側面は壁、下は天井になります。下も空で支持面がなければ穴です。

map.voxels.layersは低いzから並ぶ同寸の平面図、minZは最下層の高さです。従来のtilesはz=0の断面を保持します。立体定義のないマップはz=0のtilesを読み、下と上を密として扱います。古い地形変化部品は高さ0へ適用します。

## 水量と閉区域

空の一個の容量は3単位です。0は乾燥、1は足元、2は腰、3は完全水没。足元と腰は通行できます。完全水没した立方体への侵入・経路上の通過は標準で禁止します。梯子や縄の存在だけでこの禁止を解除しません。

水は通水可能な六面を通り、低い空間を優先して分布します。異なる場所の水は、途中の床・密の立方体・閉じた面を越えられる水位になるまで混ざりません。同じ高さの複数セルでできる窪地も、その外周と底で水を保持します。天井を閉じる必要はありません。外への開口から流れ出した水は排水量として記録します。

初期水量と給水装置が供給元です。閉じた場所へ自然に水を生成しません。水門を閉じると流れが止まり、残水は保持されます。排水蓋や壁を開けば再配分・排水されます。新しい水路では給水操作・境界変更・掘削の成立後に平衡を計算します。流速・波・圧縮空気・実時間の流体計算は行いません。整数単位のため、水面の細かい差は最大1単位残る場合があります。

既存の地下水道の周期水域は互換方式を維持します。既存水門の止水と排水の連動を、新しい六面の水門へ自動変換しません。貯水立坑では実際の容量・地形・境界から水没を決めます。

## 移動と手段

通常歩行は同じzの隣接空間への移動です。移動先が空、境界が通行可能、完全水没していない、足場があることを検査します。上下への素の移動、穴への落下、密の中への侵入はできません。

梯子・階段・ツタ・縄などは空の立方体を六方向にたどる具体的な経路です。各区間の通行と水没、到着先の足場を確認します。登りと下りの両方に手段が必要です。密の立方体や閉じた面を経路が貫く定義は拒否します。壁を越えるには上の空間を経由します。

移動手段は常設、材料による設置、隊を誘導する探索技能による一回の利用を定義できます。設置した縄は退場後も残ります。設置済みの再購入・再消費はしません。今回の隊用技能は技能者一人が仲間を誘導するものです。個人だけの飛行・泳法・別行動は今回の実装に含めません。

橋は上の立方体の下側に足場を作り、橋の下の空間を保持します。橋上の空間が乾いていれば通れ、下の立方体の完全水没を通過した扱いにはなりません。橋上まで水が達した場合はその立方体に水没判定がかかります。

## 操作・保存・退避

操作は表示と実行で同じplanを用い、距離・高さ・習得・出撃・生存・MP・材料・経路・到着を支払い前に検査します。不成立では水量・地形・所持品・位置・時刻を変更しません。設置、給水、面の開閉、許可された掘削を明示した対象へ行います。

水量、開閉した面、掘削した立方体、設置経路はダンジョンの永続状態へ保存します。現在地と踏査記録はzを区別します。z省略は旧マップの高さ0とします。旧版の保存は元の部品構成で検査してから、新しい部品の初期状態だけを補います。

足元が完全水没した場合は変更前に通行できた経路から安全足場への退避を検査します。現在地から退避できる足場がなければ既存の帰還印で救助します。密・壁・梯子のない上下経路を無視して自動移動しません。会話・戦闘の途中で給排水操作は受け付けません。

## 表示と編集

探索画面と地図は現在のzの断面を表示し、高さと水深を明記します。境界の壁、水門、床の穴、上下の接続、三段階の水を表示します。Viewは投影済みの空間・面・水深と操作可否だけを読み、ゲーム状態を変更しません。

編集元はauthoring/voxel-content.jsonとauthoring/dungeons/*.json。配布先のmap.voxelsとvoxel_space部品へ生成します。npm run build:dungeons、技能の変更を含む場合はnpm run build:jobsを実行し、Schema・参照・保存・通行・水の検証を行います。
