# 1.13.0 地下水道・立体マップの退避

基点：`f09601df2fa56b60d8380fb2910af02d489897a7`。2026-09-18、2D区画への再構成前にコピーしました。manifest.jsonに元の相対パスとSHA-256を記録しています。退避ファイルは改稿せず、旧挙動の再現資料として保持します。

通常プレイでは1.14.0の2D区画を使います。`data/game.json` から `waterworks_shaft` と `data/scripts/voxel-space.json` を外しています。立体原稿・実装を削除する移行ではありません。

旧レイアウトを調査するテストは `tests/legacy-map-helpers.mjs` がこのスナップショットを優先し、変更のない配布ファイルだけを現行ディレクトリから読みます。現行のシナリオ試験は通常の `tests/helpers.mjs` を使います。

復元を行う場合はこの退避資料と基点コミットを別ブランチで参照し、マップだけでなくダンジョン所属、ゲームのロード一覧、q002〜q010の配置・worldPlacesもセットで復元してください。現行のビルドは `tools/build-connected-maps.mjs` による2D原稿の適用を含むため、旧ファイルだけを配布先へ戻しても次の生成で上書きされます。
