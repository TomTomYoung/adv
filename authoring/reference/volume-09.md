# GQ081　白い矢筒
依頼と人物：弓兵隊長は、敵陣へ矢文を届ける護衛を頼みます。白い矢筒は停戦使者の印ですが、新任隊長はその意味を知らず、古参の臆病さと思っています。古参は部下の前で訂正して隊長の面目を潰したくありません。
展開と開示：古参が矢尻を外す動作を、戦闘準備不足に見せます。敵側からも同じ白い筒が掲げられ、双方に共有する慣習と分かります。ただし慣習を知らない傭兵も戦場におり、印だけで安全が保証されません。
状態と条件：`F.custom`は古参の説明を聞く、`F.enemy_ack`は相手の返礼を目撃、`F.mercenaries_told`は両陣の傭兵へ通達した履歴です。主人公の戦績を見せる場合は、威圧でなく護衛能力を説明する材料に限ります。
経路：準備→古参へ質問／直ちに前線→信号交換→対面／撤回。慣習を知り通達すれば安全な会談路、通達なしなら誤射の騒動から救援場面へ移ります。返礼がなければ勝手に停戦成立とせず戻れます。
結末と余韻：対面なら短い遺体回収の休戦を結べます。救援を優先しても使者の命は守れます。撤回なら別の伝達方法を探します。報酬は護衛料と敵側の通行保証。新任隊長が白い矢筒を古参へ返す時、部下の前で使い方を尋ねます。
# GQ082　一発も撃たない砲手
依頼と人物：魔導砲手オルは、砲台へ最後の魔石を運んでほしいと頼みます。司令は攻撃用と思っていますが、オルは砲を照明へ切り替え、夜間避難の道を示すつもりです。彼は昔の一射で得た名声を捨てたいのでなく、今できる仕事を変えたいのです。
展開と開示：照準は敵城でなく谷の岩壁へ向いています。壁に残る古い反射鏡の跡が、砲台の元の用途を示します。避難者が来ていない段階で点灯しても役立たず、軍が退却を勘づかれる危険もあるため、合図と移動の調整が必要です。
状態と条件：`F.mirrors`は反射鏡を設置、`F.convoy_ready`は避難隊の到着を確認、`F.order`は`attack/light/hold`、`F.stone_used`は発動時に一度だけ確定します。魔石は所持品から消費します。
経路：運搬→砲手の計画→司令と相談／避難隊へ連絡→発動。攻撃なら包囲敵との戦闘が有利になります。照明なら準備二条件が必要です。条件不足は発動保留にでき、魔石を無駄に消費しません。
結末と余韻：攻撃は軍事的成果、照明は避難路、保留は次の判断の余地を残します。命令に背いた場合の処遇と救援の功績は別に報告します。報酬は軍の謝礼か避難者の支援。照明の結末では、誰も砲声を聞かず、それでも遠くから歓声が返ります。拡張：魔導砲は専用場面で処理します。
# GQ083　勝者の洗濯場
依頼と人物：戦後の洗濯場で、同じ兵の軍服が何枚も届きます。係長は横流しを疑い調査を頼みます。兵士たちは死んだ友の名を自分の襟へ縫い、全員帰還したことにして遺族年金を止めないようにしています。目的は支援ですが、死の知らせも遺族の選択も奪っています。
展開と開示：泥は別々の戦場のものなのに、名札の糸は同じです。最初に金目当ての偽装を疑わせ、洗い代だけ兵たちが自腹で払っていることを見せます。遺族側には既に死を察している者と、本当に帰りを待つ者がいます。
状態と条件：`F.tags`は縫い直しを確認、`F.plan`は兵士の説明、`F.families_heard`は二家族の意向を聞く、`F.report`は`expose/transition/withhold`です。死者の名をプレイヤーの戦績へ関係付けません。
経路：衣類調査→兵士／遺族→報告と支援の選択。即時告発、実際の支援を確保してから訂正、当面の秘匿があります。支援確保は物資の引渡しか公的な受給確認で、口約束だけでは成立しません。
結末と余韻：訂正すれば弔いが可能になり、兵たちの処分問題は残ります。秘匿なら支援は続いても帰還の期待が長引きます。報酬は洗濯場の防寒着。遺族が受け取る服には、別人の泥を落とした後でも、何度も縫い直した小さな穴が残ります。
# GQ084　捕虜の鍋
依頼と人物：捕虜収容所の料理係が、盗まれた大鍋の捜索を頼みます。鍋は敵兵の料理人ジャルが隠し、断食している捕虜へ故郷の料理を作ろうとしています。監督は食事拒否を反抗と考え、ジャルは相手の食べ物を口にすれば屈服だと思っています。
展開と開示：捕虜は空腹でも配膳に手を付けず、鍋から同じ香草の匂いがすると近づきます。政治的な意味はありますが、慣れない味や調理法への拒否も混ざっています。全員を一つの信念で動かさず、一人は単純に焦げた食事が嫌だと明かします。
状態と条件：`F.pot_found`は鍋を発見、`F.recipe_shared`はジャルが料理係へ作り方を教える同意、`F.inspection`は材料の共同確認、`F.kitchen`は`separate/shared/confiscated`です。
経路：捜索→隠し厨房→没収／別鍋を貸す／共同炊事を交渉。共同には検査と本人の協力が必要です。材料が不足すれば似た料理でよいか捕虜へ相談できます。拒否されたら普通食と別鍋を併存させられます。
結末と余韻：共同炊事は交流、別鍋は距離を保った改善、没収は規律と不満を残します。食事の改善を戦争の正当化にしません。報酬は携行食。二人の料理人が、捕虜と看守の話より先に、相手の火加減へ文句を言い合います。
# GQ085　橋を落とさない理由
依頼と人物：撤退軍は、追手を止めるため古い橋の封鎖を命じます。橋守ネヴは最後まで閉鎖を拒み、兵に裏切り者と疑われます。彼が待つのは敵でなく、反対岸へ出稼ぎに行った両国の家族です。指揮官にも、待つほど部隊を危険にさらす責任があります。
展開と開示：橋守は人の顔より荷車の車輪を見ています。目印は故郷で修理した車輪の印で、言葉や軍服では帰還者を判別できません。最後の荷車に敵兵も混じり、避難者を守るため装備を置いています。
状態と条件：`F.wagon_mark`は車輪の印を知る、`N.groups`は三組の通過完了、`F.enemy_disarmed`は当該兵が武器を置く合意、`F.bridge`は`open/closed/abandoned`です。時間は敵の接近を三つの場面で示し、会話を読むだけでは進めません。
経路：橋頭→荷車確認→通過を待つ／即時封鎖／別の渡河を支援→撤退。戦闘で時間を稼ぐ、舟を費用で確保する、最後の組を別隊へ託す代案があります。逃走した場合は自軍撤退へ移り、通せた組だけを記録します。
結末と余韻：待機成功なら両国の家族が渡ります。早期封鎖なら部隊を守り、残った人々の救援を約束できます。報酬は軍需品または橋守の謝礼。橋が使えなくなった後、ネヴは車輪の印を別の渡し場にも刻みます。
# GQ086　返事のない停戦
依頼と人物：停戦交渉で、敵砦から同じ定型文だけが返ります。交渉官ハスは侮辱と受け取り、強硬策を求めます。実際の砦司令は負傷し、留守番の若い通信士が権限を持たず、返答機の定型を使い続けています。
展開と開示：文面の同じ誤字が、時刻だけを変えて繰り返されます。相手が嘘をついているのではなく、意思決定できる人がいないと分かります。通信士は降伏を決めれば帰郷後に家族が責められると恐れています。
状態と条件：`F.repeat_error`は二通を比較、`F.medic_report`は負傷の情報を独立に確認、`F.authority`は`unknown/deputy/council`、`F.truce`は`none/local/formal`です。受け取った文書と実際の合意を同じフラグにしません。
経路：交渉所→返答の比較／使者の対面→臨時の局地休戦／代理権の取得待ち／交渉打切り。局地休戦なら物資搬入や負傷者交換だけを合意します。正式停戦には権限確認が必要です。打切りでも捕虜の安全を別に相談できます。
結末と余韻：小さな合意から正式停戦へ進めますが、必ず成立するとはしません。強硬策なら砦戦へ、待機なら双方の兵站負担が増えます。報酬は交渉料。最後の返書は短く、誤字もありますが、通信士自身の言葉です。
# GQ087　旗を持たない兵士
依頼と人物：国境村は、所属を示さない武装者の調査を頼みます。彼は三度所属を変えた兵カドで、村を守る仕事だけを続けています。村長は実績を信用し、駐留将校は忠誠の証明を求めます。カドは旗が変わるたび同じ村が敵領になることに耐えられません。
展開と開示：過去の隊章が外套の裏へ縫われ、隠し持った工作員に見えます。だがどの章にも同じ救護所の糸が使われています。彼を無条件の善人にはせず、敵軍として村から徴発した過去も本人が認めます。
状態と条件：`F.service`は村人の目撃証言、`F.requisition`は徴発の告白、`F.oath`は`national/local/none`です。プレイヤーの討伐戦績をカドの功績に転用しません。共同防衛の結果だけは指定遭遇のWと目撃で共有できます。
経路：調査→駐留所／住民／本人→野盗防衛→任用の判断。国旗を掲げる条件、村への限定契約、退去があります。戦わず住民を退避させても守った行為として報告できます。
結末と余韻：国軍任用は補給と命令、村契約は自治と責任、退去は将校の安心と村の人手不足を残します。報酬は村の宿泊と補給。村契約の外套には新しい旗でなく、守る橋と井戸の名前が縫われます。
# GQ088　帰還兵の席
依頼と人物：行方不明だった兵士ラフを故郷へ送ります。妻は帰還を喜びますが、彼がいない間、弟と店を切り盛りして生活を作っています。弟は妻の恋人ではありません。しかしラフは家で役割を失ったことを、誰かに奪われたと感じます。
展開と開示：食卓の席が変わり、使っていた道具が別の棚へ移っています。妻は彼の存在を消したのではなく、怪我した自分でも届く位置へ動かしました。小さな変更を疑惑として見せ、理由を一つずつ知れるようにします。
状態と条件：`F.changes_explained`は家族が変更の理由を話す、`F.injury_heard`は妻の事情を聞く、`F.role`は`old/shared/new_work`です。帰還した事実と同居再開への同意を分けます。
経路：帰郷→家の観察／家族との個別会話→同じ仕事へ戻る／役割を再分担／別の住まいから交流。本人が怒って家を出ても追跡戦にはせず、落ち着く場所で話せます。護衛依頼は安全な到着で達成し、家庭を仲直りさせることを報酬条件にしません。
結末と余韻：旧役割の回復は弟の仕事を別に探す負担、分担は新しい技能、別居は距離を守る再会になります。報酬は旅費と店の補給。食卓に古い席が戻る結末だけを成功にせず、三人で新しい机を持ち上げる場面も用意します。
# GQ089　敵国の子守歌
依頼と人物：避難所で子守歌を歌う薬売りアサが、敵国の暗号を使ったと疑われます。看守は昔その旋律を軍の合図として聞きました。アサの故郷では普通の歌で、軍が後から借用したものです。彼女は疑いを晴らすために、避難者全員の出身を暴かれたくありません。
展開と開示：同じ旋律でも、軍の合図には欠けている終わりの一節があります。最初は看守の記憶も正しく扱い、別の用途が共存すると示します。眠りかけた子どもが歌の続きを言う場面が、公開の証言を要求する前にあります。
状態と条件：`F.full_verse`は歌の全節を聞く、`F.old_songbook`は戦前の歌集を確認、`F.asa_consent`は本人が由来説明に同意、`F.policy`は`ban/context/private`です。
経路：呼出し→歌集／看守の記憶／本人への面談→禁止・事情説明・私的使用。歌集があれば出身者を名指しせず由来を説明できます。証拠不足でも即時処罰でなく保留を求められます。
結末と余韻：事情説明なら見張りの確認方法が改められます。私的使用なら歌える場所だけ守れます。禁止なら秩序は保たれても夜泣きと緊張が増えます。報酬は薬売りの物資。看守が夜番で無意識に続きを口ずさみ、そこで自分が軍の節しか知らなかったと気づきます。
# GQ090　終戦翌日の魔物
依頼と人物：終戦が決まった翌日、戦場の骸骨獣が補給村を襲います。軍は撤収を急ぎ、冒険者への討伐依頼だけを残そうとします。兵站係フウは、戦争が終われば危険も終わると家族に手紙を書いたばかりです。
展開と開示：魔物は敵国の呪いだけでなく、放置された軍用魔石の残響へ集まっています。旗が下りても戦場に残った物は消えません。戦勝式の遠い花火と、地面の骨の振動を交互に見せます。敵を倒す必要と後片付けの必要を分けます。
状態と条件：`K(bone_hound)`は受注後の討伐、`N.stones_removed`は三つの封鎖区画から回収した数、`F.handover`は村へ管理責任を押し付けず受取体制を合意した履歴です。
経路：襲撃防衛→魔石源の確認→討伐だけ／軍を引き留めて回収／避難を優先。回収は三か所の封鎖と安全な保管先が必要です。兵が去った後でも冒険者の増援で続けられますが費用が変わります。戦闘撤退なら避難の結末へ接続します。
結末と余韻：討伐だけでは次の群れが来る余地を明記します。回収なら地域の復旧が始まります。避難なら村の再建が後日の課題です。報酬は軍需品と復旧契約。フウは帰還日を消して、手紙の末尾へ「片付けてから帰る」と書き足します。
