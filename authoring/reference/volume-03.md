# GQ021　百匹目の狼
依頼と人物：牧場主の依頼で狼を追うと、老猟師バスクが最後の一頭だけ譲れと言います。彼は百頭倒せば亡き兄への弔いが済むと誓い、今は九十九頭です。牧場主は数字より今夜の羊を守ってほしく、バスクの娘は誓いが終わった後の父を心配しています。
展開と開示：父の猟帳には九十九の印がありますが、最後の印だけ何度も書き直されています。百頭を達成できないのではなく、達成すれば兄を忘れるのではないかと恐れています。狼は実際に羊を襲っており、猟師の事情を知っても防衛の必要は消えません。
状態と条件：`K(moor_wolf)`は受注後の討伐、`F.ledger`は猟帳を本人に見せてもらう、`F.fence`は牧場の囲いを修復、`F.last_hunt`は`unset/assisted/alone/retired`です。猟師自身の過去九十九頭は固定された物語情報で、プレイヤー戦績へ足しません。
経路：牧場→巣の追跡／囲い修繕→バスクとの対話→共猟／単独討伐／防衛と引退。共猟は生存して同行する本人が必要です。退却なら囲いへ戻れます。修繕のみでも今夜の防衛を達成できますが、狼は後日の地域危険として残ります。
結末と余韻：共猟なら最後の一撃の功績をどう語るか本人に委ねます。単独なら被害は止まっても誓いは未完です。引退なら娘が猟帳を捨てず、本棚へ戻します。報酬は毛皮の外套か防衛料。百の印を書いたバスクが、空いた次の頁へ兄の名を書く場面を置けます。
# GQ022　逃げた竜殺し

展開と開示：出発前、彼が逃走経路を三度確認するため、臆病さを疑わせます。巣では親竜が見えず、出口に突然帰ってきます。予告した退路が、そのまま反撃の位置へ変わります。退く判断が攻略の一部であることを、演説でなく空間で示します。
状態と条件：`F.route`は退路の確認、`F.lure`は餌場の準備、`F.rek_present`は帰還時の目撃ではなく当該場面で同行と生存を検査します。`W(valley_drake)`と`E`は結果として読み、逃走ゼロを成功条件にはしません。
経路：準備→巣への進入→討伐戦／誘導退避→帰還。誘導は退路と餌場が必要です。戦闘から逃げても用意した餌場へ接続できます。準備なしの逃走は安全な麓へ戻り、次の出撃を組み直します。
結末と余韻：討伐なら槍兵は戦利品を得ます。誘導なら谷は空きますが、移転先を見張る仕事が残ります。再挑戦を断ればレクが別隊を募ります。報酬は竜対策の装備。後日、槍兵が武勇を語る時、レクは割り込まず、卓の端に退路の地図を置きます。
# GQ023　討伐数ゼロの勲章
依頼と人物：城門の守備隊長が、避難者を通す間の足止めを頼みます。義勇兵アムは一頭も倒せなければ臆病者と思われると焦ります。医師は戦闘の腕より、戻って来る担架の少なさを評価します。
展開と開示：敵は橋の腐肉鬼で、追撃すれば勝利と引き換えに門の守りが薄くなります。アムは最初、敵の数を数えています。避難の途中から、手を離してはぐれた人の数を数え始めます。危険を生むのは善意の不足ではなく、異なる達成指標です。
状態と条件：`N.evacuated`は三つの避難組を門へ導くたび1増加、`F.bridge_closed`は最後に橋を封鎖、`F.chased`は追撃を選んだ履歴です。討伐は`K(carrion_ghoul)`で別集計します。足止め成功は専用場面の達成で、勝利数を偽って増やしません。
経路：城門→第一組→第二組→最後の組→門閉鎖。各区間で防衛、誘導障害物、追撃を選びます。追撃した区間は避難が一段遅れ、次区間の応援を呼べます。三組を運べなくても救えた人数を確定し、救援継続へ移る終端があります。
結末と余韻：討伐ゼロでも全員通せば勲章が出ます。追撃で首領を倒せば次の襲撃は減りますが、負傷者の後日談が加わります。部分成功なら功績と不足を同じ報告に残します。報酬は避難実績に対応する謝礼。アムの勲章の裏には、敵の名でなく門を通った家々の名が彫られます。
# GQ024　二度死んだ大猪
依頼と人物：村の鍛冶屋は、大猪の討伐報告が二度届いたので調査を求めます。二人の猟師は互いを詐欺師と呼んでいます。しかし猪は双子で、同じ焼印を付けられた家畜が野生化したものでした。元の飼主は被害弁償を恐れ、名乗りません。
展開と開示：牙の欠け方は似ていますが、左右が反対です。最初の報告だけで片方を嘘つきにできない証拠を見せます。飼主が二頭分の餌桶を一つずつ隠す姿を置き、復活怪異の仮説から、同一視された二個体へ読みを変えます。
状態と条件：`F.left_tusk`、`F.right_tusk`は証拠の確認、`F.owner`は餌桶と焼印を照合、`F.report`は`unset/fraud/twins/unknown`です。新たに現れる猪は同一定義IDの二個体として討伐されます。過去の他人の討伐をプレイヤーのKへ加えません。
経路：報告の比較→猟師二人／飼主の納屋→残る被害の確認→結論。二つの牙を比較すれば飼主を知らなくても双子説を確定できます。納屋へ入る許可が得られなければ公開の家畜市記録で代替できます。確信がなければ保留報告も可能です。
結末と余韻：双子を認めれば二人に正当な報酬が出ます。飼主の責任は、彼が協力したかで弁償交渉が変わります。誤告発なら後日訂正を求められます。調査料と猪革が報酬です。仲の悪かった猟師が、二本の牙を左右揃えて飾る場面で閉じます。
# GQ025　弓を置く日
依頼と人物：森番ユノは、縄張りを越えた角獣を追うため、引退した師オサを説得してほしいと頼みます。師は殺した数を弟子の成長の証と教えてきました。今のユノは、増えた討伐数より、畑が荒れなくなった理由を知りたがっています。
展開と開示：角獣の群れは餌場を失っています。強い個体を倒す必要がある場合もありますが、群れ全体の追撃では移動が終わりません。師は知識が間違っていたのではなく、自分の弓以外の解決を弟子へ渡せずにいます。
状態と条件：`F.forage`は失われた餌場を確認、`F.passage`は村が迂回路を空ける同意、`F.master_observed`は師が新しい誘導を実見した時です。`K(thorn_stag)`は戦果、角獣の通過完了は別の確定イベントにします。
経路：弟子の相談→師／森の調査→暴れる先頭個体への対応→群れを討つ／迂回路へ誘導。誘導は餌場の理解と通過路が必要です。先頭を倒してから誘導する混合解決も認めます。調査中に退けば畑の柵を守る小目標へ切り替えられます。
結末と余韻：討伐なら今季は安全ですが、森番は来季も警戒します。誘導ならユノが新しい役割を得ます。師が目撃していなければ理解には後日の実演が必要です。報酬は森道の通行許可か角材。師は弓を捨てず、弟子に渡す笛の穴を削ります。

# GQ027　魔物の借金

展開と開示：同じ借主の名が別の人形から現れ、Kが増えても借主の戸口の印が消えません。討伐数が虚偽なのではなく、除去した個体数と契約の終結が別なのです。術者は利息を取り続けるため、核の処理法を教えていません。
状態と条件：`K(debt_golem)`、`F.transfer`は核の移動を目撃、`F.release_terms`は契約解除条件を入手、`F.contract`は`active/suspended/released`です。記録から個体復活を推測せず、新個体の生成を場面で示します。

結末と余韻：封印なら当面安全、解除なら泥は作業用へ戻ります。破壊なら傭兵への請求と借主の支援が並行します。報酬は固定の後始末料で、Kによる無限加算はありません。帳簿係が初めて「何体倒したか」でなく「もう出ないか」を確認します。拡張：再生成は有限の固定遭遇列で扱います。

# GQ030　最弱の王
依頼と人物：冒険者組合は、低級魔物を束ねる苔冠王の討伐を依頼します。熟練者は弱い敵に時間を使いたがりません。案内役の新米テオは大物を倒したいと焦りますが、村を困らせるのは王の強さではなく、細かな通路を使う群れの連携です。
展開と開示：王を倒すと別の小型個体が苔冠を拾い、同じ侵入が続きます。王という呼称から単独の支配者を想像させ、実際は王冠が誘導具だと分かります。テオは見栄を捨てるだけでなく、弱い相手にも観察が必要だと学びます。
状態と条件：`K(moss_crawler)`は個体数、`F.crown_seen`は冠の引継ぎを目撃、`F.tunnels`は抜け道三か所の封鎖完了、`F.crown`は`active/sealed/studied`です。穴ごとの状態を正準の物体状態で管理します。
経路：襲撃防衛→王を倒す／通路を調べる→冠の処理。冠を封印すれば群れは散ります。穴を塞げば居住地だけ守れます。冠を研究者へ預けるなら運搬中の護衛が追加されます。討伐だけを続ける道も回数上限で再相談へ戻し、無限報酬にしません。
結末と余韻：封印は脅威を除き、研究は今後の道具へ、封鎖は共存ではなく境界管理へつながります。報酬は村の装備修繕。テオが武勇談を始める時、王の大きさではなく、三つ目の穴を見落としかけた話から始めます。
