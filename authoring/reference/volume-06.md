# GQ051　暗殺者の遅刻
依頼と人物：領主の側近が、祝宴へ来る暗殺者の捕縛を依頼します。予告時刻を過ぎても現れません。側近は領主への同情を集めるため、偽の襲撃を仕込んでいました。雇われた役者は直前に危険を悟って逃げ、本物の政敵だけが計画を知って会場に残っています。
展開と開示：側近は入口より客席の反応を気にし、合図の楽曲を何度も延長させます。衣装部屋の刃のない短剣で芝居の企みを示し、その後、給仕が本物の結界切断具を見つけます。偽装を見抜いたから安全、という二度目の思い込みを揺らします。
状態と条件：`F.staged`は小道具と役者の証言を確認、`F.real_tool`は給仕から現物を受領、`F.lord_warned`は本人へ知らせる、`N.program`は宴の演目を進める選択で増え、3演目後に本物の襲撃が始まります。
経路：祝宴→舞台裏／役者を追う／給仕を守る→領主へ警告／宴を止める／囮として続行。続行は本人の同意と防衛準備が必要です。偽装の暴露だけを先行すると混乱が起き、本物を追う経路が変わります。
結末と余韻：中止なら命を守り、側近の責任を別に追えます。囮成功なら政敵を捕らえますが領主の危険利用も公になります。警告が遅れれば負傷後の救援へ移り、勝利宣伝で上書きしません。報酬は護衛料。逃げた役者が後日、本当に誰も倒れない芝居を演じます。
# GQ052　密書を読ませる仕事
依頼と人物：密偵カナは、敵の目を避けて密書を運べと頼みます。しかし彼女は敵に読ませることを狙い、わざと目立つ封をしています。書かれた偽の移動計画で敵兵を空の谷へ引き、包囲された味方を逃がすためです。同行の若い伝令は、秘密を守る仕事に誇りを持っています。
展開と開示：カナは安全な道を提案されるたび理由を変えて反対します。封の模様と別の捨て文書が一致し、漏洩が予定されていると分かります。伝令は囮になること自体より、知らされず失敗者にされることへ怒ります。
状態と条件：`F.plan_known`はカナへ問い直して計画を聞く、`F.courier_consent`は伝令が囮役へ同意、`F.delivery`は`sealed/intercepted/revised`です。敵が密書を得たことは指定遭遇の受渡しイベントで確定し、単なる逃走回数では判定しません。
経路：密書受領→尾行の確認→密封を守って届ける／計画を承知して奪わせる／別の偽情報を交渉。囮戦で逃げても、密書を残したかで結果が違います。本人の同意なく囮を続ける道は選べますが、その裏切りを関係へ残します。
結末と余韻：密封配達は命令の表面を守る一方、救出の別案が必要になります。承知した囮なら伝令は偽の失敗報告にも自分の条件を付けます。撤回なら計画は遅れます。報酬は諜報料。伝令が新しい封を押す時、何を守る封なのか先に尋ねます。
# GQ053　招待されなかった伯爵
依頼と人物：城の侍従は、招待状のない伯爵を追い返してほしいと頼みます。本人は本物ですが、爵位を娘へ譲った後も自分が代表だと思っています。娘は新しい同盟を結ぶため、父の反対を避けて招待から外しました。敵国の使者は父を利用して交渉を壊そうとします。
展開と開示：偽物を示すはずの紋章の違いが、父が古い印を使っているだけだと分かります。使者は父の昔話だけを丁寧に聞き、現行条約の話をしません。父は尊重される快さと政治的利用を混同します。
状態と条件：`F.succession`は現当主を確認、`F.envoy_offer`は使者の取引を父か目撃から知る、`F.role`は`none/guest/adviser/excluded`です。父を現代表として紹介した履歴は会談側にも残します。
経路：門前→系譜確認／父との対話→娘へ取次ぎ→客として入れる／助言役を合意／退去。身元確認だけでは代理権は得られません。使者へ渡る前に役割を決める機会があり、早く利用を見抜けば父本人へ説明できます。
結末と余韻：客なら父は口を挟まない条件を受けます。助言役なら娘が必要な部分だけ頼みます。退去なら会談は守られ、家族の関係は後日へ残ります。報酬は城内の紹介状。父が帰り際、古い印を隠すのでなく、娘の印の隣へ置くかが余韻を変えます。
# GQ054　鍵を盗まない泥棒
依頼と人物：盗賊エノが、財宝庫の鍵を盗まずに一晩だけ持ち主を足止めしてほしいと頼みます。鍵は持主がいる場所を庫の入口にする転移具です。エノは鍵を奪うのでなく、持主を自分の倉庫へ誘い込むつもりです。庫番は中に預けた他人の品まで危険にさらしたくありません。
展開と開示：宴会の招待先が空の倉庫と重なり、鍵穴のない扉が持主の足元にだけ現れます。盗賊は「誰も傷つかない」と説明しますが、預り品には取り戻せない遺品もあります。財宝を一括の無人格な金として扱いません。
状態と条件：`F.portal_rule`は転移を目撃、`F.deposits`は庫番から保管内容を聞く、`F.host_informed`は持主へ誘導を警告、`F.operation`は`theft/sting/cancelled`です。
経路：依頼→会場下見／持主の護衛→仕掛けを知る→盗みに協力／庫番と捕縛を組む／契約を破棄。協力しても個々の所有者を知る機会を残します。捕縛は庫番の同意と預り品を避難させる準備が必要です。失敗すれば脱出か自首で終結します。
結末と余韻：盗めば利益と被害者からの追跡が残ります。捕縛ならエノを取調べに渡し、庫の仕組みも見直されます。破棄なら報酬はありませんが被害を予告できます。庫番が最後に数えるのは金額でなく、返却先の残った札です。拡張：転移具は固定場面の移動だけに限定します。
# GQ055　味方の密告
依頼と人物：反乱軍の連絡係ベルナは、仲間を密告した者を探しています。密告者は穏健派の兵で、襲撃予定を漏らして市民の巻き添えを防ぎました。しかしその情報で別の仲間が捕まり、本人はそこまで予測していません。
展開と開示：密告文は標的の位置を省き、市民の集まる時刻だけを強調しています。正義の密告として一方的に許さず、何を知り何を予測できなかったかを分けます。ベルナは裏切り者を裁くより先に、捕虜を取り戻したいと途中で目的を切り替えます。
状態と条件：`F.message`は密告文を取得、`F.intent`は本人の説明、`F.prisoner_route`は捕虜の移送先確認、`F.disclosure`は`internal/public/withheld`です。真相と、誰へ知らせたかを別に残します。
経路：文書調査→密告者との面談→救出を先行／内部審議／公開告発。密告者を協力者にするなら本人の同意で移送情報を使えます。救出に失敗しても責任の判断へ戻れます。真相を知らず疑わしい者を処罰する道では誤判定が後日判明します。
結末と余韻：内部審議なら作戦の承認手順が変わります。公開なら組織は割れますが市民は危険を知ります。秘匿なら短期の団結と同じ問題の再発リスクが残ります。報酬は救出に応じた支援。ベルナは会議で、市民のいる時刻を誰より先に尋ねるようになります。

展開と開示：牢には内側から開けられる扉があり、食器は他の避難者と同じです。捕虜でないと即断させず、移動の自由と安全の保証が別だと示します。砦側も彼を政治的盾として利用しており、永久の避難所ではありません。

結末と余韻：捕縛なら組織の安全と家族の救援が分かれます。逆取引なら脅迫者を追えます。逃亡ならセルは革命の祝辞から消えます。報酬は密偵料または協力者。再び演説を聞く場面で、セルは拍手せず、最後まで言葉を聞いています。
