# GQ071　足音を持ち帰る
依頼と人物：迷宮から戻った靴職人ダイの後ろで、必ず一歩遅れて足音がします。妻は家へ入れたくなく、ダイは自分が疑われたと怒っています。足音は、迷宮の追跡者が地上への道を覚えるため付けたものです。悪意ある怪異として、家族の不信とは別に実在させます。
展開と開示：ダイが止まると音も止まりますが、彼が寝た後も、昼間歩いた道を小さく再現します。最初は気のせいに見せ、雨の降らない軒下にも濡れた靴跡が続くことで外在する脅威と示します。妻は冷たいのではなく、家の入口を教えることを恐れています。
状態と条件：`F.replay_seen`は夜の再演を目撃、`F.origin`は迷宮の境界印を確認、`F.path`は`unknown/home/loop/returned`です。追跡開始後の歩数差分を読み、12歩で覚え込みの判定をします。相談と休息では歩数を増やしません。
経路：靴店→境界調査／歩行試験→迷宮へ戻す／閉じた輪を歩かせ封じる／家の周囲を防衛。輪の封じは境界の規則と準備した護符が必要です。期限に達した場合は追跡者が現れ、戦闘または避難へ接続します。
結末と余韻：返還なら道を断ち、封印なら輪の維持が残ります。討伐しても家族の言い争いは別に話し直します。報酬は防音靴。ダイが帰宅する最後の場面では、一人分の音がしてから、妻が戸を開けます。拡張：追跡は指定評価地点のスクリプトで処理します。

展開と開示：衣類には二種類の名の刺繍があります。ルイは家の期待から逃れるため「誰も昔の私を呼ばないで」と願い、井戸は本人の記憶まで奪いました。願いの曲解を本人の責任だけにせず、取引内容を説明しなかった主の企みとします。
状態と条件：`F.old_name`は母の証言、`F.chosen_name`は本人の作品の署名、`F.wish`は井戸の残響で願いを確認、`F.settlement`は`restore/new_name/seal`です。名前は状態・呼称で管理し、人の存在IDは変更しません。
経路：工房→母／作品市→井戸→元の名を返させる／新たな名を本人が選ぶ／主を封じる。二つの名を知れば取引の対象を特定できます。新たな名はプレイヤーが勝手に付けず本人が決めます。交渉決裂は封印の戦闘または退避へつなぎます。
結末と余韻：復元なら両方の名と過去を取り戻します。新名なら記憶の一部を探す旅が残ります。封印なら水源の代替を手配します。報酬は織物。母が新しい呼び名を一度間違え、言い直す短い応答を残します。

展開と開示：夫の悪い癖を知らず、良い思い出だけを正確に演じます。妻は早くから別物と気づいていますが、帰ってくる音を失いたくありません。精霊にも、誰かにならなければ家に居場所がないという誤認があります。
状態と条件：`F.memory_gap`は相違を確認、`F.tera_admits`は妻が認識を語る、`F.spirit_origin`は墓地の記憶石を調べる、`F.arrangement`は`parting/guest/imitation`です。

結末と余韻：別れなら記憶は墓地へ戻ります。客なら精霊が自分の呼び名を持ちます。模倣なら安らぎと緊張が共存します。報酬は夜道の護符。客になった精霊が、夫の好物ではない料理を初めて頼み、テラが少し考えてから台所へ向かいます。
# GQ074　泣かない葬列

展開と開示：列の人は楽しそうでも足は擦り切れています。道化師の娘だけが列に加わらず、父への怒りを抱いています。彼女は葬儀を終える道具として泣くことを要求されたくありません。悲しい話を集めて涙を点数化する仕組みにはしません。
状態と条件：`F.rule`は弔いの古い取り決めを知る、`F.daughter_heard`は娘の話を最後まで聞く、`F.mask_removed`は道化師の仮面を本人の遺志に従って外す履歴です。
経路：葬列へ近づく→列の観察／娘と対話／道化師の小屋→弔いをやり直す／棺を封じる／列から人だけ救出。泣く代わりに、死者を役柄でなく個人として呼ぶ言葉でも弔いは成立すると小屋の遺書で示します。
結末と余韻：個人として送れば葬列は止まり、娘は怒ったまま帰ってもかまいません。封印なら土地に怪異が残ります。部分救出なら次の弔いへ時間を稼げます。報酬は旅の護符。最後の笑いは止められた反応でなく、誰かが思い出した本当にくだらない芸への笑いです。
