# GQ061　治さない傷
依頼と人物：祈祷師イネは、治療を拒む剣士の説得を頼みます。剣士の魔法傷には、取り込まれた仲間の最後の言葉が残り、治癒すると声も消えます。イネは痛みを消したい。剣士は声を忘れた時、自分だけが生き残ったことになると恐れています。
展開と開示：傷に耳を寄せる様子を見せ、呪いを育てているように思わせます。声は本人の返事を聞けず、決まった言葉だけを繰り返します。剣士はそれを知っています。真実を説明すればすぐ治療に同意する人物にはしません。
状態と条件：現在の負傷はHP、`F.voice_heard`は本人の許可で声を聞く、`F.recorded`は記録具へ写す、`F.consent`は治療へ同意した時です。治療後に声が残るとは約束せず、写しは元の存在と別の記録として扱います。
経路：面会→声を聞く／記録具を探す／本人の希望を聞く→治療・記録後の治療・保留。記録具がなくても保留できます。治療可能な仲間がいる場合は実施手段を変えますが、同意条件を省きません。
結末と余韻：治療なら声は消えます。記録後なら再生するかどうかを本人が選べます。保留なら痛みを抱えたまま次の相談の約束を残します。報酬は護符と助力。治った剣士が、声のない間を自分の言葉で埋めようとして、一度言い直します。拡張：声の消失は専用イベントであり、一般的な傷の性質ではありません。
# GQ062　騎士の盾を借りる
依頼と人物：騎士エルドは、姪の成人式まで家の盾を運んでほしいと頼みます。盾には領民を守る誓いが刻まれています。姪は騎士にならず船大工になるつもりで、エルドは盾を受け取れば気が変わると期待しています。
展開と開示：道中の橋で荷車が倒れ、盾を足場にすれば救助できますが家紋が傷つきます。姪の職業選択は到着前から手紙で知れるようにし、盾をどう使ったかが後の会話の根拠になります。騎士だから必ず正しく、職人だから誓いを捨てるという構造にはしません。
状態と条件：盾は実際の装備可否と所持状態を使います。`F.used_for_rescue`は救助に使用、`F.letter`は姪の希望を本人の手紙から知る、`F.handover`は`ceremony/workshop/returned`です。
経路：受領→橋の事故→盾を使う／別の資材で救助／応援へ引継ぎ→成人式。資材不足でも盾使用か引継ぎが可能です。盾の傷を隠すか説明するかも選べ、後で修理痕が見つかる場合は嘘の履歴を残します。
結末と余韻：式で渡せば姪は受取と進路を別々に答えます。工房へ渡せば盾は船の試作時の防護板になります。返せば家の象徴を本人に強いません。報酬は船旅の紹介か騎士の謝礼。姪が家紋の傷を埋めず、その脇へ救助した人の名を小さく彫ります。
# GQ063　盗賊の初仕事
依頼と人物：元盗賊ソムは、鍵師として初めて正式な依頼を受けます。依頼人は昔ソムに盗まれた店主で、腕を認めつつ信用しきれません。同行を頼まれた主人公は保証人ですが、店主は保証人がいる間だけ金庫を開けさせる条件を出します。
展開と開示：ソムは昔の侵入路を知っており、速く直せます。しかしそれを説明すれば別の未告白の盗みが明らかになります。謝罪すれば全て許されるのではなく、返す物と修理代をどう分けるかを話します。
状態と条件：`F.old_route`はソムが侵入路を説明、`F.owner_told`は店主へ告知、`F.inventory_checked`は開錠前の立会い確認、`F.contract`は`repair/restitution/declined`です。盗賊職の技能は作業の一手段で、職名を犯罪の証拠にしません。
経路：契約→金庫の外観確認→旧経路の利用／別手段の修理→開錠と照合。立会人不在なら鍵は開けず、別の日へ延期できます。昔の品が中から出ても、勝手に持ち帰らせず所有者の確認へ回します。
結末と余韻：修理だけなら慎重な取引が始まります。弁償を合意すれば長い返済が残ります。辞退でも店主は別業者を紹介します。報酬は正式な修理代。ソムが最後に扉を閉め、誰も見ていない裏口ではなく、正面の受取印を待ちます。
# GQ064　吟遊詩人抜きの宴
依頼と人物：宿の常連は、いつも皆を歌へ巻き込む吟遊詩人ペルに内緒で送別会を開きたいと言います。本人は仲間外れを疑います。客は嫌っているのではなく、彼の前では話の途中でも歌にされるため、一度自分たちの言葉を揃えたいのです。
展開と開示：本人のいない席では失敗談が悪口に聞こえますが、客はその話を送辞にするため本人の傷つく部分を削っています。ペルにも、沈黙が怖くて歌い始める理由があります。聞き耳で断片だけ得た時と、客に尋ねた時で認識を分けます。
状態と条件：ペルの同行は現在状態で判定します。`F.fragment`は断片を聞く、`F.farewell_plan`は主催者から計画を聞く、`F.listen_promise`は本人が最後まで聞くと約束した履歴です。
経路：準備依頼→ペルを別用事へ案内／事情を説明／席へ同伴→送別会。本人不在は準備会話の条件にだけ使い、追放を強制しません。話を漏らした場合はサプライズでなく、本人も準備に加わる会へ変わります。
結末と余韻：秘密を守れば不器用な送辞が届きます。説明すれば本人が歌わず待つ試みをします。同伴なら話を遮ったかの明示選択で宴の様子が変わります。報酬は宿の紹介。別れの歌は短く、客の話を一つも引用しないものになります。
# GQ065　仲間を外す依頼
依頼と人物：商人リナは、護衛隊の魔法剣士カイルを外して商談へ来てほしいと頼みます。カイルの出自への差別を疑わせますが、彼はリナが昔支援した弟で、家族に仕事を救われたくないと言い続けています。リナは助けたいが、支配していた頃へ戻りたくありません。
展開と開示：カイルの前では値段の話しかしない商人が、不在時には彼の苦手な料理を覚えています。秘密の援助を受けるかどうかは本人の問題です。主人公が同席条件を満たせば何をしてもよい、とはしません。
状態と条件：カイルの不在は`has_member`の否定で表します。`F.relation_known`は商人が関係を明かす、`F.kyle_told`は本人へ知らせる、`F.aid`は`secret/open/declined`です。本人を外したこと自体を裏切り点にしません。
経路：招待→同席の理由を聞く／一時的に別行動→援助案→本人への確認または秘密の受領。本人を外したくなければ公開商談へ切り替えられます。秘密の援助は短期利益がありますが、後に相手から知られた場合の説明を残します。
結末と余韻：公開援助ならカイルが返済条件を決めます。辞退ならリナは客として依頼を出し直せます。秘密なら兄弟姉妹の距離は直ちに変わらず、後日談で問われます。報酬は商談に応じた補給。リナが別れ際、食事代を勝手に払わず財布をしまいます。
# GQ066　最後の一撃を譲れ
依頼と人物：弟子戦士ルウは、故郷の試験のため石喰い獣を倒した実績が必要です。師は最後の一撃だけ譲ればよいと考えますが、ルウはそれを自分の力と認められません。試験官は単独撃破より、危険を判断し協力を求められるかを重視しています。
展開と開示：受験規則を早く読めば共同討伐が認められると分かります。師は知らなかったのでなく、自分が受けた厳しい試験を価値の基準にしています。戦闘中のルウが救助に回る場面を、功績を逃した失敗とも成長とも読めるようにします。
状態と条件：`W(stone_eater_trial)`は隊の勝利、`F.rules`は規則を確認、`F.ruu_role`は`unset/strike/rescue/support`です。役割は固定の選択場面で確定し、累計戦績から最終打撃者を推測しません。
経路：受験相談→規則照会／訓練→固定遭遇→功績をどう報告するか。救助役でも合格を求められます。敗北すれば再訓練、撤退を正直に報告すれば判断についての面談へ進めます。
結末と余韻：借りた一撃を単独撃破と偽れば短期の合格と露見の不安、共同報告なら技能に応じた配属、再試験なら遅い成長になります。報酬は訓練場利用権。師が記念写真で中央を空け、ルウが救った荷担ぎをそこへ呼びます。拡張：最終打撃の選択を実戦へ接続するなら専用の戦闘イベントが必要です。

展開と開示：指示書の余白には、各案を捨てる条件が書いてあります。几帳面さの象徴に見えた番号が、優先順位でないと分かります。病床からの伝言は「第二案」ではなく「今、何が見える？」です。

経路：指示書受領→偵察二地点を任意順→作戦選択→砦戦または撤退。橋の崩落を見たなら尾根、敵の集中を見たなら橋の迂回支援など、選択前の観測へ対応させます。未偵察でも決断できますが、既定の世界状況は変えません。
結末と余韻：勝利なら自分たちの判断を報告します。軍師の名で成功を報告すると本人は次に過大な期待を受けます。撤退なら避難民を守る別成果を記します。報酬は奪還または救援の実績に応じます。ユウナが戻ると、会議の椅子は中央でなく皆と同じ列にあります。
# GQ068　ふたりでひとり分の報酬
依頼と人物：双子の術師ネムとノムは、一人分の報酬で二人の働きを売っています。店主は得だと思い、兄弟は片方だけ選ばれることを恐れています。依頼は魔力灯の修繕ですが、診断が得意な兄と調整が得意な弟で作業量が違います。
展開と開示：同じ言葉で返事する二人が、工具を取る手だけ違います。途中で一人が別の不具合に気づいて離れると、残った一人が自分の説明を続けられません。能力不足でなく、二人一組の契約しか経験していないことを見せます。
状態と条件：`F.skills_heard`は個別面談、`F.separate_terms`は各自の仕事と報酬に合意、`F.lamps_fixed`は三灯の修繕完了、`F.future`は`together/separate/flexible`です。双子の同行判定は別々に行います。
経路：契約→診断→同時作業／役割分担→追加不具合→精算。主人公が一方の作業を補っても、もう一方の報酬を無断で減らしません。修繕失敗なら店を仮設灯で維持し、翌作業へ持ち越せます。
結末と余韻：一組継続なら料金を適正化します。別契約なら次回の依頼が別々に来ます。柔軟契約なら一緒に働く日も残ります。報酬は灯油と魔力灯。二人が別々の杯で乾杯し、結局同じタイミングで飲んでしまう軽い終わりにします。
# GQ069　誰にも贈れない指輪
依頼と人物：仲間の騎士マオは、成人した旧友への指輪を届けてほしいと頼みます。受取人は既に別の相手との暮らしを選び、受領を拒みます。マオは返事を恐れ、自分で渡さず、主人公ならうまく言えると期待しています。
展開と開示：指輪は結婚の約束ではなく、昔の冒険で交わした「帰ったらまた旅へ出る」合図でした。受取人は愛情を否定しているのでなく、昔の約束が今の意思を代わることを拒んでいます。贈れば関係値が上がる道具にはしません。
状態と条件：`F.old_promise`は約束の意味を聞く、`F.refusal`は本人の拒否を受け取る、`F.report`は`truth/softened/lie`です。指輪は受領されなければ所持品に残り、届けたことにしません。
経路：託される→旧友と面会→指輪を返す／別れの返事を託す／マオを呼ぶ。本人が会いたくない場合は呼出しを成功させません。嘘の成功報告も選べますが、指輪の所在と後の再会で矛盾が生じます。
結末と余韻：正直な報告ならマオは怒りや悲しみを見せ、時間を置いて指輪をしまいます。柔らかな要約は拒否を曖昧にせず、今後の交流だけ残せます。嘘なら同行の信用が傷つきます。報酬は交通費のみ。後日マオが新しい旅の計画を立てる時、誰を連れていくかを本人に聞きます。
# GQ070　別れるための冒険

展開と開示：島には財宝でなく、初めて野営した時の鍋が残っています。セフは自分が食事を作ったことしか覚えられていないと考えています。同行時の救助や約束が記録されていれば、その具体的な出来事を返せます。未記録の功績を突然作りません。
状態と条件：`F.departure_told`は本人の告知、`F.keepsake`は`unset/pot/map/shared`、`F.future`は`shop/return_later/stay`です。過去篇を使わない場合は、出発前の短い回想選択で共有経験を固定します。

結末と余韻：店へ戻れば新しい補給先になります。休暇なら再会の条件を約束します。残留なら戦う以外の仕事にも選択権を与えます。報酬は共有の記念品と関係の継続。次の野営で鍋の置き方だけが少し違い、別れを台詞で繰り返さず示します。
