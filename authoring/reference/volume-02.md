# GQ011　白旗の荷馬車
依頼と人物：御者ハンナは、白い布を掲げた荷馬車の護衛を依頼します。荷は敵対領へ返す農具です。息子を失った雇い主は和解を望みますが、荷台に乗る元兵士グスは、白旗を掲げることを降伏と思い、布を何度も下ろします。
展開と開示：峠の検問は布ではなく、返却農具の刻印を確認します。グスが恥じるのは敗北ではなく、徴発に自分も加わったことです。柄に残る印を彼が指で隠す場面を先に置き、持ち主の名を聞かれた時に事情を明かします。
状態と条件：`F.marks`は刻印を確認、`F.confession`はグスの告白、`F.flag`は`white/covered`、`F.return_form`は`anonymous/named`です。旗の変更は戦闘力に影響せず、検問側の接近の仕方を変えます。
経路：出発→野盗のいる本道／迂回の渡し→検問→引渡し。本道の戦闘から逃げれば渡しへ移れます。グスの名を出すには本人の同意が必要です。農具の由来が不明なら現地の職人へ照合を頼み、引渡しを待機できます。
結末と余韻：匿名返却でも農具は戻り、雇い主の目的は達します。名を出せばグスは礼と非難の両方を受け、後日修繕に通います。荷を引き返せば報酬は護衛分だけとなり、返却は次便へ残ります。受取人が白旗を洗濯紐へ掛け、もともとの枕カバーだと分かる場面で終わります。
# GQ012　置いていく灯
依頼と人物：坑夫三人の救出を、監督リオが求めます。救助班の灯は出口まで足りません。リオは全員を連れ帰ることに固執し、負傷者自身は「歩ける二人を先に」と言います。かつて一人を置いた経験から、監督は相談そのものを放棄と受け取っています。
展開と開示：帰路の壁には、昔の救助でリオが残した目印があります。先に放置の痕跡として見せ、後に彼が援軍を連れて戻った日付も見つかります。過去の失敗を必ず捏造に反転させず、救えなかった事実と戻ろうとした行為を両方残します。
状態と条件：`F.cache`は途中の灯油庫を発見、`F.signal`は地上との伝達手順を確認、`F.relay`は分割救助を全員で承諾した履歴です。灯火、負傷者HP、所持灯油を実値で判定します。脇道の魔物の討伐は灯油庫への安全な通路を作ります。
経路：下降→負傷者へ到達→一斉退避／補給探索／連絡役を先行。補給探索の前に灯火の不足を表示します。`F.signal`があれば安全区画に負傷者を置き、明示した一回の往復で援軍を呼べます。戦闘に敗れれば地上班が救出を引き継ぎ、委任の結末になります。
結末と余韻：一斉退避は装備を捨てて軽量化します。補給が整えば装備も回収できます。分割救助ではリオが負傷者と残り、自分で連絡役を送り出します。報酬は救助報酬と坑道利用権。最後の灯は誰かを置く印ではなく、戻る場所の印になります。
# GQ013　雪解けを待たない男
依頼と人物：庭師オドは、封鎖前の山道を越えて故郷へ帰りたいと言います。娘は手紙で引き留め、案内人は雪崩の危険を説明します。オドが運ぶのは亡妻の遺骨ではなく、妻が生前に予約した苗木です。庭を完成させれば悲しみが終わると信じています。
展開と開示：荷を墓へ向ける描写で弔いの旅を予感させますが、箱から生きた根が出ます。娘の二通目には「庭は売った。父さんの部屋は残した」とあります。苗を届ける目的はそのままでは達せず、帰宅の意味を話し合う必要があります。
状態と条件：`F.second_letter`は本人の許可で娘の手紙を読む、`F.weather`は案内人の現場報告、`F.destination`は`old_garden/daughter/valley`です。`N.stages`は山行区間の完了で増え、2区間目の前に最終の進退判断をします。
経路：宿→旧道の偵察／娘への伝言→峠の決断。安全な季節まで預かる、娘の町へ迂回する、旧庭の新所有者へ受入れを確認して進む道があります。旧庭へ勝手に植えることは成功扱いにしません。危険を越える前ならいつでも宿へ戻れます。
結末と余韻：娘の家には一本だけ植えます。旧庭では新しい家族の木になります。谷へ預ければ翌春の続きが残ります。報酬は庭師の薬草知識。箱が軽くなっても足取りは急には軽くならず、オドは初めて道端の別の花の名を教えます。
# GQ014　二人分の通行料
依頼と人物：旅芸人ネラは、一人なのに二人分を要求する渡し守の調停を頼みます。渡し守は足跡を数える呪具を信じています。ネラには亡姉の舞を映す分身が付き、舞台では二人として扱われるのに、支払時だけ一人と言うことを指摘されます。
展開と開示：渡し守は金を欲しているだけではありません。呪具の人数で救命具を積み、過去の転覆以来手順を変えられません。分身には体重も溺死もありませんが、川の結界には反応します。重さと境界の人数を別に検証できる場面を置きます。
状態と条件：`F.weight_test`は空舟との比較、`F.boundary_test`は岸の結界で実演、`F.crossing`は`double/dismissed/exception`です。二人分の支払いは所持金で検査し、分身を一時消すとこの渡河中の芸だけ使えません。
経路：桟橋→支払う／実演する／別の渡しへ回る。二つの試験をすれば救命具一つと結界代だけの例外料金を提案できます。渡し守は無料にはせず、根拠を帳面に残します。分身を消す道はネラ本人が承諾した時だけです。
結末と余韻：全額支払えば早く渡れます。消して渡れば対岸で姉の輪郭を呼び戻します。例外なら次の旅人のための扱いが増えます。報酬は一席の舞。最後、渡し守は拍手を二人へ送り、ネラは今度は訂正しません。拡張：分身は会話演出として扱い、通常パーティー人数へ追加しません。
# GQ015　追手のいない逃亡
依頼と人物：高級料理人サビが、誰にも行先を知らせず港まで護衛してほしいと頼みます。宮廷から逃げていると思わせますが、雇い主は退職を認めています。サビは、自分がいなければ厨房が崩れると信じ、追われることで必要とされていた証拠を得たいのです。
展開と開示：道中の影は追手ではなく、忘れた包丁を届ける助手です。助手は自分の献立を試せる喜びと師への敬意を両方持ちます。包丁が丁寧に研がれていることを見せてから、厨房が通常営業していると伝えます。
状態と条件：`F.terms`は本人が退職の合意を明かした時、`F.knife`は助手から包丁を受領、`F.farewell`は別れの挨拶を本人が選んだ時です。護衛契約は到着が条件で、追手を発見する必要はありません。
経路：裏門→隠密路／市場→助手に遭遇→港。助手を追い払って秘密を守る、事情を確かめる、本人の同意で厨房へ一度戻る道があります。戻っても船を逃さない便を事前に確認できます。無理に改心させなくても護衛は完了します。
結末と余韻：黙って発てばサビは追われた体裁を保ちます。挨拶すれば、助手の料理を一口食べてから発ちます。滞在を選べば新しい立場を相談します。報酬は旅の食料。別れ際、サビは助手の塩加減に文句を言い、助手は初めて直しません。

展開と開示：鳥の民の家は季節とともに移動します。線は定住地から毎年の住居へ帰る経路です。老婆は誤記を訂正しないのではなく、家を一つに固定する発想を採らないだけです。道中の目印が仮設の炊事場として使われていることで示します。

結末と余韻：固定図は町の旅行者に便利です。移動図は読み方の講習と組で売れ、住居の正確な位置は本人たちの同意で伏せられます。返却なら共同で一枚を描く誘いが来ます。報酬は野営地の利用許可。最後、フェンが地図の中心を描かず、余白から線を引き始めます。
