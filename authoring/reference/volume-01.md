# GQ001　三度目の戸締まり
依頼と人物：鍵屋の娘ミナが、毎晩開いている裏口の見張りを頼みます。父ガロは「閉め忘れる者に店は渡せん」と引退を延ばしています。ミナは継ぎたいのではなく、自分の店を出したいのですが、父を一人にすることを言い出せません。
展開と開示：見張ると、父が自分で鍵を開けています。盗難ではなく、娘に必要とされる口実です。ただし、引き出しには娘の新店用の鍵も作られています。父が嘘をつく場面を先に、娘の名を刻んだ鍵を後で見せ、妨害と送り出したさが同居する人物にします。
状態と条件：`F.saw_unlock`は父の開錠を目撃、`F.saw_key`は父の許可で新店の鍵を見る、`F.mina_wish`は娘が独立の希望を語った時に確定します。施錠状態そのものは扉の正準状態を使います。
経路：受注→夜番→父に話す／朝まで黙る→娘への報告です。告発は目撃だけで可能です。両者の話を知れば、食事の日を決めて別居する案を出せます。娘の希望を聞かずに同居や継承を勝手に確約する選択はありません。見張りを中断すれば翌晩やり直せます。
結末と余韻：事実を伝えると父娘は一度衝突し、娘は早く独立します。父の秘密を守れば報酬は出ますが、娘は店を出る話を先送りします。訪問の約束を仲介すれば二つの店が開き、週一度だけ父の店が早仕舞いします。報酬は鍵の修理券。後日、父が一度で戸締まりを終える音が聞こえます。
# GQ002　弔鐘は誰のために
依頼と人物：鐘番ロウは、亡くなった異国の行商人のため鐘を鳴らしたいと頼みます。宿主エダは、鐘が昔の占領軍の合図と同じだとして反対します。ロウは若い頃、その国の兵に助けられた恩を、行商人への葬儀で返そうとしています。
展開と開示：エダが鐘楼を見上げず、地面を数えるように歩く様子を置きます。昔の合図は三打。行商人の家族が望むのは五打です。回数を変えれば記憶の問題が全部消えるわけではありません。家族は「恩返しの役に父を使わないで」とも告げます。
状態と条件：`F.family_wish`は遺族への聞き取り、`F.three_beats`はエダの説明、`F.notice`は時刻と五打を町へ事前告知した履歴です。`N.prepare`は葬儀の準備行動ごとに1増え、3で葬列が出発します。期限は受注時に説明します。
経路：依頼→遺族／宿／告知板を任意順に訪問→出発時に鐘・手鈴・無音を選びます。鐘は遺族の同意が必要です。告知がなくても鳴らせますが、町の反応が変わります。鐘を断っても葬儀の手伝いは完了できます。
結末と余韻：告知した五打ならエダは戸を閉め、自分なりの距離で見送ります。手鈴ならロウが葬列を歩き、初めて遺族本人の話を聞きます。無音なら町の雑踏の中で別れます。報酬は行商人の旅路を記した地図。ロウが最後に言うのは兵の武勇ではなく、行商人の好物です。
# GQ003　一枚多い食券
依頼と人物：炊き出しの料理人トマが、毎日一枚ずつ増える食券を調べてほしいと頼みます。見習いニルは不正を許せません。券を増やすのは、字が読めず申請できない老人を見た、隣の食堂の女将です。自店の客を減らす炊き出しを嫌いながら、見捨てられません。
展開と開示：偽券は食堂の献立の裏紙で、発見は難しくありません。追及されると女将は謝るより先に「今日の鍋は足りるのか」と聞きます。問題の中心を犯人当てから、誰が食事を受け取れるかへ移します。トマは善意に同情しても、在庫を無限には増やせません。
状態と条件：`F.source`は裏紙を照合、`F.elder_consent`は老人が代筆を頼んだ時、`F.partner`は両店が共同仕込みへ合意した時です。食材の必要数は所持品で確認し、寄付は実際に渡した分だけ記録します。
経路：券の調査→食堂→配膳前の相談。偽造を止める、本人の同意で申請を代筆する、食材を持ち込んで共同仕込みを仲介する道があります。代筆は無料ですが老人の身の上を公表しません。食材不足なら代筆か不正停止へ戻れます。
結末と余韻：取り締まれば枚数は合いますが、老人は列から消えます。代筆なら一人の穴を塞げます。協力案なら女将の店にも仕事が戻りますが、毎日の負担は残ります。報酬は持ち帰りの煮込み。最後にニルが、食券ではなく皿を数えて不足を見つけるようになります。
# GQ004　雨を売る少年
依頼と人物：花売りの少年が、晴天なのに雨音を立てる瓶を盗まれたと訴えます。盗んだのは老楽師ベロ。眠れない夜に、故郷の雨の音を聞きたかったのです。少年は不思議な道具の商売に誇りがあり、同情で商品を無価値にされることを嫌います。
展開と開示：追跡は音を頼りにしますが、噴水、桶、屋根の修理音が紛らわしく響きます。瓶は雨を生むのではなく、最初に聞かせた音を繰り返す品です。ベロが思い出す雨音の途中に、少年のくしゃみが入ります。魔法の誤認を、笑いと郷愁へ着地させます。
状態と条件：`F.found`は楽師を発見、`F.loop_known`は録音の仕組みを試した時、`F.lease`は少年と楽師が貸出へ同意した時です。弁償金は所持金で検査します。瓶の所在は道具の所有状態へ置きます。
経路：聞き込み→音の追跡→発見→返却／買い取りの仲介／貸出の提案。仕組みに早く気づけば少年へ直接尋ね、追跡を短縮できます。買い取りは金が足りなければ選べませんが、返却は常に可能です。
結末と余韻：返せば少年は商売を続け、楽師には借りが残ります。買い取れば正式な所有物になります。貸出なら楽師は音楽を吹き込み、少年は新しい商品を得ます。報酬は小さな録音瓶。ただし戦闘効果はありません。最後、雨音の瓶を買った客が、くしゃみのところで笑います。
# GQ005　花嫁の片方の靴
依頼と人物：婚礼の日、成人した花嫁リセが姿を消し、靴だけが運河に浮かびます。婚約者ダンは捜索を頼みます。リセは結婚から逃げたのではなく、出席を拒む姉のもとへ行きました。姉は家業を一人で背負ったことへの怒りを、結婚への反対として口にしています。
展開と開示：靴を落としたのは、泥道で姉の荷車を押したためです。ダンは浮気や誘拐を恐れていますが、別の靴には工房の木屑が詰まっています。リセは姉に来てほしくても、今後の家業を手伝う気持ちは未整理です。仲直りの言葉だけでは姉は動きません。
状態と条件：`F.found_rise`、`F.sister_burden`、`F.dan_informed`はそれぞれ発見・姉の事情を聞く・本人の無事を伝える履歴です。`F.plan`は`none/shared/hired/postponed`、具体的な分担や雇用資金を当事者が承諾した時だけ変えます。
経路：靴を拾う→工房か運河を追う→姉妹へ合流→婚礼へ戻る／役割を相談／式を延期。発見後はいつでも無事の報告を先にできます。勝手に連れ戻す道ではなく、リセが戻る条件を交渉します。
結末と余韻：式だけ再開すると姉の席は空いたままです。仕事の分担を決めれば姉は遅れて来ます。延期なら祝いの料理は近所に配られ、後日の式が小さくなります。報酬は運河の渡し無料券。姉が直した靴は両方とも少し頑丈で、リセは文句を言いながら履きます。
# GQ006　パン泥棒の影
依頼と人物：パン屋が、姿のない盗人の捕縛を求めます。犯人は夜勤の荷運びから剝がれた影です。この町の影術では、主人が認めない欲求が影へ移ります。荷運びは家族に心配させまいと食事を抜き、影だけが飢えを認めています。
展開と開示：追うほど影は小さな抜け道へ逃げます。最初は怪物らしい輪郭だけを見せ、次に寝た主人と同じ傷のある手を映します。影を戻す儀式は、主人が自分の空腹を口にした後だけ成立します。説明は術師か古い祭具の実演から得られます。
状態と条件：`F.owner`は同じ傷を確認、`F.rule`は儀式条件を知る、`F.admitted`は主人が食事を断っていたと認めた時です。パンを渡した場合は所持数を減らし、影の盗みとは別の履歴にします。
経路：追跡→捕獲罠／主人の捜索→夕食の場。罠で封じるなら影封じの代金を支払います。主人と食べるならパンと`F.admitted`が必要です。説得を拒まれたら、一晩だけ店を守り翌日に話し直せます。
結末と余韻：影を封じれば盗みは止まりますが、主人の疲れは残り、後日救済を続けられます。食事で戻せば影は足元へ収まり、主人は勤務を減らす相談をします。報酬は夜食の提供。最後、本人より一拍早く影がパンへ手を伸ばし、主人が笑ってもう一つ買います。
# GQ007　六人目の客
依頼と人物：宿主モラは、五人組の旅客が六人分の食事を注文する理由を調べてほしいと頼みます。客は失踪した仲間を待つ元運送隊です。一人は捜索費のため席を減らしたいと言えず、一人は空席を埋めることを裏切りと思っています。
展開と開示：怪談のように空席の皿が減りますが、食べているのは夜に来る配達人です。失踪者から「仲間が食べきれない分を受け取ってくれ」と頼まれていました。本人は失敗の借金を恐れて隣町に潜み、帰る勇気がありません。配達人は住所を売りません。
状態と条件：`F.courier`は配達人を目撃、`F.message`は失踪者へ返事を託した履歴、`F.reply`は次の配達で返事を受け取る、`F.meeting`は双方が再会に同意した時です。
経路：食堂の観察→配達人との対話→消息だけ伝える／返事を仲介／無理な捜索を中止する。返事は「一晩泊まる」の明示選択後に届きます。住所の強要で即時解決する道はありません。返事を待たずとも消息報告で完了できます。
結末と余韻：消息だけなら客は旅を再開し、食事を五人分にします。再会なら借金と役割の相談から始まり、即座に昔へ戻りません。仲介を断れば宿主は詮索をやめます。報酬は宿泊権と運送路の情報。再会の食卓では、六人目が自分で椅子を引きます。
# GQ008　猫に付いた懸賞

展開と開示：猫は魚を盗みますが、鼠除けの働きも本当です。善良な動物だから無罪とせず、店の置き方を変えれば被害を減らせると観察で示します。猫を捕まえた直後、二人が同時に違う名前で呼び、猫がどちらにも返事をしない場面を置きます。
状態と条件：`F.fish_route`は侵入経路を観察、`F.rat_work`は鼠を追う姿を確認、`F.enclosure`は棚と餌場の改修が完了、`F.custody`は`none/fish/bird/shared`です。
経路：依頼→餌で捕獲／店を観察→引渡し交渉。魚屋への引渡しは遠い倉庫へ移すという条件を先に説明します。共同管理は両方の観察と改修費が必要です。金がなくても片方の保護か、懸賞辞退を選べます。
結末と余韻：倉庫へ移せば魚の被害は止まり、鼠対策が別の仕事になります。鳥屋の保護なら魚屋との関係は悪くなります。共同管理なら猫の昼寝場所だけが二つ増えます。報酬は干物か餌袋。最後、二人は共同の名前を考えていますが、猫は配達人の呼び声でだけ起きます。
# GQ009　火のない鍛冶場
依頼と人物：老鍛冶師エンが、弟子に見つからないよう炉材の運搬を頼みます。炉は壊れていません。手が震えるため火を入れず、注文を断る口実を作っています。弟子セドは技術を教わりたい一方、師が自分を信用していないと感じています。
展開と開示：床には重い剣でなく、小さな留め金の試作品が増えています。師は戦具を作れなくても、暮らしの道具なら仕事を続けられると知っていますが、名工の看板を下ろせません。能力の高い主人公が一度鍛造を代行しても、この選択は解決しません。
状態と条件：`F.tremor`は本人から事情を聞く、`F.samples`は見せてもらった試作品、`F.sedo_agrees`は弟子が主作業を引き受ける同意です。STR等は運搬の手段を変えるだけで、人の同意を代用しません。
経路：運搬→師の試作を手伝う／弟子へ嘘の伝言をする→次の注文への回答。弟子に任せる、生活道具へ転向する、一旦休業する道があります。弟子の独立を望む場合、無期限の介護役に留める条件は設けません。
結末と余韻：継承なら二人の銘が並びます。転向なら名剣の隣に鍋の取手が置かれます。休業なら前払い金を返す作業まで手伝います。報酬は修繕か既製の留め金。最後の火入れで、師は槌を握るのでなく、弟子の打つ間隔を指で数えています。
# GQ010　明日までの英雄
依頼と人物：退役兵イーロが、祭の行列へ一日だけ護衛してほしいと頼みます。町は彼を「一度も退かなかった英雄」と紹介していますが、彼が誇るのは、撤退を決めて部隊を救った夜です。祭係は嘘を守りたいのではなく、子どもに勇気を伝える物語が必要だと考えています。
展開と開示：旧兵の証言は初めから得られ、隠し真相にしません。問題は、祝う席でどの言葉を使うかです。自分の逃走戦績を見せればイーロは具体的に話しますが、逃走経験のない主人公も話を聞けます。記録から人格を決めません。
状態と条件：`F.retreat_story`は証言取得、`F.record_shared`は自分の戦績を本人へ提示、`F.speech`は`unset/legend/retreat/none`です。過去が不完全な戦績は「記録開始後」として紹介します。
経路：依頼→衣装合わせと証言→演説文の相談→祭。伝説のまま祝う、撤退を中心に語る、演説をやめて生還者全員を招く道があります。演説変更は本人の同意で確定します。護衛だけを務めて語り方に介入しなくても報酬は出ます。
結末と余韻：伝説なら拍手は大きいが、本人の言葉は少なくなります。撤退の話なら祭係が帰還路を模した遊びを作ります。群像の祭なら英雄席が足りません。報酬は旧式の盾。最後、イーロは行列の先頭ではなく、歩くのが遅い友人の隣に立ちます。
