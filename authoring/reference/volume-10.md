# GQ091　勇者を通さない門
依頼と人物：「戦功ある者だけが通れる」と言われる古門が、名高い冒険者を拒みます。門番は故障と思い調査を求めます。門は戦果でなく、入口で表明した用件に対応する資格を確かめています。討伐の英雄が、交易交渉の代表として来ても、その権限は持っていません。
展開と開示：荷運びは素通りし、英雄だけが拒まれる構図で侮辱を感じさせます。入口の小さな用件札と、通った者の荷札が対応します。依頼人は自分の交渉力を補うため、主人公の名声を代理権の代わりに使おうとしていました。
状態と条件：`F.purpose`は`trade/guard/visit`、`F.mandate`は町の代表権を正式に受領、`F.rule_known`は札と通行を照合した履歴です。全期間の勝利数は紹介文に使えますが、通行条件の代用にはしません。
経路：門前→観察／門番との対話→代表権を得る／護衛として入り直す／門を破る。用件の変更は内部で行える行為も変えます。護衛で入って勝手に契約すれば、後で交渉が無効とされます。破壊は警備戦と外交上の損失を先に示します。
結末と余韻：正式代表なら交渉の責任を負い、護衛なら依頼人自身が話します。辞退しても調査料は得られます。報酬は通商の利用権か護衛料。門を越えた依頼人が、主人公より先に挨拶する場面で締めます。GQ010やGQ030の功績があれば、門番の敬意と拒否が同時に強くなります。
# GQ092　消えた依頼板
依頼と人物：いつもの町の依頼板が撤去され、組合長は何者かの妨害を疑います。町の人々は、冒険者へ頼む前に自分たちで相談する場所へ変えていました。主人公の仕事が役立たなかったのではなく、修繕や連絡の方法が町へ残った結果です。
展開と開示：かつて救った店へ行くと、今は別の店の荷物を預かっています。組合長は存在意義を失うのが怖く、難しい依頼だけを誇張して掲示し直そうとします。住民は冒険者を排除したいわけでなく、日常の判断を取り戻したいのです。
状態と条件：`F.network_seen`は三つの助け合いを現場で確認、`F.guild_role`は`broker/trainer/emergency/old`です。前篇の完了状態を使う場合も、住民がその成果を知る経路を導入します。未採用なら町の過去の支援を新しい固定設定として明記します。
経路：旧広場→店／橋／炊事場を任意順に訪問→組合会議。依頼仲介、訓練、緊急対応へ組合を改める道と、旧制度を維持する道があります。役割変更には住民と組合の合意が必要です。主人公が会議を降りても町は話合いを続けます。
結末と余韻：仲介なら専門家をつなぎ、訓練なら住民が小問題を解き、緊急対応なら難しい依頼が減っても備えます。報酬は活動拠点。撤去された依頼板は捨てられず、町の相談机へ作り直されます。GQ001・GQ003・GQ009の成果を具体例として接続できます。
# GQ093　祈りの届かない場所
依頼と人物：巡礼師セイは、祈祷が使えない谷から住民を移住させようとします。谷の人々は、呪いと神罰も届かない安全を選んで住んでいます。外で治療を受けたい若者と、追われてここへ来た老人で希望が割れます。
展開と開示：護符は消えるのでなく、谷の境界を越えるとまた灯ります。効かないことが信仰の否定ではなく、地域固有の遮断だと示します。セイは救いたい思いと、自分の力が必要とされる場所へ連れ出したい願いを区別できていません。
状態と条件：`F.boundary_test`は往復で作用を確認、`F.volunteers`は移住希望者の同意、`F.refuge_risk`は老人の事情を本人が語った時、`F.route`は`migration/outpost/stay`です。治癒技能の使用可否は地域ルールとして明示します。
経路：谷へ入る→住民の個別相談→全体移住を求める／境界外の治療拠点／現地の生活支援。拠点は物資と往復の護衛が条件です。希望しない者を自動同行にしません。護衛戦から退けば谷へ戻り、再調整できます。
結末と余韻：移住は医療と追跡リスク、拠点は選択肢と維持費、残留は安全と制約を残します。報酬は谷の薬草と避難権。セイは祈れない場所で、ただ重い水桶を運びます。GQ061の人物がいれば、治すことと望みを尊重することの差を別の角度から語れます。拡張：地域別技能制限の接続が必要です。
# GQ094　売れた故郷
依頼と人物：巨獣の背に建つ移動村が、獣ごと商会へ売却されます。村の代表は借金を返して住民を救いたい。一方、獣使いは巨獣の行きたい季節の道を守りたいと、移動路の調査を頼みます。売買は建物の権利でも、獣や住民の意思の所有ではありません。
展開と開示：村人は「いつもの揺れ」が変わったことで、進路変更を知ります。商会は観光地へ固定したいが、巨獣は定期的に塩地へ行かなければ衰弱します。伝承として聞いた巡回が、生存の条件だったと分かります。
状態と条件：`F.salt_route`は古い巡回と餌場を確認、`F.resident_vote`は住民が方針を選ぶ場面、`F.contract`は`fixed/revised/bought_back`です。投票結果は選んだ説得材料と各代表の固定した利害から決め、全員へ同じ好感度を配りません。
経路：売却後の護衛→路の調査→商会の計画提示→季節巡回を契約へ加える／住民が下りる／買戻し。買戻しは十分な資金と住民の承認が必要です。資金がなくても巡回権や退去費用を交渉できます。
結末と余韻：改定なら商売と移動を組み、下りれば故郷が場所から人の関係へ変わります。買戻しても借金を作った仕組みは見直します。報酬は移動村の部屋。下りた住民が振り返ると、故郷の灯がゆっくり遠ざかります。GQ016の移動地図をそのまま巡回の根拠へ接続できます。
# GQ095　魔王の畑

展開と開示：城の牢と畑の収穫帳を別々に見せ、加害と生活基盤が同じ施設に存在したことを示します。農夫は炉を再開したいが、その燃料には捕虜の魔力が使われていました。古い農法へ戻すには時間と外からの食料が必要です。

経路：枯れた畑→城／炉番／周辺農地→代替燃料へ改修／一季を支援して転作／旧炉を再開。旧炉再開の被害は選択前に明示し、救済の最適解として隠しません。改修失敗なら転作と食料支援へ移れます。
結末と余韻：改修は技術と費用、転作は時間と援助、旧炉は新たな支配への加担を残します。報酬は城の農地利用権と食料。収穫祭で人々が魔王の肖像を燃やしても、炉の構造図は次の世代へ残す場面を置きます。単独使用では魔王討伐を背景設定として提示します。

# GQ097　忘れられる勝利

展開と開示：名前を消しても災厄の被害は消えません。失うのは「誰が終わらせたか」の結び付きです。初期の史料に原因と復旧だけが残る空白を置き、以前にも同じ選択があったと示します。忘却を功績への罰や作者の万能リセットにはしません。
状態と条件：`F.rule_proven`は過去の封印例を確認、`F.consent`は本人が記憶への影響を了承、`F.archive`は`public/sealed/none`、`F.seal`は`temporary/complete`です。実際の戦績recordsは削らず、世界内人物が参照できる伝承と記録へのアクセスだけを変えます。
経路：再発→史料調査→一時封印／完全儀式／別の封印手段を探す旅へ出る。完全儀式の前に仲間が残せるものを選びます。名を含まぬ品は残せますが、後で誰の品かを自動で思い出す抜け道にはしません。
結末と余韻：完全封印なら平和と匿名の帰還、一時封印なら名誉と継続する備え、探索なら次の冒険が始まります。報酬は儀式前に預けた物資として確保します。仲間が名を忘れても、歩調の合う見知らぬ旅人へ隣を空ける場面で閉じます。拡張：局所的な記憶更新と会話差替えが必要です。

結末と余韻：最短なら交通、安全なら保護、複数表示なら読む側の選択を増やしますが案内の複雑さも残ります。報酬は完成地図と旅費。地図師が自分の帰り道だけは口頭で尋ね、人の説明を聞いてから歩き出します。GQ016・GQ020・GQ085の道路変化と接続できます。

展開と開示：行先の家では、どこも帰還を待つため灯を残しています。装置の故障に見せた複数の行先が、積み重なった関係の存在を示します。全員が一緒に暮らす解決にせず、待たせた相手へどんな約束を更新するかを問います。来訪者を待たない家へ無断で飛ぶ能力にはしません。
状態と条件：`F.anchor_a`、`F.anchor_b`は二人の相手が帰還先の灯を受け入れた履歴、`F.promise`は`unset/one_home/visits/released`です。単独使用では、導入の二つの短い過去場面で約束を作ります。連作ならGQ001・GQ007・GQ070などの実際の関係を使えます。
