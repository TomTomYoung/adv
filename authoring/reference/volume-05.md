# GQ041　音の出ない優勝旗
依頼と人物：楽団長ポルは、歌うはずの優勝旗が黙ったため修理を頼みます。旗は優勝曲を覚える魔具です。去年の演奏で、舞台裏の洗濯娘サナが口ずさんだ対旋律まで記憶し、今年の楽団だけでは曲が完成しません。
展開と開示：ポルは自分の指揮が衰えたと思い、若手へ厳しく当たります。旗は演奏の直後でなく、洗濯物を絞る音に微かに揺れます。サナは舞台に上がりたいのではなく、仕事中の歌まで人に採点されたくありません。才能発掘を無条件の救済にしません。
状態と条件：`F.countermelody`は二つの音を聞き比べる、`F.sana_permission`は歌の使用許可、`F.arrangement`は`old/new/duet`です。無断録音や本人の自動加入は行いません。
経路：旗の試奏→楽譜／洗濯場→曲の相談→本番。許可を得て対旋律を入れる、別の新曲で旗を上書きする、今年は旗を鳴らさず演奏する道があります。本人が出演を断っても曲の使用は別に相談できます。
結末と余韻：共演ならサナの名を掲げます。編曲使用なら本人は客席でも仕事場でも選べます。新曲なら去年とは異なる優勝の形になります。報酬は音楽堂の招待券か音律護符。鳴った旗より、洗濯場でサナが少し調子を変えて歌い続ける声を最後に残します。
# GQ042　偽物職人の本物
依頼と人物：偽宝石職人キオは、騎士の結婚祝いに納めた指輪を取り戻してほしいと頼みます。依頼主は本物と思って高額な保険を掛けています。キオは金を騙し取っており、受取人の喜びに触れてから罪悪感を持ちました。美しい偽物だから詐欺でなくなる話にはしません。
展開と開示：指輪の石は安物ですが、内側の刻印は手間を惜しまぬ出来です。騎士の配偶者は石の価値を知らなくても、毎年少しずつ刻印を増やせる約束を大切にしています。キオの「取り戻して黙って交換する」計画は、買った側の判断を奪います。
状態と条件：`F.material`は鑑定、`F.buyer_told`は依頼主へ事実を伝える、`F.compensation`は`none/refund/work`です。返金には実際の金を用意し、将来労働は本人たちの同意で別契約にします。
経路：依頼→贈呈前に面会／鑑定を取る→告知／秘密の交換を断る→返金・作り直し・保管。贈呈後でも告知できますが、演出の場が変わります。盗み返す依頼を拒否して調査料だけ受け取ることもできます。
結末と余韻：返金なら指輪を残すか返すかは買主が決めます。仕事で返すならキオは名を隠さず修理を請けます。隠したままなら後日鑑定で信用を失います。報酬は仲介料。贈り手が指輪を残す場合、石の価格は削られても内側の年月日は消えません。
# GQ043　辛くない火吹き料理
依頼と人物：料理祭の店主メメは、火を吹く名物料理の香辛料を集めてほしいと頼みます。助手は味より派手な演出を売ることを嫌います。名物の炎は香辛料でなく、皿の底の小さな精霊が作っています。精霊は休暇を要求し、当日だけ火を出しません。
展開と開示：客は辛さを恐れながら注文し、炎が出ない一皿を子どもが美味しそうに食べます。味はもともと穏やかです。メメが守りたいのは伝統だけでなく、食べる前に客が笑う瞬間。助手は、それを味への裏切りと狭く見ています。
状態と条件：`F.tasted`は炎のない料理を試食、`F.spirit_terms`は精霊の要求を聞く、`F.service`は`flame/taste/alternating`です。香辛料の収集目標は現在所持数で、不要になった分は返却できます。
経路：仕入れ→試食／精霊と話す→献立の決定→祭。代役精霊を雇って炎を守る、味だけで勝負する、時間ごとに演出を休ませる道があります。代役には費用、交代制には店主と助手の役割合意が必要です。収集に失敗しても普通の材料で出店できます。
結末と余韻：炎の店は賑わい、味の店は常連が付きます。交代制は忙しく、助手が客の前で説明する仕事を覚えます。報酬は旅用の料理。休憩中の精霊が客席で鍋を注文し、火を吹かないことへ文句を言う軽い落ちを付けます。
# GQ044　祭の悪役
依頼と人物：悪竜役の役者ジルが、壊された衣装の調査を頼みます。若い勇者役は主役を奪われると嫉妬していますが、切ったのは衣装係です。重すぎる新衣装でジルが倒れる前に止めようとし、本人は好意を侮辱と思います。
展開と開示：観客は勇者より、毎年負けても起き上がる悪竜を待っています。ジルは人気を失いたくないため、苦しい動きを増やしていました。裏地に何度も補強した縫い跡を先に見せ、破損が敵意だけでは読めないようにします。
状態と条件：`F.stitches`は補強を確認、`F.maker_admits`は衣装係の告白、`F.script`は`duel/comic/retirement`です。重量は小道具の設定、演技の耐久は専用の試演場面で確認します。
経路：衣装調査→関係者の聞き取り→試演→軽量化して決闘／知恵比べへ変更／引退公演。破損の弁償と舞台の安全を別々に決めます。手掛かりが少なくても、危険を見た時点で軽量化を提案できます。
結末と余韻：決闘なら若手と息を合わせて立ち上がります。知恵比べなら悪竜が主役を食わず、勇者役にも笑いが生まれます。引退なら翌年の悪竜は別の役者です。報酬は劇場の通行札。幕が下りた後、ジルが竜の頭を脱ぎ、同じ角度で観客へ礼をする姿で閉じます。
# GQ045　花を咲かせない庭
依頼と人物：若い庭師ロマは、師の庭が咲かない理由を調べてほしいと言います。庭の主である老婦人は、庭師が下手になったと怒っています。師は開花を遅らせています。遠くで働く婦人の娘が、戻る日に合わせて見せてほしいと頼んだからです。
展開と開示：娘の帰省は何度も延期され、母にはその約束が知らされていません。蕾を守る覆いが美しく整えられていることで、放置でなく意図的な管理だと示します。娘は母を喜ばせたい一方、自分がいない日にも母が楽しむことを考えていません。
状態と条件：`F.request_known`は師から理由を聞く、`F.mother_told`は本人の庭の扱いを説明、`F.garden`は`waiting/blooming/divided`です。分割開花には管理できる苗が二株以上必要です。
経路：庭の観察→師／娘への伝言→母へ提案。今咲かせる、期限を決めて待つ、一部だけ咲かせる道があります。待つ期限は「次の便り一通まで」で、現実の日付を使いません。次便が来た場面で母が再判断します。
結末と余韻：今咲かせれば娘には絵を送ります。待てば再会の花になるか、待つことをやめた花になります。分ければ同じ庭に二つの季節ができます。報酬は薬草の苗。母が花を見ながら娘の不在を責めるのでなく、次に植えるものを自分で選ぶ場面を置きます。
# GQ046　染め直せない軍服
依頼と人物：染物屋ニアは、退役兵の軍服が何色を重ねても元の色へ戻るため、魔力処理を頼みます。服は部隊の誓約に染められ、本人が除隊を認めても、誓いの相手が解放していません。元上官は戦死し、手続の相手がいません。
展開と開示：服には誓いを結んだ全員の小さな刺繍があります。相手は上官一人でなく、生き残った同僚たちでした。退役兵は故郷で軍歴を隠したいのですが、同僚は見捨てられるように感じます。染色の成功を、友情の断絶の強制にはしません。
状態と条件：`F.oath_read`は刺繍の文を解く、`F.release`は同僚代表が解放へ同意、`F.new_promise`は民間での再会を約束した履歴です。服の装備中か所持中かも区別します。
経路：染物屋→刺繍の調査→旧同僚を訪問→誓約解除／外套へ仕立て直し／軍服を保管。解除は本人の意思と相手の同意、仕立直しは生地を切るため戦闘装備としての能力を失います。どちらも選ばず私服を新調できます。
結末と余韻：解除すれば色を選べます。外套なら裏地に旧色が残ります。保管なら軍歴を忘れるのでなく、いつ着るかを選べます。報酬は染色券。再会の約束がある場合、同僚は酒場で徽章を探さず、本人の顔を見て手を上げます。
# GQ047　一番遅い配達

展開と開示：近道を走るほど花は閉じ、到着が早くても受取条件を満たしません。店主は条件を知りながら宣伝の速さだけを強調しています。出発前に花の扱い札を読めるようにし、到着後の隠し減点にはしません。

経路：荷受け→速い山道／遅い水路／費用の高い懸架車→受取。閉じた花でも事情を説明して翌晩の配達へ変更できます。速さを優先した場合、競技賞と依頼達成を別に扱います。
結末と余韻：慎重な配達なら花の開く音を一緒に聞けます。翌晩なら舞踊家は待つことも演目の一部とします。競技だけ達成すると店主の宣伝は成功し、配達人との評価は割れます。報酬は輸送料と花の押し葉。配達人の掲示した記録に、初めて到着時刻でなく荷の状態が添えられます。
