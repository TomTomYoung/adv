# GQ031　逆向きの足跡
依頼と人物：考古学者シェルは、行方不明の師を探して砂の回廊へ入ります。足跡はすべて入口へ向き、戻った者がいないことと矛盾します。彼女は師の発見を証明したい。同行する荷担ぎは、生還を優先して新発見を後回しにしたがります。
展開と開示：回廊は一定の区画を越えると床の砂だけを裏返し、足跡の凹凸が逆転します。靴の形から進行方向を読んだ推論が間違っています。荷物を引きずった線だけが途切れず、師が奥の避難室へ向かったと分かります。床の反転前に荷担ぎが釘を落とす小さな実演を置きます。
状態と条件：`F.sand_rule`は反転を観測、`F.drag_line`は引きずり跡を追う、`F.anchor`は持ち込んだ綱を入口へ固定した履歴です。`N.crossings`は区画境界を実際に越えた時だけ増え、偶奇で砂面を切り替えます。
経路：入口→足跡の追跡／釘の試験→避難室→師の救出／標本の回収。師は生存しており、自分の誤読を認めたくありません。綱があれば標本も運べ、なければ人か重量標本を優先します。迷えば釘の試験へ戻れる退路を残します。
結末と余韻：師を先に救えば発表は遅れます。標本優先は師の同意が必要で、救助隊へ引き継ぎます。両方運べば荷担ぎを共同発見者として扱うかが最後の選択です。報酬は発見料と砂除け具。帰路、師は弟子の足跡でなく、荷担ぎの綱を辿ります。
# GQ032　宝箱の底の椅子
依頼と人物：財宝庫の管理人は、人を食う宝箱の処分を依頼します。箱の底には、小さな椅子と茶器があります。かつて警備員が内部で監視していた箱に擬態生物が住み、今も座る者を職員と認識して通します。管理人は父がここで働いていたことを誇りにしています。
展開と開示：最初は犠牲者の生活跡に見せ、壁の覗き穴と食べ残しの年代差で監視詰所と分かります。ただし現在の擬態生物は人を襲った事実があり、懐かしい設備だから安全とはしません。管理人は父の仕事を怪物と同じにされたくありません。
状態と条件：`F.watch_post`は覗き穴を確認、`F.signals`は交代の合図を旧日誌から得る、`F.box`は`hostile/destroyed/contained`です。椅子へ座る行為は合図を知るだけでは安全確定せず、先に無人の道具で反応を試します。
経路：財宝庫→戦闘処分／詰所調査→囮試験→隔離／破壊。隔離は合図と外から閉める封鎖具が必要です。調査をやめて通常戦闘へ戻れます。逃走時は宝箱が扉を越えない範囲まで退き、再準備できます。
結末と余韻：破壊なら人身被害は止まり、椅子だけ回収できます。隔離なら研究機会を得ますが管理費が残ります。報酬は安全に回収された庫内品。管理人が最後に椅子へ掛けるのは勲章でなく、父が使っていた薄い座布団です。
# GQ033　一段足りない階段
依頼と人物：地下礼拝堂へ向かう階段が、何度数えても設計図より一段少ない。建築師ドマは師匠の図面を守りたいと調査を頼みます。同行の石工は図面の誤りを疑い、ドマはそれを侮辱と受け取ります。
展開と開示：足りない一段は、重い石棺を運ぶ時だけ沈んで現れる荷台です。図面は人が歩く時でなく葬列の状態を描いています。擦れた肩の高さの溝と、靴跡のない段を先に見せます。師匠は正しかったが、説明を省いたため後世に伝わらなかったという結論です。
状態と条件：`F.load_rule`は重量で段が動くことを試す、`F.grooves`は運搬溝を確認、`F.locked`は荷台を安全に固定した履歴です。STRは錘の移動方法へ、所持綱と工具は安全固定へ使います。
経路：階段の計測→図面の読み直し／実物の試験→荷台を下ろす→礼拝堂。錘を人の代わりに載せる道と、石工の手動固定で下りる道があります。能力不足は共同作業か道具の調達で代替できます。準備なしに踏めば落下直前の退避となり、再準備へ戻します。
結末と余韻：機構保存なら建築史の発見、通常階段へ改修なら地域の参拝路になります。どちらも価値があり、保存と利用の判断を残します。報酬は建築図と足場道具。ドマは新しい図面へ、師匠が書かなかった荷の重さを大きく書き足します。
# GQ034　敗者の宝物庫
依頼と人物：剣士ザグは、敗北を認めた者だけが入れる宝物庫へ挑みます。彼はわざと決闘に負けますが扉は開きません。修道士は、ここに集められた品が敵から奪った戦利品ではなく、返してほしいと頼めなかった遺失物だと知っています。
展開と開示：扉が求めるのは戦闘結果ではなく、所有権の主張を一つ手放す宣言です。入口に並ぶ名札は倒した相手ではなく返却先です。ザグはかつて拾った師の剣を自分の継承の証にしており、返す相手はまだ生きています。
状態と条件：`F.names`は名札を読む、`F.rule`は返却の実演を目撃、`F.claim_released`は実際に一品を所有者へ返すと確定します。通常の敗北数や逃走数では開きません。返却した物は所持品から除きます。
経路：挑戦→模擬決闘／庫の調査→返却先と会う→扉を開く。ザグの剣でなく、自分が預かった返却可能な品でも条件を満たせます。渡す物がなければ庫番の届け物を引き受ける道があります。庫を破るなら番人戦となり、宝物の正当な受領とは別の結末です。
結末と余韻：返却して入れば、持主のいない品を一つ正式に譲られます。ザグが剣を返すと師は別の練習剣を渡します。辞退しても配達料を得られます。最後、彼は新しい剣の由来を、奪った戦いではなく話した相手の名で語ります。拡張：模擬決闘は非致死の会話判定です。
# GQ035　水底の朝食
依頼と人物：沈んだ宿の食堂に、毎朝湯気が立つという。潜水具職人アネは調査を頼みます。祖母の宿が怪談になって客を呼ぶことを嫌う一方、誰かが今も火を守っているなら会いたいと思っています。
展開と開示：鍋を動かすのは祖母の幽霊でなく、同じ三つの作業だけを繰り返す給仕人形です。パンを出し、湯を注ぎ、客の返事を待ちます。洪水前に最後の客が返事をしないまま避難したため、区切りを失っています。食器は毎日同じ位置で、食材は乾いた幻です。
状態と条件：`F.cycle`は三作業を一巡観察、`F.last_guest`は宿帳から最後の呼びかけを確認、`F.automaton`は`waiting/stopped/relocated`です。反復は訪問回数だけで進めず、観察を選んだ時に一巡を描きます。
経路：潜水→食堂→人形を壊す／返事を探す／運び上げる。停止は正しい呼びかけへの応答、移設は職人の準備と浮力具が条件です。空気不足なら撤退して道具を補充でき、人形は待機を続けます。
結末と余韻：返事で止めれば食堂は静かになります。移設なら新しい宿で別の仕事を教えます。破壊して魔石を持ち帰る道ではアネが受取を拒むこともあります。報酬は潜水具の改良。地上で人形が初めて「おかわり」を聞き、同じ三作業の後に一つ新しい動きをします。
# GQ036　翻訳しない扉
依頼と人物：言語学者トゥリは、読めるのに開かない遺跡の扉を調べています。傭兵は通行料の暗号と思い、供物を積みます。扉の文は命令でも謎でもなく、来訪者が自分の名を名乗る挨拶です。学者は翻訳の正しさに固執し、対話の場として扱えていません。
展開と開示：古い録音石では、番人が名前を聞き返しています。辞書通りの単語だけを唱えても会話になりません。扉は正確な発音より、聞き返しへの応答を待っています。ただし誰でも無条件で入れるのではなく、訪問理由を申告する規則があります。
状態と条件：`F.dialogue`は録音を最後まで聞く、`F.name_given`は名前を申告、`F.purpose`は`unset/study/refuge/plunder`です。申告と実際の行為が違えば、退出時の番人の反応が変わります。
経路：扉→辞書調査／録音／試しに返事→用件の申告→内部。早期に会話と見抜けば調査を省けます。偽名でも通れますが、記録に残る名が変わります。破壊は別の入口を作る代わりに封印守護者との戦闘を招きます。
結末と余韻：研究なら記録室、避難なら宿直室へ案内されます。略奪を申告すると拒否され、別の行動を選べます。報酬は保存食か言語資料。トゥリが論文の冒頭へ、訳文でなく最初に返ってきた「お名前は？」を記します。拡張：会話式の扉は固定分岐で実現します。
# GQ037　燃え残る図書館
依頼と人物：一度燃えた図書館に、焦げた頁を開くたび新しい火が灯ります。写本師エルは唯一の薬学書を回収したい。消防係は全焼を防ぐため封鎖を望みます。館長は、自分が避難順を誤った過去を、蔵書を残すことで償おうとしています。
展開と開示：火は内容でなく、未完の読書に応じて再現される記憶魔法です。読み終えた児童書だけが冷たいことを先に示します。一冊を最後まで読む間、他の本へ手を出さなければその本を安全に持ち出せます。館長が何冊も同時に開いたことが火勢を保っています。
状態と条件：`F.rule`は冷たい本を比較、`N.read`は選んだ一冊の三段階読解、`F.selected`は`medicine/history/stories`、`F.closed_others`は残る本を閉じ終える履歴です。
経路：封鎖口→調査→一冊選定→読解三段階／途中退避→回収。別の本へ変える場合、読解は対象ごとに保管し、同時に開けません。薬学書以外を選ぶ理由も、それぞれ家族記録と地域の言語保存として示します。
結末と余韻：一冊救出、全閉鎖で将来へ保存、危険を承知して追加救出を準備する結末があります。今すぐ全部を救う道はありませんが、後の増援で続けられます。報酬は救った内容の閲覧権。館長が書架の戸を閉める音を、敗北でなく次に開くための区切りとして聞かせます。
# GQ038　行き止まりの探検家
依頼と人物：探検家ナルは、弟子を迷宮へ入れないため、未踏区画をすべて行き止まりとして報告しています。弟子イラは自分の発見を横取りされたと思い、証明のため単独で進みます。組合は不正地図の訂正と帰還者の確保を依頼します。
展開と開示：ナルの地図には、行き止まりの先ほど細かな休息地点があります。彼は実際には何度も進み、弟子が怪我をした時の退路を用意していました。保護の意図はあっても、探索権や選択を奪ったことは消えません。
状態と条件：`F.false_map`は実地との差を確認、`F.shelters`は救護地点の印を読む、`F.ila_found`は弟子へ到達、`F.credit`は`joint/ila/naru`です。発見済み地図を実歩行と同一視せず、測量で見た区画は別に扱います。
経路：組合→旧地図の追跡／弟子の足跡→休息所→弟子との帰還判断。先へ同行する、地図を訂正して戻る、ナルを呼び当人同士で話す道があります。弟子は同行を断れる人物として扱い、その場合は退路情報だけ渡せます。
結末と余韻：共同探索なら功績の配分を合意します。単独続行なら師弟は距離を置きます。訂正だけでも依頼は完了します。報酬は探索料と地図利用権。ナルが最後に描くのは通行止めでなく、危険の程度を示す小さな注意印です。
# GQ039　ふたつの出口
依頼と人物：崩落した坑道の二方向で救難の声がします。救助責任者セナは人数の多い側を優先し、地質師は水位の低い側を急ぐべきだと言います。声の片方は反響ですが、二組の生存者は本当に別の場所にいます。
展開と開示：声の数から人数を誤認させ、壁へ当てた器の振動で発生源を分けます。片側には声を出せない負傷者がいます。単なる偽の声を見抜けば解決という謎にせず、情報の少ない人をどう探すかへ続けます。
状態と条件：`F.echo`は反響の測定、`F.water_route`は排水路を確認、`F.air_link`は二室へ空気を通す、`N.work`は掘削または排水の完了一手ごとに増え、3手後に水位判定します。説明・相談では増えません。
経路：分岐点→声の測定／掘削開始→片室の救出→残室への対応。先に排水し空気を通せば、道具二組を使って両方を救えます。道具不足なら応援を呼ぶ間、空気を通す維持作業が必要です。片側だけ救う場合は残室の救援継続を明示します。
結末と余韻：両室救出、負傷者優先、人数優先で、後の感謝と責任が変わります。未確認の死亡を断定しません。報酬は救助料。声を出せなかった人が、地上で救難笛を返す時だけ小さく鳴らします。
# GQ040　迷宮の休業日
依頼と人物：毎週同じ日に迷宮の罠が止まる理由を、探索組合が調べています。罠を修理する小鬼の整備隊には休業日があり、人間がその日だけ財宝を持ち出すため、責任者ボロは休みを撤廃しようとしています。部下は疲れて事故を起こし始めています。
展開と開示：入口に並ぶ札を呪文と思わせ、実際は当番表だと分かります。ただし整備隊は侵入者を歓迎しておらず、罠の危険は本物です。人間側の組合も、迷宮を無制限に採掘する権利を持っているわけではありません。
状態と条件：`F.rota`は当番札を理解、`F.accident`は整備事故の救助、`F.pact`は`none/limited/closure`です。調査は受注後の一回の休業日に固定し、現実の曜日は参照しません。
経路：停止した罠→財宝庫へ急ぐ／整備区画へ入る→事故または会談→略取・入域協定・一時閉鎖。救助だけでも会談は始められますが、協定には持出品を申告する必要があります。交渉決裂なら外へ退くか、敵対する整備隊と戦って脱出します。
結末と余韻：略取は短期利益と将来の強化罠、協定は限られた探索権、閉鎖は修理期間の安全を生みます。報酬は調査料か正式な回収品。最後、ボロが休業札を裏返し、初めて入口ではなく部下の方を見て「帰れ」と言います。
